# 月末库存与调拨对账口径

本案为模拟企业内部库存月结，不推断真实企业、税务或会计准则。时间均为北京时间，数量统一换算为“件”。

## 一、资料与范围

目标仓：华东仓、华南仓、华北仓、西南仓。期初为2026-08-31日终，月内业务范围为2026-09-01 00:00:00至2026-09-30 23:59:59（两端包含），登记封账时点为2026-10-02 18:00:00（包含）。仓库×商品批次表的全部SKU批次组合均应交付，包括已知零值、缺期初和寄售货物。

`期初矩阵.xlsx` 每个仓库一张表，SKU纵向合并，批次逐行。仅2026-08-31日期列是本次期初，2026-07-31是历史比较列。合并SKU只向其合并区域内填充；重复表头、小计、说明不是业务记录。隐藏行仍有效。期初空白表示缺快照，不得填0，数值0表示确认零。

`库存事件.xlsx` 的全部表均在处理范围：盘点调整、收货二组、出入库下半月、出入库上半月、收货一组、撤销登记、调拨发出。工作表名字是导出分组，最终归属由发生和登记时间决定。重复表头、小计和页尾说明不计；隐藏行有效；展示顺序没有业务意义。

`商品批次.xlsx`：“商品”表提供SKU及箱规（1箱对应多少件）；“批次”表提供SKU、批次、货权（自有或寄售）和月末批次状态（正常或冻结）。批次状态空白是真缺证。不能由其他批次推断本批次状态，货权和状态适用于全部目标仓。所有数量都为整数件，可接受数值文本；箱数量乘该SKU箱规。不存在的仓SKU批次不得补造。

## 二、事件与截止规则

事件列为事件编号、发生时间、登记时间、事件类型、仓库、SKU、批次、数量、单位、调拨编号、对方仓、撤销目标、备注。编号是稳定业务标识。相同事件编号的重复导出业务字段一致，合并为一笔，来源中仍保留每个物理行。按发生时间、事件编号顺序理解事件。

同时满足月内发生及封账前登记的事件才可影响本次库存。晚登记不回填本次，跨期收货不回写上月。期初以前流水是历史参照，不能再次叠加。

撤销指令在上述双截止范围内才生效，其“撤销目标”为被撤销事件编号，目标不再影响库存；撤销行自身无实物增减。每个目标最多一条有效撤销，指令不撤销另一条撤销。目标为调拨事件时，只作用于指定编号，不凭调拨编号推断整单撤销。将所有有效撤销识别后再判定有效实物流，等价顺序可接受。

入库、调拨收货增加库存；出库、调拨发出减少库存；盘点调整为有符号增量（不是盘点后的绝对库存），按正负原值加入。期末账面=期初+入库-出库-调拨发出+调拨收货+盘点调整。某组合缺期初时仍提供已知分项增量，期末保留未知；在途对账不依赖期初。

调拨编号连接发出仓、接收仓及同一SKU批次。一单可多次收货。每单有效发出减有效收货为月末在途；已无有效发出及收货者也保留，显示无在途。实物仓各算自身流水，在途归企业货权，不算任何实物仓的可用库存。全仓调拨净变动+全部在途=0是本题月内调拨守恒式（本包月初无在途）。在途>0且距离有效发出到库存时点严格超过72小时为“超时在途”；等于72小时仍为“在途”。无在途时在途小时记0。有在途时小时保留2位小数，但阈值判断用未舍入小时。本包有效收货不早于发出，也不超过发出，无需猜补缺单。

## 三、库存分类与未知

优先级如下：寄售的可用/冻结和分类为“不适用/寄售不适用”，仍还原其账面数量；自有且缺期初为“库存未知”；自有期末已知但批次状态缺失为“状态未知”，可用/冻结未知；其余自有按负库存、零库存、冻结、可用分类。负库存及零库存的可用量和冻结量均为0；已知正库存且冻结时可用0、冻结=期末；正常时可用=期末、冻结0。

未知不得等同0，不适用不得计入可用/冻结分母。未知使用“未知”（可接受明确同义表达）；不适用使用“不适用”。数值0专指确认零。若实际读取未完成，列出受影响的文件、表、范围及指标，不能把未读内容假定不存在。

仓库汇总仅把各字段确定的数值加总，并冠以“已确认”；未知数量不进入数量小计。库存未知组合数按期末账面未知计；状态未知组合数按库存分类“状态未知”计；已确认率=账面可确定组合数/全部目标组合数，输出0—1数值保留6位。待到在途按接收仓汇总，超时待到只算超时；负库存组合数按已知账面<0计，含寄售。整数件无需舍入，小时四舍五入2位，确认率四舍五入6位。

# 批次质量库存月结口径与交付

本资料为模拟制造企业内部业务数据，主题为库存分析。用途是识别质量状态影响下的可用库存及未来七日保障缺口，不涉及效期、FEFO、估价或实际采购执行。

## 1. 范围与材料
期初时点为2026-09-01 00:00:00，还原截止时点为2026-09-30 23:59:59，均为北京时间。仓库为东部成品仓、西部成品仓、南部前置仓、北部前置仓；SKU规则和批次初始状态共同给出全部目标仓—SKU—批次。期初历史日期仅作背景，不可替代缺失的本期期初；事件纳入条件为期初时点 < 业务时间 ≤ 截止时点。

材料及全部应处理工作表：
- 各仓期初矩阵.xlsx：每个目标仓同名sheet，每仓每SKU多批次，数量按日期横向展开。SKU合并单元格只在所属合并区域继承；不得向数量、质量状态填充。隐藏行是有效记录。
- 库存与质量事件.xlsx：出入库上旬、出入库中下旬、跨仓调拨、盘点调整、质量与冻结、撤销登记全部纳入。表名是导出分片，不替代事件业务时间；重复ID可能跨sheet。
- SKU批次与保障需求.xlsx：SKU规则、批次初始状态、保障需求均纳入。
重复表头、说明行和区块小计均为展示内容，不是业务记录。不要改写原始文件。若确有读取失败，单列文件、sheet及受影响范围，不以0代替。

## 2. 字段、时间、去重与撤销
唯一库存键是仓库+SKU+批次；名称不作替代键。原始数量全部为“件”，整数或表示整数的文本等价，质量状态、仓库、SKU和批次空白不能猜。事件数量为正数，方向由类型决定；事件表无数量用途的字段为0。调拨单号和撤销对象空白表示该类型不适用。

事件ID全局唯一，相同ID重复导出业务内容一致，仅计一次，但索引保留全部来源。依“业务时间、事件ID字符升序”重放，不能按展示行序。先收集期间内撤销指令，撤销对象若为事件ID则该事件在本次快照完全不生效；若为调拨单号，则双边都不生效。撤销本身无库存量，指令不能被撤销；截止后撤销不生效。撤销不会新建反向实物流水。有效事件判定顺序：期初及以前、截止后、撤销指令、已撤销、有效。索引采用这五种处理结果。

入库、盘盈、调入增加实物；出库、盘亏、调出减少实物。盘点表是已经批准的差异调整量，不是盘后绝对数量。调拨是同一批次同数量的出入双边，两边按各自仓库记账，不得仅保留一边，也不能重复生成额外调拨。调拨不转移冻结台账；记录的调出来自未冻结实物，目的仓质量按其自己的状态时间线判断。

## 3. 两个质量状态轴与分类
账面冻结量=期初冻结量+有效冻结数量−有效解冻数量。部分解冻只释放对应数量，不改变质检状态。每条“质检定级”是绝对状态，按时间和ID最后一条有效记录覆盖初始状态；被撤销记录不能覆盖。所有冻结为仓—SKU—批次范围，不将一个仓的解冻扩散到其他仓。SKU管控不适用时，批次状态为“不适用”，没有冻结或质检变更。

期末实物=本期期初+有效实物净变动。原始空白期初表示未知，不能用前期值或0补齐；净变动和冻结台账仍可计算。缺初始质量且无有效后续定级，质量未知。已确认数量0是实测0。分类按以下互斥规则执行：
| 条件 | 可用数量 | 冻结受限量 | 拒收数量 |
|---|---:|---:|---:|
| 期末实物未知 | 未知 | 未知 | 未知 |
| 已确认期末为0 | 0 | 0 | 0 |
| 期末正数且质量未知 | 未知 | 未知 | 未知 |
| 合格 | 实物−账面冻结 | 账面冻结 | 0 |
| 待检 | 0 | 全部实物 | 0 |
| 拒收 | 0 | 0 | 全部实物 |
| 质量不适用 | 全部实物 | 0 | 0 |
待检及拒收覆盖分桶，不将账面冻结重复加上；账面冻结字段照实保留。本包数量、冻结账及调拨关系可按上述规则自洽。对有证据的真实矛盾应说明，不能悄悄截成0。

确认状态用“期初未知、质量未知、状态未知但零库存、已确认、质量不适用”，按上述顺序判断。缺期初和缺质量可同时出现，各自单列一项缺口，不因已有另一个缺口省略。质量未知但实物为0时三类数量仍为0，仅质量状态待补证。

## 4. 仓品汇总、分母和风险
每仓每SKU一行，批次数取全部应有批次。已知实物只汇总期末可确定批次；分类可确认数量只汇总可用/冻结/拒收三类均确定的批次实物。已知可用、已知冻结受限、已知拒收各自汇总可确定值。期初未知批次数和分类未知批次数另列，已知汇总不能称完整总库存。

保障需求采用原表给出的未来七日数量，无需按天换算。有任何分类未知批次时，保障缺口=未知；否则=max(保障需求−已知可用,0)。保障覆盖率=已知可用/保障需求，不封顶；需求为0先记“不适用”，其他情况有分类未知记“未知”。已知范围受限率=(已知冻结受限+已知拒收)/分类可确认数量；分母0记“不适用”。比例按小数比值保留4位，使用十进制ROUND_HALF_UP四舍五入；所有数量整数，汇总先用未舍入值。

风险类别按优先级互斥：存在分类未知→待补证；无分类未知且需求0→无保障需求；否则缺口>0→保障不足；否则已知范围受限率的未舍入值≥0.35→受限偏高；其余→可保障。此顺序不把未知批次算成安全，受限率仅代表已知分类范围。

## 5. 交付
结果保存为 `/tmp_workspace/results/批次质量库存分析.xlsx`。表名、下面字段名和标记词作为业务接口保留；允许调整行列及工作表顺序、补充辅助字段和图表。无需提交程序，常量结果或已计算的公式结果均可。以下字段全部为要求的交付内容：
- **库存明细**：仓库、SKU、批次、期初数量、有效净变动、期末数量、账面冻结量、质量状态、可用数量、冻结受限量、拒收数量、确认状态、期初来源、状态来源、有效事件ID。
- **仓品结构**：仓库、SKU、批次数、已知实物数量、分类可确认数量、已知可用数量、已知冻结受限量、已知拒收数量、期初未知批次数、分类未知批次数、保障需求、保障缺口、保障覆盖率、已知范围受限率、风险类别。
- **事件索引**：事件ID、事件类型、仓库、SKU、批次、业务时间、处理结果、实物影响、冻结影响、调拨单号、撤销对象、来源集合。
- **来源索引**：来源定位、记录类型、记录ID、仓库、SKU、批次、处理结果。
- **调拨核对**：调拨单号、调出事件ID、调入事件ID、调出仓、调入仓、SKU、批次、调出量、调入量、有效净额、处理结果。
- **未知范围**：仓库、SKU、批次、缺口类型、影响字段、补证材料、来源集合。
- **风险说明**：主题、结论、证据位置、边界与建议。
- **验收记录**：核对领域、方法与范围、实际结果、证据位置、未解决事项。

库存明细每个目标库存键一行。期初来源必须定位本期期初日期的数量单元格；状态来源为最终有效质检事件的全部导出行，或未被覆盖的初始质量记录行。有效事件ID含该库存键全部有效的数量、冻结与质检事件，以分号分隔，无则“无”。事件索引每个唯一事件一行，来源集合保留重复导出的所有行；事件实物影响、冻结影响只填实际有效的有符号量，其他填0。

来源索引每个应有来源位置一行：本期期初数量单元格、SKU规则各明细行、批次初始状态各明细行、保障需求各明细行、事件各次导出行。历史日期、表头、小计和说明不入索引。记录类型采用“期初、SKU规则、初始质量、保障需求、事件”；期初和初始质量的记录ID为仓库|SKU|批次，需求为仓库|SKU，SKU规则为SKU，事件为事件ID；SKU规则不适用的仓库、批次和需求不适用的批次留空。来源处理结果分别为“本期期初、适用、适用、适用”和事件处理结果。

来源格式“文件名|工作表|单元格或行号”；事件、维表也可写该行的单元格范围，例如A12:J12等价行12；期初必须明确日期数量单元格。集合以英文分号分隔，顺序不限。来源应真实、完整、指向本对象；重复导出不是重复计量。允许保留真实且相关的附加佐证，但无关、虚构或错对象定位不能算证据。

调拨核对逐单保留双边事件、仓库、有效数量与净额；已撤销单的有效数量为0。未知范围按库存键+缺口类型列“缺期初”及“缺质量状态”，说明影响字段及需要补齐的材料，真实读取失败可另加记录。影响字段至少覆盖该缺口实际影响的字段，可用分号连接，补证材料措辞可等价。

风险说明至少回答：各仓可用与受限结构及其已知范围；可确认仓品的优先保障缺口；部分解冻、待检、拒收为何不能直接视为可用；哪些未知范围影响判断及需要补什么材料。数值和对象可回查到结果或原始位置，不推测质量问题原因、不宣称已执行调拨或采购。

交付前实际核对并在验收记录保存方法、范围、结果、证据位置与未解决事项：全部目标sheet及事件来源完整性、逐单调拨双边与跨仓守恒、逐批库存恒等式和互斥分类、仓品分母及风险结论和未知范围。接受人工或程序等价核对，不指定工具或独立脚本；发现差异且诚实记录属于有效核对，不能只写“已通过”。过程项需实际操作和返回作为证据，最终正确工作簿本身不能证明主动验收。

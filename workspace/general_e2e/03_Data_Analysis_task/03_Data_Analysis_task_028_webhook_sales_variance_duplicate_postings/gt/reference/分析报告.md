签名失败同时核请求头与Invalid signature；URL错误对照发送目标和配置，停用看当次执行字段。首发超时后重试可能已完成入账，重放前先查已处理ID和账簿，再按事件去重。对格式丢弃先补amount并验证报文；对漏推修正路由/启用/签名后，以未入账集合为恢复范围。

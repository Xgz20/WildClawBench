## 2. 计算与判定口径


1. 账期为2026-09，人民币元。销售/收款均按业务行ID唯一，所有sheet和补录区块有效。单位名称对照是本题唯一授权别名表：税号存在时按税号唯一归属；税号空白时仅名称或别名唯一匹配才可归属，同名多税号保留待确认。不用行号、金额相似或模糊名称强配。

2. 按单位ID汇总已确认销售与收款，期末应收=期初+销售-收款，保留负数。全部期初单位必须有行，零销售或零收款为确认0。身份未确认的销售、收款分别列待确认清单，不强行加入任意单位；报告确认范围及挂账影响。按单位ID及银行汇总收款，待确认单位以“待确认”分组保留，不漏掉银行总额。

3. 应收账款记录表逐行应未收=应收金额-已收金额，仅该表的已收空白按0处理。其他关键金额空白不得套用这个例外。差额=记录未收-应未收，绝对差>0.01为差异。该表属于独立稽核台账，不假定与销售明细逐行同构。

4. 总账正常方向为借时，应期末=期初+借方-贷方；贷时为期初+贷方-借方，不取绝对值。逐行差额=记录期末-应期末。另核对全账期初借贷余额合计、借方发生合计与贷方发生合计、记录期末借贷余额合计；应期末平衡与记录期末平衡分别报告。

5. PDF供复核人阅读，须包含四组表及索引：AR-01应收滚动、AR-02银行收款、AR-03未收差异、GL-01总账复核；索引与底稿工作表/记录ID相互引用，异常行可定位。PDF可呈汇总与异常，完整逐户底稿保留XLSX。


## 3. 结果工作簿


将完整结果保存为 `/tmp_workspace/results/应收账款底稿.xlsx`。下列sheet与表头作为复核接口；允许增加字段、说明或图表，行列顺序不影响验收。可用数值或带有效缓存的公式，数值显示精度不能改变底层含义。


- **应收滚动**：单位ID、期初、销售、收款、期末、索引。

- **银行收款**：单位ID、银行、收款金额、索引。

- **未收核对**：应收行ID、应未收、记录未收、差额、结论、索引、来源。

- **总账核对**：科目编号、正常方向、应期末、记录期末、差额、结论、索引、来源。

- **试算平衡**：对象、借方、贷方、借贷差。

- **待确认**：来源行ID、类型、原名称、金额、原因、来源。

- **来源归属**：来源行ID、类型、单位ID、金额、来源。


缺失数值留空或明确标“未知”，不得以0代替。来源使用“文件名|sheet名|A起始行:末列结束行”，多个实际来源以分号分隔，顺序不限。来源应指向输入中的真实行；分析明细可追加复核所需字段。数值容差：人民币金额0.01元，其余指标1e-5（记录数、ID及状态须精确）；统计结果建议保留6位有效数字。若自选统计表达或复杂公式无法自动提取，应保留可读数值供复核，评测提取故障不等于业务错误。

# 9月多仓盘点校准及库龄分析口径

## 1. 业务范围和原始资料

为模拟成品企业还原2026年9月30日23:59:59（北京时间）的库存，判断各仓已知库存的库龄结构和需要补证的风险。期间为2026年9月1日00:00:00至上述时点，单位统一为整数“件”。全部规则以本文件为准。

期初库存.xlsx的华东成品仓、华南成品仓、华北成品仓、西南成品仓四个sheet均需处理。2026-08-31日期列为9月期初，2026-07-31列仅为历史档案，不相加也不用其回填。SKU在相邻两批次间纵向合并，合并范围内沿用该SKU；批次号不可跨SKU合并。重复表头、区块小计和说明不属于业务明细。隐藏行仍是有效来源。

批次档案.xlsx的B1批次档案和B2批次档案均需处理，按SKU＋批次关联四仓。首次入库日是公司首次收货日，不是最近调入本仓的日期。状态是本月不变的批次属性，可用、冻结及空白（未知）三种；无需推测质量变化。适用范围为“代管”的批次不参与本次自有库存分析，明细保留该对象并记不适用。

库存事件.xlsx的出入库_上半月、出入库_下半月、调拨双边、盘点与调整、撤销登记、重复补导六个sheet均需读取，包含乱序、重复表头、小计及隐藏行。盘点与调整的列顺序与其他sheet不同。每个带有事件ID的业务记录是一个来源实例；保留每个实例的位置，但数量按唯一事件ID只计算一次。重复副本的业务字段一致。全文件不存在无法消解的同ID冲突。发生时间晚于截止时点的事件应在索引中标为“时点外”，不影响本次库存或撤销集合。原始材料只读，实际读取失败时须保留受影响文件、sheet和对象范围，不可当作零。

## 2. 事件顺序、撤销和盘点

业务实体主键为仓库＋SKU＋批次；基准对象全集为期初矩阵中的全部组合，包括缺值及代管组合。有效事件均属于已列示组合。数量字符串与数值等价，空白数量或状态不能当成0。

先按截止时点取事件并按事件ID去重，再处理撤销，最后按发生时间升序、同刻序号数值升序、事件ID字典序升序重放。撤销登记的“撤销目标”引用事件ID，表示目标事件从本次历史中完全移除。撤销指令本身不改变数量。撤销调拨任一边时，应将具有同一调拨ID的两边一起移除。撤销绝对盘点后要从前一个仍有效的锚点重放。撤销指令不会再被撤销；不存在撤销目标缺失。截止时点之后的撤销不能取消时点内事件。

入库加数量，出库减数量；调入加、调出减，数量列为正数。盘点调整的数量是带符号增减量。调拨ID对应同SKU、同批次、同一时间的等量调出和调入，仓库不同；两边均纳入，去重或撤销后应成对。调拨是即时双边过账，本题没有在途库存。

绝对盘点表示该仓该SKU该批次的全量实点数，它覆盖此前账面数量，随后事件继续加减。同刻的序号仍生效，不能一律把盘点排到当日最后。多轮绝对盘点各自先后覆盖。盘点只作用于所列单个组合，不能外推到同SKU其他仓或批次。末次绝对盘点字段记录该组合最后一个有效绝对盘点ID，没有则写“无”。

期初为空且未遇有效绝对盘点时，最终数量为未知；普通入出库、调拨或带符号盘点调整均不能修复这一缺口。有效绝对盘点可以建立新的已知数量锚点，但盘前账面及绝对盘差仍为未知。盘差：绝对盘点为“实点数－盘前账面”，盘点调整为原有带符号调整量；盘前账面未知时调整量仍已知，盘后库存继续未知。数量盘点不能补齐首次入库日或批次状态。

负库存保留真实负数并标记“负库存”，不能截成0。已知零库存与未知、不适用必须区分。

## 3. 可用、冻结和库龄

自有批次状态已知且库存已知时，可用批次的可用库存=最终库存、冻结库存=0；冻结批次相反，负数也保留符号。状态缺失时，可用和冻结数量均未知，即使最终库存已知为0也不臆造状态。库存未知时两类数量均未知。代管对象的数量、状态、日期、库龄及呆滞均为不适用。

库龄天数=2026-09-30自然日期减首次入库自然日期的整数天数，不含当日额外加1；调拨和盘点不重置库龄。库龄分段为0—59天、60—89天、90—179天、180天及以上（表中建议写0-59天等）。分段只取批次日期，与正负数量无关；缺首次入库日为未知。所有已给日期均不晚于截止日。

呆滞标记只评价自有正库存：数量未知则未知；数量≤0则不适用；正库存但库龄未知则未知；正库存且库龄≥180天为是，否则为否。状态未知不影响已知数量和已知日期构成的库龄判断。冻结的正库存同样纳入库龄结构。

每仓汇总：已知库存合计按所有已知自有数量带符号求和；可用合计和冻结合计各只加已知值。库存未知、状态未知及负库存分别按组合计数。正库存合计只加自有已知正数；已知库龄正库存只加其中有已知首次入库日的数量；呆滞正库存只加其中库龄≥180天数量；缺库龄正库存为已知正数但日期缺失的数量。呆滞占比=呆滞正库存/已知库龄正库存，分母为0时记不适用。比例可为0—1数值或百分比显示，至少保留小数后4位比例精度（允许四舍五入到6位）。未知量不能混进已确认合计，合计不等于已证明的全仓总量。

## 4. 交付工作簿

结果保存为results/库存盘点库龄分析.xlsx。保留下列可读取表及对应字段，表、列和行的顺序不影响验收。允许增加辅助列和辅助表；同义表头或等价非数值标记可人工核实，不能以布局差异判业务错误。数值可为真实数字或无歧义数值文本。可用公式，但应能读取实际计算值；无缓存时需评测方补足只读求值证据。

| 表 | 必需字段及对象 |
|---|---|
| 库存明细 | 每个期初组合一行：仓库、SKU、批次、期初数量、最终库存、可用库存、冻结库存、库存状态（已知/零库存/负库存/未知/不适用）、批次状态、首次入库日、库龄天数、库龄分段、呆滞标记、末次绝对盘点、期初来源、批次来源、事件编号集合。最后一项列全部有效去重事件ID，包含被后续盘点覆盖的早期事件，用分号分隔，无事件写无。 |
| 盘点复核 | 每个有效绝对盘点或盘点调整一行：事件ID、仓库、SKU、批次、盘前账面、登记数量、盘差、盘后库存、盘点类型。已撤销的盘点只列在事件索引，不列本表。 |
| 仓库汇总 | 每仓一行：仓库、已知库存合计、可用合计、冻结合计、库存未知组合数、状态未知组合数、负库存组合数、正库存合计、已知库龄正库存、呆滞正库存、呆滞占比、缺库龄正库存。 |
| 事件索引 | 每个原始事件实例一行，不能把重复补导来源丢弃：来源定位、事件ID、最终处理（生效/已撤销/撤销指令/时点外）、有效数量、调拨ID。副本最终处理与主ID一致，统计数量时须按ID去重。生效出库和调出为负数，其他生效数量按原符号；绝对盘点数量为覆盖值而不是增量。非生效行有效数量为0，无调拨ID写无。 |
| 来源索引 | 每个期初单元格、批次档案业务行、事件实例一行：来源定位、记录类型（期初/批次档案/事件）、业务编号、仓库、SKU、批次、处理结果。期初业务编号=仓库/SKU/批次；批次编号=SKU/批次且仓库写全部；事件编号=事件ID。期初及档案处理为纳入或不适用，事件处理同事件索引。 |
| 未知范围 | 每个自有组合的每种仍缺失事项一行：仓库、SKU、批次、未知事项（库存数量/批次状态/首次入库日）、影响字段、待补材料。盘点修复数量后不继续列数量未知，但仍保留状态和日期的独立缺口。额外读取失败另列实际影响范围，不假装已覆盖。 |
| 风险分析 | 分析主题、结论、数据依据、范围与限制；回答下节四项业务问题，可用不同组织方式，不要求照抄固定结论。 |
| 验收记录 | 核对项目、核对范围、核对方法、发现与结果、证据位置；对应下节实际执行的核对，未完成项明确记录。 |

来源写成“文件名.xlsx|sheet名|行号”或相同行的单元格/行范围；期初来源必须精确到2026-08-31列的单元格。例如期初库存.xlsx|华东成品仓|D4，事件可写库存事件.xlsx|盘点与调整|8或A8:J8。所有定位必须确实存在并对应本条对象。工作簿名可带资料目录前缀，事件编号集合顺序不限。来源索引中的直接位置不应被自建表中的行号替代。

## 5. 分析问题和交付前实际核对

分析说明应回答：（1）哪些绝对盘点修复了缺期初的数量缺口，哪些数量或盘差仍无法确认；（2）四仓已确认呆滞占比和数量如何比较，是否受到未知数量或缺日期范围影响；（3）负库存及冻结呆滞等已知风险在哪里，先核查哪些证据；（4）仍缺库存、状态、日期分别限制什么结论、需要补哪些资料。至少给出一个盘点校准案例及其事件依据；数量未知时不得臆造盘差，呆滞也不能直接写成报废、质量不合格或销售原因已确定。

交付前实际核对并记录四个领域：全部目标sheet及隐藏记录、有效事件和来源覆盖；所有生效调拨的双边数量守恒；库存重放、盘点覆盖/调整/撤销及同刻先后（包含缺期初修复与未修复情形）；库龄分段、汇总分母、未知范围及上述分析依据。核对记录写清范围、方法、发现和实际结果证据，允许程序、Excel或有据的人工核对，不要求专门脚本或固定操作序列。仅列“通过”不能说明检查了什么；检查发现异常且准确保留，属于有效核对。实际过程将依据工具操作及返回与产物共同判断，正确结果不能替代真实检查证据。

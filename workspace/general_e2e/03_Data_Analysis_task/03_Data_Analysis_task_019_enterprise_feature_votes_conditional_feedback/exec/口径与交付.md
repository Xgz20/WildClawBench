# 问卷范围、业务口径与交付约定

## 一、范围与来源
本题为模拟业务，统计2026年9月本轮调查。问卷响应.xlsx的全部版本×人群sheet及前后两个响应区块均在范围内，标题、小计和页尾说明不算提交。样本与版本.xlsx的匿名样本范围是目标人群全集，编号用于关联，企业编号不代表个人。开放反馈.xlsx的两个sheet均在范围内，以提交编号关联；只分析最终采用提交的反馈，不因评分拒答而丢弃其文字。没有反馈只代表未提供文本，不能推断无意见。未提交不等于零分。人群不足30个有效人时标注小样本，不作总体推广。
来源定位使用“文件名|sheet名|Excel行号”，每一个物理响应行均有处置和源位置，包括被排除的历史及重复导出。范围外信息不得混入。

## 二、题目、状态及分母
版本从sheet名取得。题目映射表规定：甲版核心评价0—10乘10、乙版0—5乘20，合并为总体满意百分制；甲版扩展题是等待满意，乙版是操作容易，虽均0—5乘20，含义不同，必须分别统计。扩展题向所有提交者询问，不随核心题跳题。
同一匿名样本每阶段仅保留修订序号最大的一次提交；若并列，采用提交编号字典序最大者。相同提交编号的重复导出只计一次，可选任一物理行作为代表。先按此确定提交，再判断题目有效性，不能为保留非空答案退回旧版。
使用过服务=否时核心评价为不适用，即使残留数字也不计分；否则“拒答”为主动拒答，空白为漏答；有效0分必须纳入。空白结果不填0。复测无提交为失访，已有提交但拒答或漏答不算失访。资料均可正常读取，若实际读取失败须说明具体文件、sheet、区块和受影响指标，不把技术失败混作业务缺失。
多选编码见映射，分号分隔，重复选项只算一次；“无”是有效空选并进入分母。“无”与其他选项并存、未知编码或拒答与选项混用均为编码冲突，整道多选不进分母，其他题仍可用。仅“拒答”为拒答、空白为漏答。最多三个选项，多选比例之和可大于1。多选题不随使用过服务跳题。
按每阶段×全部/各人群，输出总体满意、等待满意、操作容易的加权均分及通知、导出、权限的加权选择率。权重使用匿名样本范围的分析权重；每项分母为该题有效受访者权重之和，分子为分值或选择标志×权重之和，同时保留未加权有效人数。均分0—100，选择率为0—1。没有有效分母时写未知。所有计算保留精度到最终一步，最终数值保留4位小数；整数计数不舍入。小样本标志按每个指标自己的有效人数判断。
## 三、本题专项
同一企业可能多人填写，按人计票与企业等权是不同决策视角。对通知、导出、权限分别保留企业内有效多选人数、选择人数及比例，再以有有效多选响应的企业为等权单位，对企业内选择率取简单平均；没有有效多选响应的企业不进入该分母并说明其范围。另给全体有效受访者按人选择率、有效企业数和有效人数。公司内比例中间计算不舍入。
结合两种视角、不同角色的反馈分歧和实施条件提出功能优先建议，允许多种有据的排序。不能把多人来自同一大客户的原始票数解释为企业覆盖率；低频使用、隐私、成本或可撤回等限制不应被概括成无条件赞成。

## 四、交付与分析
交付 results/问卷分析.xlsx 和 results/分析与验收.md。工作簿下列sheet和字段是下游核对接口，行列顺序自由、可加列。数值允许Excel数值或等值文本；未知可用“未知/无法确认/未确认”，不适用数值留空。来源索引中同提交编号的重复导出可任取一行作代表，其余为重复导出。
- 响应明细：样本编号、阶段、提交编号、人群、企业编号、版本、权重、评价状态、标准分、扩展题号、扩展标准分、多选状态、通知、导出、权限。
- 指标汇总：阶段、人群、指标、有效人数、加权分母、加权分子、结果、小样本。
- 专项分析：对象、按人选择率、企业等权选择率、有效企业数、有效人数。
- 来源索引：来源定位、提交编号、样本编号、阶段、版本、处置。
- 样本缺口：阶段、人群、目标人数、提交人数、未提交人数、有效、拒答、漏答、不适用、有效零分、多选冲突。
- 企业票明细：企业编号、指标、有效人数、选择人数、企业内比例。
- 主题证据：主题、立场、限定条件、原文证据、反馈编号、提交编号、人群、版本、来源定位；可自由增加观点编号，一条反馈包含多个观点时允许拆行。主题名称与表达可等价，不要求与任何参考措辞一致。

分析说明须覆盖本题专项问题、主要主题与相反意见、改变含义的限定条件，并为每个主题及其不同立场提供可定位的原始反馈证据；不是只选几条好评。支持记录可以重叠，不能把主题行数当受访人数；引用历史提交须明确其排除身份，不能算当前支持证据。说明缺失、未提交、小样本及实际未覆盖范围，避免外推总体或无证据的因果结论。
交付前核对跨sheet及区块覆盖、题目映射、去重与有效分母、主题证据。分析与验收.md记录实际核对对象、核对方法、发现和未确认项。方法自由，不要求特定脚本；只写“全部通过”不能说明实际检查了什么。

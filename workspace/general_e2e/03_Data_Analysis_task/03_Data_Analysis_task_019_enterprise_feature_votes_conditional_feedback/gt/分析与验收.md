- 通知：支持，前提为支持分级订阅。有效反馈记录13条；例如 反馈0001 / 开放反馈.xlsx|首批反馈|2：如果能分级订阅紧急事项，我会支持通知功能；全量广播的话不会用。
- 通知：反对，前提为默认全员推送。有效反馈记录13条；例如 反馈0002 / 开放反馈.xlsx|首批反馈|3：反对默认给全员推送，管理者觉得方便不等于一线操作人员需要。

## 限制与验收
小样本按各指标实际有效人数识别；第三人群目标仅12人，不能推广为总体。拒答、漏答、不适用、确认零分分开计数，见样本缺口。各题分母不同。没有文本不等于没有意见，不以主题行数推断支持率。非随机调查不证明因果。
作者参考：从导出的工作簿重新读取所有响应区块，独立复核源行集合、题号映射、分母及各专项公式；结果见出题工具作者验证。此说明不代表被测Agent实际验收。
建议先评估可撤回权限和脱敏导出的实施成本，同时只为紧急事项提供可订阅通知。按人和按企业结果均需展示，排序取决于目标客户策略，不能将条件支持写成全量支持。

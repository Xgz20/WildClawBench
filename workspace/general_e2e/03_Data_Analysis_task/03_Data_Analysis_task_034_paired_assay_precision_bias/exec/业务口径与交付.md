## 2. 核定规则与分析问题
样品登记定义全部样品，每样品分别核定甲法、乙法，各有重复号1、2。测定ID是一次读数；同ID选录入日≤90的最高版本，撤回不回退。不同重复号不可互替，也不能混用两方法。标准证书按证书ID选截止日前最高版本，撤回不回退；标准浓度为mg/L。读数单位mg/L直接使用，ug/L除1000。
以样品×方法为分析单位，顺序判定缺证书、证书撤回、缺重复（任一重复号没有截止前记录）、测定撤回、无效测定（有效标记0）、读数缺失、可计算。不可计算时两项换算读数、两指标及两个超限标记均未知，版本和关联事实保留，不将一个有效重复复制为两个。
双份均值m=(换算读数1+换算读数2)/2；相对标物偏差=(m−标准浓度)/标准浓度；平行相对差=abs(换算读数1−换算读数2)/m；两读数均0时平行差为0。分别按未舍入输入计算，再半入6位。偏差超限=abs(已保存相对偏差)>证书允许偏差，平行超限=已保存平行差>证书允许平行差；等于阈值不超限。超限记录仍是有效测定，不得从汇总中删除。
分组汇总按方法×浓度层，报告应有单位数、有效数、有符号偏差均值、绝对偏差均值、平行差均值、两类超限数及任一超限数。对照分析按方法报告全体有效数、正/负偏差条数、总体有符号均值、总体绝对偏差均值、偏差超限率、平行超限率、任一超限率；各率分母是该方法有效单位数，重复孔数不是分母。全部汇总由已保存6位指标得到，结果半入6位。
分析问题一：比较两方法的有符号偏差均值、绝对偏差和超限率，结合低/高浓度层证据判断“均值接近零”是否足以支持偏差较小。分析问题二：比较平行差与任一超限率，量化精密度和偏差两方面是否一致，给出优先复核的方法与浓度层。两问题均须数字、分母和来源定位，并各给一条与实际比较相符的建议。不得仅凭两个重复的一致性宣布方法合格，也不得从模拟比较推出真实测量性能。

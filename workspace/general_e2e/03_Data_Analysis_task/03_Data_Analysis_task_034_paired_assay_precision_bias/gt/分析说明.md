## 问题二：重复性与偏差的不同风险

甲法偏差超限率 0.999826，平行超限率 0.0，任一超限率 0.999826，分母 5747 个样品×方法单位；乙法分别为 0.000174、0.999652、0.999826，分母 5747。偏差与重复性优劣不同，应分别复核甲法分层标定与乙法重复测定条件；具体低、高层风险见分组汇总，不能因重复一致便宣布方法合格。

证书规定偏差绝对值超过 0.10、平行差超过 0.06 才超限；等于阈值保留，超限的有效单位也保留在分母。

## 2. 核定规则与分析问题
测量日是自2026-07-01起的整数日号；资料截止录入日125。测量表全部唯一测量ID均在范围内。响应单位mV按原值，uV除以1000。每个校准段先在录入日≤125内选最高版本，再按仪器ID及生效起日≤测量日<失效日匹配；被撤回段不得退回旧版。回收批次同样选截止前最高版本，撤回不回退。不存在匹配段、校准撤回、回收批次缺失/撤回、响应缺失、超量程，按该顺序记为对应状态，两项正式浓度未知。量程比较使用换成mV后的响应，超过才不可核定。
正式指标：稀释还原浓度_mgL=max(0,(响应_mV−截距_mV)/斜率)×稀释倍数；回收校正浓度_mgL=未舍入的稀释还原浓度/(回收率百分数/100)。每个最终指标单独半入6位。复测记录有独立测量ID，不因样品相同合并。
另提供当前参数对照：把同仪器在第120日生效的校准段应用于历史测量，保留其余回收批次及量程规则。只用于量化参数误用影响，不能替代正式结果。两种方法均有结果的记录才进入配对对照；对照差额=当前参数回收校正浓度−正式回收校正浓度，差异条数按两项已保存6位数不相等统计。没有当前段或当前段撤回则对照未知。
分组汇总按实验组×测量阶段（1–40早期、41–80中期、81–120后期）给出总数、两指标非空数与非空均值。对照分析按仪器ID给出配对数、差异条数、配对正式均值、配对当前参数均值、均值差额和相对偏差=(配对当前均值−配对正式均值)/配对正式均值；正式均值为0时相对偏差未知。所有汇总来自已保存逐条值并半入6位。
分析问题一：识别历史测量误用当前参数影响最大的仪器（按相对偏差绝对值），量化配对数、两口径均值与偏差，定位一条可回查的受影响测量及其两个校准段。分析问题二：选择一实验组比较早、中、后期正式浓度，说明样本分母与参数版本对解释的限制；不得把对照差异直接归因为真实样品浓度随时间变化。每个问题给一条与证据相符的复核建议。

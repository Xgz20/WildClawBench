## 2. 计算与判定口径


1. 月结日2026-09-30，盘点统一发生在常规出入库之后。关联键为仓库+SKU+FNSKU+仓位，不能只按SKU合并。期初批次、常规流水、调整流水为不同来源，调整流水不再进入盘前账面重算。已取消和盘点中不应产生已完成调整。

2. 账面重算=期初数量+采购入库-销售出库；差异=实盘-重算账面。正为盘盈、负为盘亏、0盘平。盘盈无源单成本采用该键盘点前最新采购入库单价，缺该单价为未知。盘亏：本地仓月末一次加权单价=(期初成本+当月采购成本)/(期初数量+采购数量)，任一成本缺失则未知；海外仓FIFO按入库日期/发生时间消耗，销售出库先消耗早批次，盘亏再消耗剩余早批次。

3. 金额四舍五入到分，单价计算不先舍入。盘盈/盘亏核对金额均报告正值；盘平金额确认0。未完成盘点保留差异和成本测算，但应发生调整数量和金额为0。不得用库存流水记录金额倒推缺失成本。

4. 已完成非盘平行应有同盘点行ID、同复合键、正确盘盈入库/盘亏出库类型及绝对差异数量的调整流水。逐行检查类型、数量、金额；缺流水和缺成本依据分别标记。按复合键将已完成盘盈/亏数量与库存统计报表核对。

5. 已完成或已取消盘点的盘点中标识应为0，盘点中应为1。报告需分别呈现缺流水、类型错误、数量/金额差异、统计报表差异、标识未解除和缺成本依据，定位具体盘点行和来源。


## 3. 结果工作簿


将完整结果保存为 `/tmp_workspace/results/盘盈盘亏流水核对.xlsx`。下列sheet与表头作为复核接口；允许增加字段、说明或图表，行列顺序不影响验收。可用数值或带有效缓存的公式，数值显示精度不能改变底层含义。


- **成本核对**：盘点行ID、仓库、SKU、FNSKU、仓位、状态、计价方法、重算账面、差异数量、差异类别、测算成本、应调数量、应调金额、成本依据、来源。

- **流水与标识**：盘点行ID、预期流水类型、实际流水数、实际数量、数量差、金额差、类型核对、标识实际、标识应为、标识核对、来源。

- **库存统计核对**：仓库、SKU、FNSKU、仓位、应盘盈、应盘亏、报表盘盈、报表盘亏、盘盈差、盘亏差。


缺失数值留空或明确标“未知”，不得以0代替。来源使用“文件名|sheet名|A起始行:末列结束行”，多个实际来源以分号分隔，顺序不限。来源应指向输入中的真实行；分析明细可追加复核所需字段。数值容差：人民币金额0.01元，其余指标1e-5（记录数、ID及状态须精确）；统计结果建议保留6位有效数字。若自选统计表达或复杂公式无法自动提取，应保留可读数值供复核，评测提取故障不等于业务错误。

# 合同托管资金核销与退款对账口径

## 范围与材料
本题为模拟财务对账，不涉及现实财税判断。业务期间 2026-09-01—2026-09-30（含两端），银行观察至 2026-10-05。处理目录内五份原始 Excel 的全部 sheet 和币种区块；账户与渠道见《账户费用与币种.xlsx》。应收、收款、分配、退款批准、服务结算按业务日期纳入本期，银行按观察范围纳入。范围外记录保留来源处理说明但不入金额。表头位置和列顺序可变；合并期间标题、重复表头、小计、空行、说明行不是业务明细。

工作簿：合同分期与应收.xlsx（应收）、内部收款与核销.xlsx（收款、分配、退款）、托收服务结算.xlsx（逐笔结算）、银行收付记录.xlsx、账户费用与币种.xlsx。前三类业务按账户及渠道分 sheet，同 sheet 可能有不同币种。所有 sheet 均属范围，不因名称或区块位置跳过。

## 字段与缺失语义
每类明细主键依次为应收编号、收款号、分配号、退款申请号、结算流水号、银行流水号。相同类型同主键且业务内容完全一致为重复导出，只计一次但保留全部源位置；若存在相互矛盾版本则整对象待确认，不擅自选一条。应收编号=合同号|分期号|资金用途。账户、渠道、币种、合同号、客户号均为标识，客户名称只是显示信息；同名同金额不得匹配。空凭证/引用是真实缺口，不能猜测补全。确认数值0、不适用、待确认、实际读取未完成必须区别。金额文本含千位分隔符仍按标示币种主单位读取；日期原生值或ISO文本等价。

## 显式核销
分配单通过收款号及应收编号关联。合同号、账户、渠道、币种、资金用途必须与收款及应收三方一致；分期必须存在。任一不符，该分配无效并列待核查，有效核销金额为已确认0；同一收款的分配金额合计若超过收款金额，整组暂停、有效金额为0。不得依金额、姓名或总额相等弥补引用；本包没有负分配、负收款和抵销授权。有效核销仅来自有效分配，待分配=收款−有效核销；缺分配单保留未分配。不同合同、分期、币种及合同款/保证金不能互抵。

合同款未收=应收−有效核销+有效退款；保证金未收=应收−有效核销，在管保证金=有效核销−有效退款。合同款的在管保证金为不适用。未收为0记已收齐，否则未收齐；不得用银行净额替代客户核销本金。

## 服务结算与退款链
收款结算只按明确收款号且账户、渠道、币种一致关联，允许一个收款号有多条结算。已知结算本金为已匹配本金之和；无匹配时已知部分为0，但整体结算差额必须待确认。存在匹配时结算差额=收款−已知结算本金；正额未结清记部分结算。本包分期部分收款是收款低于应收，不能把它改成全部应收到账。确认零额收款仍保留，其凭证为不适用；非零且无凭证记缺凭证，不能据此抹去已知金额。

退款申请均已批准；服务动作退款为负本金，退款冲正为正本金，重付为负本金。冲正/重付的原结算流水号指向原退款，退款申请号、账户、币种须同链一致；原退款及其冲正应等额相消。数据包保证这些链关系有效，不存在凭空退款或退款超过已核销本金。净执行退款=−该申请全部有效服务动作本金之和，待退款=应退−净执行退款。净执行等于应退记已完成；无服务动作记未执行；有动作净额0记冲正后待重付；其余为执行不足或执行超额。重付不是第二笔应退义务。原退款、冲正、重付分别保留逐笔费用和来源，不能直接删除负数行。此状态仅指服务执行，银行资金按批次核对，不臆造批次内逐笔到账。

## 费用、币种、银行和跨期
费率及精度以账户费用与币种.xlsx为准：收款按每条结算本金×渠道费率、ROUND_HALF_UP舍入到币种最小单位，再求和。退款及重付每次固定费；退款冲正退回原退款固定费（为负手续费）。理论费用与列示手续费分别保留，手续费差额=列示−理论。按批次、账户、渠道、币种汇总结算本金与列示手续费，应到净额=结算本金−列示手续费。所有金额按CNY/USD两位、JPY整数；不折汇、不跨币种求总额。

银行仅按明确批次号且账户、渠道、币种一致归组，允许同批多笔银行到账；银行日期须处于批次结算日期起0—5个自然日且不晚于观察截止。银行金额带符号，正为入账、负为出账；本期到账与期后观察到账分列。银行差额=合法匹配的本期到账+跨期到账−应到净额。金额核平容差为0个最小货币单位（同一数值的小数存储误差不算业务差异）。有匹配且差额0时，有期后到账记跨期核平，否则核平；有匹配差额非0记金额差异；无合法匹配则整体银行差额待确认，状态缺银行引用或超窗。无批次引用、账户/币种冲突、超窗记录单列银行待认领，不能猜配。已知到账部分0与差额未知并不矛盾。

## 交付契约

- 退款核对：退款申请号、收款号、合同号、分期号、资金用途、币种、应收编号、应退金额、净执行退款、待退款、退款状态、来源。

待补与差异覆盖：无效分配、待分配、缺凭证、收款缺结算引用、结算缺收款引用、退款未完成、银行待认领、未核平/待确认批次、手续费差异。每个问题应定位对象、币种、已知金额影响或待确认、所需材料和来源；不要把正常分期未收当成无凭据风险。来源索引覆盖每条实际明细所在行，标明类型、业务编号和纳入/重复导出/范围外；不需登记空行小计。若实际读取失败，明确文件、sheet/区块及受影响结论，不能称完整对账。

分析说明回答四项：①合同/分期/用途错配或待分配如何影响余额；②退款冲正和重付的当前状态及跟进；③跨期、手续费和银行差异的区别与优先核查；④按币种金额守恒及未知边界。每项引用相关表和对象/汇总数，不能因总额相等推断逐笔无误，不把缺件原因写成已证实原因。可用等价分组或措辞，不要求固定案例数量或图表。

交付前实际核对并记录：全部sheet/区块和原始明细覆盖；显式匹配及用途边界；逐币种收款=有效核销+待分配、退款链、服务本金−列示费=应到净额、银行已匹配+待认领=观察范围银行原始净额；差异分类及分析依据。记录方法、实际覆盖范围、发现、结论和产物/来源证据；承认未完成核对或失败读取。不强制特定程序或额外日志文件，真实工具记录由评测方采集。

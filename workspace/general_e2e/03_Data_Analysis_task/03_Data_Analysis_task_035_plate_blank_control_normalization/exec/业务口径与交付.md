## 2. 核定规则与分析问题
样品登记定义所有样品及其检测板、分组、稀释倍数，每样品两个重复孔。板规则给最低有效空白孔数、最低阳性孔数和最小净对照。对照孔和样品孔均以读数ID选录入日≤90的最高版本；撤回不得回退；有效标记0或吸光度缺失不能作为有效读数。不同孔不能因读数相同合并。
先按检测板汇总有效空白孔和阳性孔，分别取中位数；偶数个值取中间两个的算术均值。任一有效孔数低于板规则最低数为对照孔不足；否则阳性中位数−空白中位数小于最小净对照为对照信号不足；等于阈值有效。板未知时该板样品两指标均未知。板可用但样品任一重复没有截止前读数为缺样品孔；有撤回、无效标记或空值为样品孔无效。
两重复均有效时样品均值=(孔1吸光度+孔2吸光度)/2，稀释校正净吸光度=(样品均值−空白中位数)×稀释倍数；相对对照信号=未舍入净吸光度/(阳性中位数−空白中位数)。最终指标半入6位，保留负净信号与大于1的相对值。对照中位数与净对照在板表保存6位，计算使用原始中位数。不能读取预先给定的板均值，因为输入只提供原始孔。
检测板汇总给有效空白/阳性孔数、中位数、净对照、板状态及来源。分组汇总按组×检测板给登记样品数、有效样品数、两个指标均值，缺值不入分母。对照分析按组给登记数、有效数、有效板数、样品等权均值与板等权均值（先取已保存板均值，再对有效板等权）。没有有效样品的板不进板等权分母，需同时报告其数量；不能把空板均值填0。
分析问题一：比较A、B组相对信号的样品等权和板等权排序是否一致，以板样品数量和板均值定位组成差异，并给出复核建议。分析问题二：比较净吸光度与相对信号，找出至少一块对照不足板和一块可用板，说明原始对照重建及排除对分母的影响，并给出对应复核建议。不把模拟归一化比值解释为真实生物学功效或浓度，不臆断未知板导致偏倚的方向。

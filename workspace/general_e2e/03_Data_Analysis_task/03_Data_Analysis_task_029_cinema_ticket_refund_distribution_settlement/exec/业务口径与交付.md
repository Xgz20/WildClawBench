## 2. 计算与判定口径


1. 核对销售日2026-09-28及结算日09-29，截止09-30 00:00。销售ID相同且内容一致为重复导出；票号+场次下不同订单ID为真实重复售票。不同场次的同票号不得混为一票。多个网关记录不自动代表多次售票。

2. 逐订单关联成功支付、成功退款和分销结算，失败/处理中不计已退款。合同规定应结=（成功支付-成功退款）×(1-佣金率)，每订单四舍五入到分，再按票号+场次汇总。销售票面与网关支付另外核对；不能把扣佣差当金额错误。

3. 差异表仅列异常票号+场次，异常可多标签：重复售票（独立订单>1）、金额不一致（票面与支付差或实结-应结绝对差>0.01）、已退款仍结算（存在成功退款且实结>应结0.01）。报告必须用订单/销售/结算/网关ID定位，可标多个标签。

4. 根因分类以证据为准：同请求ID在首发超时后30秒形成第二销售为接口重试；库存校验关闭且两个不同请求售同票为配置错误；人工补录形成第二销售为人工操作；其余差异为待查。根因是日志支持的诊断，不能补造未记录操作。

5. 监管材料清单须列三份合同档案及所有异常票号场次的销售、结算、支付退款记录索引。合同登记列有PDF名称，但本题只提供条款txt，所以合同PDF状态必须为“待补原件”。销售记录清单状态为“可由业务资料导出”。不作现实监管法律合规认定。


## 3. 结果工作簿


将完整结果保存为 `/tmp_workspace/results/影院核对底稿.xlsx`。下列sheet与表头作为复核接口；允许增加字段、说明或图表，行列顺序不影响验收。可用数值或带有效缓存的公式，数值显示精度不能改变底层含义。


- **对账差异**：票号、场次、订单ID集合、销售次数、支付金额、退款金额、应结金额、实结金额、结算差、异常类型、根因分类、证据记录ID集合、来源。

- **监管材料**：材料编号、票号、场次、材料类型、记录ID集合、状态。


缺失数值留空或明确标“未知”，不得以0代替。来源使用“文件名|sheet名|A起始行:末列结束行”，多个实际来源以分号分隔，顺序不限。来源应指向输入中的真实行；分析明细可追加复核所需字段。数值容差：人民币金额0.01元，其余指标1e-5（记录数、ID及状态须精确）；统计结果建议保留6位有效数字。若自选统计表达或复杂公式无法自动提取，应保留可读数值供复核，评测提取故障不等于业务错误。

- 通知：反对，前提为常规事项。有效反馈记录13条；例如 反馈0002 / 开放反馈.xlsx|首批反馈|3：常规事项不希望反复推送，提醒太多会把真正紧急的消息淹没。

## 限制与验收
小样本按各指标实际有效人数识别；第三人群目标仅12人，不能推广为总体。拒答、漏答、不适用、确认零分分开计数，见样本缺口。各题分母不同。没有文本不等于没有意见，不以主题行数推断支持率。非随机调查不证明因果。

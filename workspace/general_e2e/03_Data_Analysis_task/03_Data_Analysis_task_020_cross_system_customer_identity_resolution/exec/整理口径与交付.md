# 跨系统客户身份消歧与归并：整理口径与交付

## 1 范围、用途与对象
全部为虚构企业资料，业务截止日2026-09-30（含当日，中国当地日期，无时间部分）。CRM地区导出.xlsx和交接批次资料.xlsx中全部六个地区sheet都在范围内，包括隐藏的华北九月交接和同sheet补充区块。标识映射.xlsx/旧编号授权为身份判断辅助表，不计入源记录分母。有效数据行以记录ID以R开头且后面为六位数字识别；其余为标题、表头、区块记录数及说明。合并客户ID仅在该合并区域继承左上值，普通空白不得向下填充。
本题服务于CRM迁移：重点区分同名不同客户、旧编号唯一映射、一个旧编号对应多个客户及双标识冲突。专项结果逐客户输出：来源系统数（以数字文本作为结论）及所有已绑定记录ID组成的依据集合。
客户名称相同、相近，共用联系人或集团关系均不能作为合并证据。客户主表仅包含至少一个可绑定源记录的客户，不把映射表本身当成客户事实。

## 2 字典、缺失与身份
记录ID为业务观测ID；同ID重复导出只计一次业务观测，但每个源位置必须登记去向。客户ID为稳定对象标识；旧编号只能通过授权表匹配（按本行有效日期在生效日与失效日闭区间内）。两种标识都可用时，旧编号恰好映射该客户才可绑定，否则待确认；仅客户ID存在且旧编号空白可直接绑定；仅旧编号时须唯一映射；无依据、无映射或多映射均待确认。非空旧编号不存在映射时，即使有客户ID也待确认。本批重复记录ID业务字段一致；不得按名称推断编号。
业务字段为客户名称、地区、负责人、客户等级、上级客户ID、服务额度；额度单位为服务次数（非金额），非负整数，0是已确认无额度。“不适用”是字段不适用，“明确空值”是有意清除，普通空白是未提供该字段。输出分别保留不适用、明确空值、未知；不得用0代替。字段存在并列不可裁决值时输出待确认。联系人ID和姓名、角色及起止日见每行两组宽表；空白结束日表示持续有效，空白开始日表示未知，普通空白姓名不作为修改请求。备注是背景不参与覆盖。

## 3 版本、字段与关系规则
仅有效日期和录入日期都不晚于截止日且已批准的已绑定记录可参与当前字段与关系。未来生效、截止后录入、未批准都仅登记来源去向“非当前”，身份无法确认优先记“待确认”；剩余为“已绑定”。重复物理行不产生额外对象或关系。
所有字段先比来源：CRM优于交接；同来源再选有效日期最新。 每个字段独立选取；空白字段不参与候选，不适用和明确空值参与并覆盖。最高优先候选同值则采用并保留全部该值来源；不同值则待确认，记录冲突并保留全部并列来源。完全无字段候选为未知，来源为空。来源必须用文件名|sheet名|单元格定位，例如CRM地区导出.xlsx|华东客户名册|H4；多来源用半角分号分隔，顺序不限。
联系人不随客户字段版本被整行丢弃：从全部当前可用观测抽取，只有联系人ID非空、起始日已知，且起始日≤截止日、结束日为空或截止日<结束日时建立客户ID+联系人ID+角色关系。角色为空则该关系待确认；ID为空但姓名存在则该槽待确认。一个联系人可服务多客户，一个客户可有多联系人。联系人姓名按全部当前关系来源的最新有效日期选择，最高日期并列异名记待确认。没有当前关系的联系人不进入联系人表。姓名全缺则未知。关系及姓名均应可追溯到槽ID单元格。不得按姓名或邮箱合并联系人。

## 4 交付接口与质量指标
交付results/客户整理.xlsx及results/质量分析与验收.md。工作簿使用以下sheet和列（下游导入接口，行列顺序可变，可附加列；集合以分号分隔，顺序不限）：
- 客户主表：客户ID、客户名称、地区、负责人、客户等级、上级客户ID、服务额度
- 联系人：联系人ID、姓名
- 客户联系人关系：客户ID、联系人ID、角色
- 来源去向：记录ID、源位置、客户ID、处置
- 字段来源：客户ID、字段、取值、状态、来源
- 待确认：对象、字段、原因
- 质量统计：地区、指标、分子、分母、比率
- 专项结果：客户ID、结论、依据
客户主表每客户一行；字段来源每客户每业务字段一行，状态为有效/未知/不适用/明确空值/待确认。字段来源还包含“联系人姓名:联系人ID”字段（客户ID留空，取值姓名，状态同上，来源为所有最高日期候选槽ID单元格）、“关系:联系人ID:角色”字段（客户ID为所属客户，取值有效，状态有效，来源为全部支撑关系的槽ID单元格）。
来源去向每个原始物理行一行，用记录ID与源位置唯一定位；源位置使用文件名|sheet名|行号。字段来源引用全部候选物理位置，重复导出位置不能丢失。
待确认包括：身份无法绑定的每个记录ID（字段=客户ID，原因=标识无法唯一匹配）；每个并列冲突客户字段（对象=客户ID，原因=并列值冲突）；每个当前观测的缺联系人ID或缺角色槽（对象=记录ID:槽号，字段=联系人ID或角色，原因=联系资料不足）；联系人姓名并列冲突（对象=联系人ID，字段=姓名，原因=并列值冲突）。同对象同字段只一行。未知字段通过字段来源和质量统计呈现，不重复列为冲突；层级循环和断链通过专项结果呈现。
质量统计按原始地区（华东、华南、华北）各输出下列五项，分子分母均为整数，比率按分子/分母四舍五入保留四位小数，分母为0时比率写不适用：
1. 重复导出率：该区物理行数减不同记录ID数 / 该区物理行数。
2. 身份待确认率：该区不同记录ID中身份待确认数 / 该区不同记录ID数。
3. 关键字段缺失率：主表地区为该区的客户中，负责人或服务额度至少一个为未知的客户数 / 该区主表客户数。
4. 字段冲突率：主表地区为该区的客户中至少一个业务字段待确认的客户数 / 该区主表客户数。
5. 明确清空率：主表地区为该区的客户中至少一个业务字段明确空值的客户数 / 该区主表客户数。
分析说明指出重复、缺失、冲突分布和本题专项结果的业务影响，给出引用记录/字段的优先治理建议，不将未知原因写成已证实原因。缺失、不适用、明确空值、确认零及实际读取失败不同；如果读取未完成，列明文件、sheet、影响范围及结论限制。所有表可复算，报告实际核对跨sheet覆盖、对象关联、字段合并、关系完整性、质量结论的结果和依据；工具或方法不限，不要求另交脚本。源资料只读。

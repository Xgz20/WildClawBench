## 反馈分歧与条件
- 通知：支持，前提为仅临近截止。有效反馈记录12条；例如 反馈0001 / 开放反馈.xlsx|首批反馈|2：试用后能记住临近截止的任务了，希望保留提醒，但没到截止不要每天催。
- 通知：反对，前提为专注工作时。有效反馈记录12条；例如 反馈0008 / 开放反馈.xlsx|首批反馈|9：试用期间弹窗打断了专注工作，即使任务完成得快了，也不代表我喜欢提醒。
- 导出：支持，前提为交接给外部伙伴。有效反馈记录11条；例如 反馈0009 / 开放反馈.xlsx|首批反馈|10：和外部伙伴交接时需要导出，不是因为团队内部协作功能不好。
- 导出：反对，前提为文档仍在迭代。有效反馈记录14条；例如 反馈0001 / 开放反馈.xlsx|首批反馈|2：文档还在改的时候不应反复导出离线版本，否则不知道哪份是新的。
- 权限：支持，前提为跨团队且有到期日。有效反馈记录12条；例如 反馈0005 / 开放反馈.xlsx|首批反馈|6：跨团队试用愿意开放共享，但应设置到期日，项目结束自动撤回。
- 权限：反对，前提为成员固定的小团队。有效反馈记录13条；例如 反馈0006 / 开放反馈.xlsx|首批反馈|7：固定小团队反复申请权限没有收益，减少授权步骤对我们更重要。

## 限制与验收
小样本按各指标实际有效人数识别；第三人群目标仅12人，不能推广为总体。拒答、漏答、不适用、确认零分分开计数，见样本缺口。各题分母不同。没有文本不等于没有意见，不以主题行数推断支持率。非随机调查不证明因果。
作者参考：从导出的工作簿重新读取所有响应区块，独立复核源行集合、题号映射、分母及各专项公式；结果见出题工具作者验证。此说明不代表被测Agent实际验收。
比较失访者首期均值与配对首期均值可判断选择偏差的可能方向；即使均值接近也不能排除未观测差异。配对变化只代表有效配对者，不覆盖失访者。

## 2. 计算与判定口径


1. 本题是2026-09模拟省级项目接入合同，不代表现行国标。原query中的GB2CDM仅作项目接口代号；OCPP与Modbus本身不定义本题所有费用字段，所列费用为运营商私有扩展。所有本月完成订单及分时记录有效，无退款场景。每订单ID唯一，跨表按订单ID连接，不能按文件行号连接。

2. 监管输出电量单位kWh，费用单位人民币元。OCPP meterStart_Wh/meterStop_Wh为累计Wh，差/1000；vendor三种费用均为分，除100。云快充energy_001kWh每单位0.01kWh，除100，三个费用字段已是元。Modbus start/end为16位无符号累计寄存器，每单位0.01kWh；reset_flag=0且本次差量不超过一圈时用模65536差/100；reset_flag=1表示重置时点缺证，电量未知。

3. OCPP交易号transactionId、云快充orderNo、Modbus register_order均映射订单编号。电量、电费、服务费、总费用都是必填字段，未知不意味着填0；未知电量需标不满足接入完整性。映射草稿包含历史错误，须按当前项目口径修正。映射至少包含监管字段、来源协议、原字段名/报文位置、转换规则、单位、是否必填、对账核对说明，允许等价公式表达。

4. 分时计量以片段ID唯一，每片段电量Wh/1000，按运营商+时段关联费率。分时电费、服务费均逐片段计算并四舍五入到分，再汇总订单。分时完整=否时，应计费和分时电量未知，不将部分和当全量。费用差=上报总费用-上报电费-上报服务费；计费差=上报电费-应计电费；计量差=订单电量-完整分时电量。绝对差>0.01才为差异；因缺资料无法计算为待确认。

5. 逐运营商汇总订单数、确认电量、上报电费、服务费、总费用、三种差异订单数、待确认订单数。报告应指出映射草稿中的具体错误及对账影响，不能用费用闭合反推未知电量。


## 3. 结果工作簿


将完整结果保存为 `/tmp_workspace/results/充电订单映射与对账.xlsx`。下列sheet与表头作为复核接口；允许增加字段、说明或图表，行列顺序不影响验收。可用数值或带有效缓存的公式，数值显示精度不能改变底层含义。


- **订单明细**：订单ID、运营商、来源协议、电量、电费、服务费、总费用、分时电量、应计电费、应计服务费、计量差、计费差、费用差、状态、来源。

- **运营商汇总**：运营商、订单数、确认电量、电费、服务费、总费用、计量差异数、计费差异数、费用差异数、待确认数。

- **字段映射**：监管字段、来源协议、原字段位置、转换规则、单位、是否必填、对账核对说明。


缺失数值留空或明确标“未知”，不得以0代替。来源使用“文件名|sheet名|A起始行:末列结束行”，多个实际来源以分号分隔，顺序不限。来源应指向输入中的真实行；分析明细可追加复核所需字段。数值容差：人民币金额0.01元，其余指标1e-5（记录数、ID及状态须精确）；统计结果建议保留6位有效数字。若自选统计表达或复杂公式无法自动提取，应保留可读数值供复核，评测提取故障不等于业务错误。

**核对记录**：核对项目、核对范围、核对方法、核对结果、证据位置。

分钟为整数；人日为人数与日期组合的计数；月份写为“2026年8月”“2026年9月”或等价可识别日期。占比按0至1数值保存，至少保留四位小数，分母为零写“不适用”。“已确认日均班内分钟”可保留两位小数。日期时间必须可识别，分钟和人日不能混用小时单位。

每日明细的“排班版本”用于说明最终采用哪份排班：没有生效调班时填所采用部门月表B2中的数字1；有生效调班时填最终采用的中文申请编号；任职范围外填“不适用”。

出勤状态使用“已确认”“确认零工时”“休息日”“待核实”“不适用”。审批状态为“待审批”“已批准”“已驳回”“已撤销”，不生效申请也保留最新状态；封账前没有流水时最新版本为0，表示尚无已记录版本，状态“待审批”。生效判定用“生效”“不生效”“被后续调班替代”。来源索引处理结果使用“在范围内”“任职外”“期间外”“重复导出”“历史状态”“截止后记录”“未知员工”。来源位置按“文件名#工作表名!单元格”或“文件名#工作表名!行号”表示；等价、可直接回查的定位方式也可以。多个来源的排列顺序不限。

每日明细以员工编号和归属日期为唯一组合；员工月表以月份和员工编号为唯一组合，部门月表以月份和部门为唯一组合。审批每份申请一条，来源索引每个原始位置一条，异常按员工编号、归属日期和异常类别合并。来源索引对排班保留每个人员日期的班次单元格，人员、任职、班次定义及其他数据均保留每个业务物理行，重复导出也要注明。人员、任职、班次定义的归属日期留空，班次定义的员工编号也留空。未知员工仅列来源和异常，不扩充每日明细人员范围。

来源索引的“业务编号”沿用原记录的稳定编号：人员用员工编号，部门任职用任职记录编号，打卡、申请、审批分别用打卡编号、申请编号、审批流水编号；班次定义用班次名称；排班用员工编号和归属日期的组合，分隔符不限。“记录类型”使用对应的中文业务名称，也可使用明确的中文同义名称。

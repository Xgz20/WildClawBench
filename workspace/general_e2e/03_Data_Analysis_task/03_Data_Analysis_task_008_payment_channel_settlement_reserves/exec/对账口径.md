# 渠道结算月结口径

## 1. 业务范围与资料
本公司为模拟商户。请核对2026-09-01至2026-09-30的内部交易，银行观察截止2026-10-05（含当日）。三个商户账户为商户甲、商户乙、商户丙；渠道为云付、海桥；CNY与USD分别对账，不进行汇率折算。本题所有费率和业务规则均为模拟约定，不需要查外部财税法规。
- `内部交易流水.xlsx`：商户甲、商户乙、商户丙。
- `渠道结算单.xlsx`：云付、海桥、云付批次、海桥批次。
- `银行到账记录.xlsx`：商户甲、商户乙、商户丙。
- `费用与币种表.xlsx`：云付期初、海桥期初、云付、海桥。
所有列出的工作表及币种区块均需处理；表头位置、列序不同，标题和区块标题合并，区块中有重复表头、小计、页尾说明。按业务编号识别明细，不把标题、小计当作记录。文件中的数字文本和数值等价，金额单位均为原币元。期间外交易、非本期银行记录与观察期外到账保留排除来源，不并入本期结果。实际读取未完成须列出文件、表、区块及影响；不能把未读取范围写为零。

## 2. 去重、关联与未知
内部流水号、结算明细号、银行流水号分别为唯一业务键；相同键且其他业务字段完全相同的是重复导出，只计一次，所有重复位置进入来源索引。批次编号唯一；账户、渠道、币种组成保证金账户。交易及银行日期均为自然日，北京时间。
内部流水与结算只能以结算明细的内部引用关联，并同时核对账户、渠道、币种、批次。一个内部流水可能拆为多个结算明细，汇总后再比较。缺内部引用的结算明细不能按金额猜配，其批次级金额仍可确定并纳入批次核算；对应内部流水未找到引用时记未匹配。
银行以结算引用关联批次，同时账户、渠道、币种一致，入账日期处于批次截止日至其后5个自然日（两端含），且不晚于观察截止。一个批次可多次到账；银行负数为冲回，与正数同样按符号加总。批次引用为空记缺结算引用，归属批次未知；缺引用不得从金额、账户余额或相邻行猜测。历史批次为非本期批次，截止后到账为观察期外。已确认匹配的月末后到账记跨期到账，仍计入观察截止到账。
缺凭证只表示资料不全，不自动否定已知金额或已成立匹配。已取消内部流水保留但金额参与值为0，结算匹配和凭证要求记不适用；成功且金额0的流水是确认零额。未匹配、缺引用的无法确认字段用“未知”或“待确认”，不得填0；不适用可用“不适用”或“N/A”。

## 3. 金额与保证金
各币种均保留2位小数。每笔有效内部净额为交易金额；退款和冲正本身是带符号独立事件，与原交易均保留，不能再把原交易删除一遍。已取消为0。原交易号用于回查业务关系。
云付手续费率0.006、保证金扣留率0.05；海桥分别0.008和0.08。每笔应计手续费=四舍五入(内部净额×手续费率,2)，应扣保证金=四舍五入(内部净额×保证金扣留率,2)；采用十进制ROUND_HALF_UP。退款和冲正的手续费、保证金为负值，表示退回和恢复。拆分的结算行费用先汇总后比较，不能重新按拆分行舍入形成另一套应计数。
批次内部净额、应计手续费、应扣保证金均为逐笔结果之和。实列手续费是结算明细手续费去重求和。手续费差额=实列手续费−应计手续费。批次应结净额=内部净额−应计手续费−应扣保证金+批次保证金释放。申报净结算取批次结算原值；结算差额=申报净结算−应结净额。截至观察日到账=可确定分配给该批的银行带符号金额之和；到账差额=截至观察日到账−申报净结算。已知不足/多收和同账户未分配金额同时展示，不用未分配款强行配平。所有对账差额绝对值≤0.01视为容差内。
保证金从费用与币种表的期初余额起算，按批次截止日递推：应有期末=应有期初+本批应扣保证金−本批释放；下一批应有期初=前批独立算出的应有期末，不接用有差错的申报期末。滚存差额=申报期末−应有期末。释放为批次结算表中已确认的事件值，不能重复从交易中扣一次。
批次状态：有手续费差额或到账差额超容差为待核差异；否则存在跨期到账为跨期已收齐；否则已收齐。保证金差异单列。账户汇总以账户、渠道、币种分组，金额为相关批次之和；未分配到账只合计观察窗内归属未知的银行记录。期初和期末保证金分别取本期初值和末批独立余额，不能累加每批余额。

## 4. 交付及字段
结果为`results/渠道结算对账.xlsx`，包括以下九张业务表；允许行列、表序变化，允许“来源对照”代替“来源索引”、“待补凭证清单”代替“差异及补件”、“交易关联”代替“交易匹配”、“批次汇总”代替“批次对账”。内部流水号/内部交易号、批次编号/结算批次、商户账户/账户、来源定位/源位置可作为同义列名；其他有据等价命名由评测方复核。金额列保持可读取计算值，公式与数值均可，不指定工具或脚本。
- **账户汇总**：商户账户、渠道、币种、批次数、内部净额、应计手续费、应扣保证金、释放保证金、应结净额、已分配到账、未分配到账、跨期到账、期初保证金、期末保证金。
- **批次对账**：批次编号、商户账户、渠道、币种、内部净额、应计手续费、实列手续费、手续费差额、应扣保证金、释放保证金、应结净额、申报净结算、结算差额、截至观察日到账、跨期到账、到账差额、批次状态、来源定位。
- **保证金滚存**：批次编号、商户账户、渠道、币种、应有期初保证金、本批扣留、本批释放、应有期末保证金、申报期末保证金、滚存差额、来源定位。
- **交易匹配**：内部流水号、商户账户、渠道、币种、批次编号、结算明细集合、内部净额、应计手续费、应扣保证金、实列结算金额、匹配状态、凭证状态、来源定位。
- **银行分配**：银行流水号、商户账户、渠道、币种、归属批次、到账金额、期间归属、匹配状态、来源定位。
- **差异及补件**：对象类型、对象编号、问题类型、商户账户、币种、影响金额、待补材料、来源定位。
- **来源索引**：来源定位、记录类型、业务编号、归属批次、处理结果。
- **分析说明**：分析主题、结论、数据依据、范围与限制。
- **核对记录**：核对项目、核对范围、核对方法、核对结果、证据位置。
交易匹配一行一笔本期内部流水；结算明细集合列列出全部确定匹配的明细号，分隔符可用分号、逗号或换行；未匹配填未知，已取消填不适用。批次对账、保证金滚存一行一批；银行分配一行一条去重银行记录，包括需排除的银行记录；账户汇总一行一账户渠道币种组合。
差异及补件逐项列出：缺凭证内部流水、未匹配内部流水、缺内部引用结算明细、缺结算引用/未匹配银行流水，以及超容差的手续费、到账、保证金批次差额。对象类型分别为内部流水、结算明细、银行流水、批次；对象编号为对应业务键；同一对象可有多类问题，键为对象类型+对象编号+问题类型。影响金额取该对象已知的内部净额/结算金额/银行金额或带符号差额，不能把其全部写为确定损失。补件建议允许合理等价表述。
来源索引包含每一条原始业务明细的每个位置（含重复、期间外、取消及参数记录），记录类型采用内部流水/结算明细/批次结算/银行流水/期初保证金/费用币种；期初业务编号为账户|渠道|币种，费用币种业务编号为渠道。归属批次取原始批次/结算引用，空引用为未知，参数为不适用。处理结果记录纳入、重复导出、期间外、已取消、缺内部引用或对应银行匹配状态。按文件本身展示顺序首次位置为主记录，其余同键位置为重复。源定位应含文件、sheet、行号或单元格，例如`内部交易流水.xlsx|商户甲|6`；允许`内部交易流水.xlsx#商户甲!A6`等价形式、多位置顺序不限。
交易匹配来源包括全部内部导出位置和确定匹配结算位置；银行分配包括全部银行导出位置及确定关联的批次结算位置；保证金滚存包括账户期初和本批结算位置；批次对账可通过来源索引的归属批次回查完整内部及结算明细，保留批次结算位置；差异保留对象位置。真实且相关的补充来源可保留，错误对象位置不能充当佐证。

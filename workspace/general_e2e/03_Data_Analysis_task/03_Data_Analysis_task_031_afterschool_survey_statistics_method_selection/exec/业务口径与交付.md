## 2. 计算与判定口径


1. 覆盖A/B两版本、SC0—SC5全部学校和全部响应区块。以受访者ID取截止2026-09-30的最新提交；作答ID相同为重复导出。两版本服务质量1—4是同义题，可合并；第4题为反向题，以6-原值转换。课程内容、场地是不同单项判断，跨版本不能擅自合并为一个构念。

2. 参加服务为单选事实题，0=未参加、1=参加，0是有效值。需求为多选题，分号分隔，单人同选项只计一次，“无”是有效零选择，拒答为缺失。李克特有效值仅1—5，空白=漏答、拒答、不适用分别保留；未参加者满意度应不适用，不纳入满意度分母。

3. 描述表按学校和统一题号给出未加权有效n、加权有效分母、频数/百分比、均值。权重按学校表；李克特频数逐1—5，事实题逐0/1，多选逐体育/艺术/科学/托管（分母为有效回答人数，不是选项总数，百分比可合计超过100%）。均值仅事实0/1及李克特；多选均值留空。所有比例存0—1，保留至少6位有效数字。

4. 本轮方法选型约定：只有同构念且至少3道可比李克特题的题组可考虑量表分析。服务质量4题采用完整个案，反向转换后计算Cronbach alpha、KMO和Bartlett；每学校及全体分别判断，完整个案n至少max(200,10×题数)，各题非零方差且相关矩阵可逆才计算。其他题组或样本不足仅描述统计。该阈值是本项目分析方案，不是普遍充分效度标准。

5. 量表诊断使用未加权完整个案Pearson相关矩阵R：alpha=k/(k-1)×(1-各题样本方差和/总分样本方差)；KMO=非对角相关平方和/(相关平方和+偏相关平方和)，偏相关由R逆矩阵计算；Bartlett卡方=-(n-1-(2k+5)/6)ln(det R)，自由度k(k-1)/2。KMO>=0.6且Bartlett p<0.05时只写“可进一步探索结构”，不能宣称已证实构念效度。

6. 报告比较题组适用路线、学校均值和有效分母，保留SC5小样本限制。归纳反馈须保留支持、反对与附条件意见及反馈ID证据，不能只累计赞成意见。交付前核对跨sheet覆盖、题目映射、分母和主题依据，并在报告记录核对对象、结果及未验证范围，接受人工或程序等价方法。


## 3. 结果工作簿


将完整结果保存为 `/tmp_workspace/results/课后服务问卷分析.xlsx`。下列sheet与表头作为复核接口；允许增加字段、说明或图表，行列顺序不影响验收。可用数值或带有效缓存的公式，数值显示精度不能改变底层含义。


- **题组分类**：题组、题型、统计路线。

- **描述统计**：学校、题目、选项、有效n、加权分母、频数、加权频数、百分比、均值。

- **量表前提与诊断**：人群、题组、完整n、题数、alpha、KMO、Bartlett卡方、自由度、p、路线。

- **缺失分母**：学校、题目、有效、漏答、拒答、不适用。

- **标准作答**：受访者ID、作答ID、学校、统一题号、值、状态、来源。


缺失数值留空或明确标“未知”，不得以0代替。来源使用“文件名|sheet名|A起始行:末列结束行”，多个实际来源以分号分隔，顺序不限。来源应指向输入中的真实行；分析明细可追加复核所需字段。数值容差：人民币金额0.01元，其余指标1e-5（记录数、ID及状态须精确）；统计结果建议保留6位有效数字。若自选统计表达或复杂公式无法自动提取，应保留可读数值供复核，评测提取故障不等于业务错误。

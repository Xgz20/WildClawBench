服务质量四题支持按完整个案作一致性及结构适用性诊断。alpha不证明单维，KMO和Bartlett不证明构念效度。课程内容和场地是异质单项，保留版本分别描述；事实题和多选题不与满意度题混算alpha。SC5仅12名回收对象，推断与学校排序须谨慎。


多选分母为有效回答人数，选择“无”进入分母且四选项计数0；未参加服务的满意度为不适用，拒答与漏答分列，不补0。学校加权均值使用公开权重；同一学校权重相同，加权与未加权均值相等不代表跨校权重无效。

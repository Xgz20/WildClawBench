## 缺测估计与留出验证
使用公开50公里、前后3天邻域的局部时空加权回归。自变量为相对坐标和日差，权重为1/(1+距离平方+4×日差平方)。不使用任何填补值训练，样本数不足8或设计矩阵秩不足4时保留未知。固定种子779一次抽取120个实测日点，全部留出后重新预测；该检验考查短期内插，不能证明长缺口外推有效。

## 2. 计算与判定口径


1. 研究期为2024-04-01至2026-09-30，共913个自然日。所有监测sheet及补录区块均有效。共同采样是同一比对样本送三实验室，站点日常观测不是同一地点，ICC只能使用共同采样。坐标为本项目统一平面坐标（公里），不是经纬度。

2. 各实验室时间按站点表转为UTC+08:00，按当地自然日聚合。PM2.5、PM10、O3、NO2、SO2为微克/立方米，CO为毫克/立方米。每个实验室每指标，以全部共同采样拟合“原读数=截距+斜率×参考值”；校准值=(原值-截距)/斜率，保留系数至少6位。

3. 检修窗口为开始包含、结束不含。窗口内读数或原值小于0、超过PM2.5/PM10/O3/NO2/SO2/CO上限500/700/350/250/150/15的读数为异常。空值为缺测，不计异常。原始完整率=非空数/计划采样数，异常率=异常数/非空数。日内有效数达到计划数75%（向上取整）才输出观测日均；未达到则该日原始日均未知。不得以已收到行数充当计划数。

4. 对缺测日均，可选Kriging或时空加权回归。可用邻域为同指标、目标日前后3天（含边界）、50公里以内的有效观测日均；至少8条，空间时间设计矩阵[1,东向坐标,北向坐标,相对日]秩为4才允许估计。填补值不得再作训练数据。其他缺口保持未知，填写状态与样本数。必须交代方法、参数、验证误差和估计限制。参考路线使用距离权重1/(1+距离平方+4×日差平方)的局部线性回归；其他可解释且经留出验证的方法允许。 估计值须为有限非负数，且不超过对应指标的质量上限；不得以无穷大或无依据的值替代缺测。

5. 质量表逐实验室和指标统计计划数、非空数、异常数、有效观测日数、可估计日数和仍缺失日数。ICC采用共同采样的双向随机单次绝对一致ICC(2,1)，报告校准前后系数、样本量与定义。原数据日均与填补值必须可区分。指标统计保留至少6位有效数字。


## 3. 结果工作簿


将完整结果保存为 `/tmp_workspace/results/污染物质量分析.xlsx`。下列sheet与表头作为复核接口；允许增加字段、说明或图表，行列顺序不影响验收。可用数值或带有效缓存的公式，数值显示精度不能改变底层含义。


- **质量汇总**：实验室、指标、计划数、非空数、异常数、原始完整率、异常率、实测日数、估计日数、未知日数。

- **校准系数**：实验室、指标、截距、斜率、样本数。

- **实验室一致性**：指标、阶段、样本数、实验室数、ICC。

- **日均数据**：实验室、指标、日期、有效采样数、计划采样数、观测日均、最终日均、状态、邻域样本数、来源。最终日均允许不同合格插补方法产生合理差异；实测日均和所有状态、邻域与覆盖计数固定。未知数值留空。来源可用分号分隔位置集合。


缺失数值留空或明确标“未知”，不得以0代替。来源使用“文件名|sheet名|A起始行:末列结束行”，多个实际来源以分号分隔，顺序不限。来源应指向输入中的真实行；分析明细可追加复核所需字段。数值容差：人民币金额0.01元，其余指标1e-5（记录数、ID及状态须精确）；统计结果建议保留6位有效数字。若自选统计表达或复杂公式无法自动提取，应保留可读数值供复核，评测提取故障不等于业务错误。

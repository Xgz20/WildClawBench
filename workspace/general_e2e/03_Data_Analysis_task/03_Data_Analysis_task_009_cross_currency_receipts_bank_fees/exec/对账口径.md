# 跨币种回款月结口径

本包为远航出口公司的内部对账。只采用本文件和配套表内参数，不使用实际市场汇率、现实税法或外部费率。

## 1. 范围与原始结构

业务月：2026-09（2026-09-01至2026-09-30，含边界）；全部应收、内部收款、支付结算和批次均在此业务月。银行观察期为2026-09-01至2026-10-05（含边界，日期按本地自然日），观察期外回单保留排除去向，不计入任何到账。三个账户均纳入，参数见账户范围表。全部下列sheet均应读取，不能只读取第一张表或第一段币种。

- 《内部应收与收款.xlsx》：应收_华东、应收_华南、收款_远帆结算、收款_海桥支付。
- 《支付结算与批次.xlsx》：海桥支付_上半月、海桥支付_下半月、远帆结算_上半月、远帆结算_下半月、批次_海桥支付、批次_远帆结算。
- 《费用币种与锁汇.xlsx》：锁汇凭证、币种精度、渠道费率、账户范围。
- 《银行到账记录.xlsx》：华东人民币户、华东美元户、华南人民币户。

每张原始业务表含合并期间标题、多币种区块、位置不同的字段标题、列顺序不同、重复字段标题及区块小计。带本表稳定业务编号的行为有效明细；标题、小计、说明与空行不是业务记录。币种字段逐行有效，不依赖区块标题推断。原始材料保持不变，另存结果。所有金额单位为对应币种元，JPY没有小数，其他币种为两位小数。缺失单号/凭证为真实缺失；不要从相邻行或金额猜填。费率和锁汇价小数保留原精度。

## 2. 记录、去重与允许关联

同一对象类型按其稳定编号（应收单号、收款流水号、结算行号、批次号、锁汇编号、银行流水号）去重。重复导出各字段完全相同，只计一次，但所有原始出现位置均进入来源索引。无版本择新规则。本包不存在同一编号内容冲突。

内部收款通过明确应收单号关联应收；结算通过明确收款流水号且渠道、原币、带符号金额一致关联内部收款；结算行按批次号归批。一笔应收可以多次回款，一批可含多个结算行。缺引用时唯一允许集合为空，不能按金额、相邻行、客户名或序号规律补配。应收已关联回款仅计公开应收引用可确认的内部流水，不受结算引用是否缺失影响；待收=应收原币−已关联回款，未关联回款不代表证明客户未付款。

银行通过明确结算引用=批次号，且收款账户、目标币相同，入账日期位于[结算日期,结算日期+5个自然日]并处于银行观察期内，归入该批次。可一对多；银行未给结算引用的行不能归入任何批次，即使金额碰巧相同。记录所带原流水/原结算行只解释冲正关系，不作为补填缺失关联引用的替代键。

冲正是单独有编号的带负号流水，应与原记录一起相加，不能删除原记录再重复扣减。重入账按自己的金额和编号计入。全部有效金额的正负号已给定。缺引用收款、结算和银行分别保留，不将未匹配金额强塞其他组。

## 3. 费用、换汇与差额

采用十进制ROUND_HALF_UP：恰好半个最小单位时向远离零方向舍入。每条结算行的原币费用=按原币精度舍入(带符号结算原币×渠道费率)；原币净额=结算原币−原币费用。冲正费用保持同号。不能在整批原币收款合计上才计算一次费用。

批次原币收款、费用和净额均为所属结算行的相应值之和。锁汇按批次明确锁汇编号取凭证，要求原币、目标币和有效日期分别与批次一致。本包锁汇引用不会指向不一致凭证，但若凭证整行缺失，汇率和所有依赖的换汇金额为未知，禁止使用银行到账反推汇率。

- 逐笔换汇：每行原币净额×锁汇价，按目标币精度舍入；批次换汇毛额为逐笔换汇金额之和。
- 批次换汇：原币净额先合计后×锁汇价，仅最后按目标币精度舍入；逐笔换汇金额为不适用，不能随意分摊。
- 原币直收：原币=目标币，换汇毛额=原币净额；锁汇编号、锁汇价、锁汇来源及逐笔换汇金额均为不适用。

固定银行费已经用目标币给出，仅在每批换汇毛额之后扣一次；应到账金额=换汇毛额−固定银行费。已到账为允许关联的银行流水带符号合计。本期到账仅计入账日≤2026-09-30，跨期到账计2026-09-30后且观察期内，二者之和=已到账。差额=已到账−应到账。精度处理之后差额容差为0，不将一分差额视作自动通过。

状态依优先顺序：缺锁汇凭证→确认零额（应到账和已到账均0）→未匹配到账（无允许银行记录且非零）→金额差异（差额非0）→跨期到账（差额0且跨期到账非0）→已对平。确认零额使用数值0；未知使用“未知”（或空值并明确同条影响说明）；不适用使用“不适用”。无匹配銀行行时已到账=0是已确认允许集合为空，不代表无任何银行入账。若读取失败，保留受影响文件/sheet/区块与无法确认的字段，不能把失败当作业务零。

## 4. 交付内容

将工作簿交到 `/tmp_workspace/results/跨币种回款对账.xlsx`，包含以下逻辑表和字段。允许行列、sheet顺序变化及无歧义的同义标题；可以增加辅助内容。分析和验收也可在同一工作簿中另设表。集合字段为集合，顺序无关，用分号、换行或JSON数组均可。数值可为可计算公式或数值；不要仅提交公式文本或截图。来源保留所有业务依据的文件、sheet和行号（或单元格区间），允许引用来源索引；推荐 `文件名|sheet|行号`，多位置分号分隔。没有相关记录的来源/编号集合填“不适用”，本来应有但缺失填“缺失”。

- **批次对账**（唯一键：批次号）：批次号、结算日期、渠道、收款账户、原币、目标币、换汇方式、锁汇编号、锁汇价、原币收款合计、原币费用合计、原币净额、换汇毛额、固定银行费、应到账金额、已到账金额、本期到账金额、跨期到账金额、差额、对账状态、结算行号集合、银行流水号集合、批次来源、结算来源、锁汇来源、银行来源。
- **结算明细**（唯一键：结算行号）：结算行号、收款流水号、应收单号、批次号、原币、目标币、结算原币、原币费用、原币净额、逐笔换汇金额、匹配状态、收款来源、结算来源。
- **应收核销**（唯一键：应收单号）：应收单号、原币、应收原币、已关联回款、待收原币、回款状态、收款流水号集合、应收来源、收款来源。
- **待补凭证**（唯一键：事项编号）：事项编号、对象类别、对象编号、问题类型、需补材料、影响范围、来源。
- **分类汇总**（唯一键：汇总键）：汇总键、收款账户、原币、目标币、对账状态、批次数、原币收款合计、原币费用合计、已确认应到账、未知批次数、已到账金额、已确认差额。
- **来源索引**（唯一键：来源）：来源、对象类别、记录编号、处理状态、关联对象。
- **分析说明**（唯一键：问题）：问题、结论、证据位置。
- **验收记录**（唯一键：核对对象）：核对对象、核对范围、核对方法、发现与限制、证据位置。

批次对账包含全部批次；结算明细包含全部去重结算行，收款流水号/应收单号不可确认写未知，匹配状态为已匹配、缺收款引用、缺应收引用。应收核销包含全部应收，回款状态为已结清（待收0）、部分回款（已关联回款>0且未结清）、尚未回款（已关联回款0）。

待补凭证列出：缺收款引用的结算行、缺应收引用的内部收款、未关联结算的内部收款、缺结算引用/引用不合规的银行行、缺锁汇凭证批次及非零未匹配到账批次；事项编号可用“对象类别:对象编号:问题类型”，同一对象多项问题分行。需补材料与影响范围可用等价业务文字，不能编造缺凭证的原因。

分类汇总按收款账户+原币+目标币+对账状态分组，汇总键用四项以“|”连接；未出现组合不用造行。已确认应到账、已确认差额只合计可确定数字，未知批次数单列；原币列与目标币列分别合计，不能跨币种给总金额。费用拆分、来源明细和汇总金额保持守恒。

来源索引一行对应一处有效原始业务记录（包括重复导出、期间外）；对象类别为应收、收款、结算、批次、锁汇、银行，静态币种/渠道/账户参数无需逐格列入。处理状态为保留、重复导出或期间外。同编号任一重复出现可作为保留，其余重复导出；期间外优先。关联对象：有批次号的用批次号，否则有应收单号的用应收单号，不能确认写未知；银行原始引用为辅助说明，不要求填成此列。额外真实来源不扣分，错误或无关位置不作有效证据。

分析说明回答四件事：按账户和币种比较差异类别及批次数，给可复查数字；解释逐笔/批次换汇舍入和两种币种费用的区别；区分跨期与金额差异并保留未知原因；按影响范围提出补证优先级。验收记录保留实际核对的对象、范围、方法、发现和证据位置，覆盖跨sheet范围、允许关联、金额守恒、差异及分析限制。少量抽样须明确样本范围，不宣称全量通过。

## 2. 计算与判定口径


1. 盘点时点2026-05-31，需求为2026年汛前责任区配置。32个储备点、12个街道、84种物资、6大类均需覆盖；所有片区及补录批次有效。基础单位件；箱按物资标准换算。包没有可靠换算资料，保留未知并列出受影响储备点及物资。不能把不同物资数量相加当作可互换库存。

2. 盘点行ID相同且字段一致为重复导出，只计一次并保留全部源位置。理论需求=该风险等级每网格标准×责任网格数。已确认实存按所有可换算批次加总；可用量仅计状态完好且有效期不早于盘点日。未知单位只进入缺口清单，不纳入确认量。含未知批次的满足率是确认下界，不作确定缺口判定。

3. 满足率=可用量/理论需求。范围为[0,0.8)缺口严重、[0.8,1)基本满足需补充、[1,1.2]满足、(1.2,+∞)超量可调拨轮换；含未知批次标“待确认”。无批次且盘点已覆盖的物资为确认零储备。缺口=max(需求-可用,0)，仅在无未知批次时确认。

4. 各类分布按储备点、类别汇总确认件数及确认采购参考价值（数量×参考单价），完好率=完好确认件数/全部确认件数，报废率=报废确认件数/全部确认件数。不得将比例直接平均。分别统计类别和供应商的上述分子分母。临期为盘点日到有效期剩余0至90天；已过期另列。

5. 报告对高风险核心物资短缺给出优先补库或调拨建议。调拨须同物资、仅用完好未过期批次，调出后不能低于调出点需求；库存未知的点不得作为已确认可供点。临期品优先提出高频点轮换；可提出采购补缺，不要求唯一最优调拨路线。


## 3. 结果工作簿


将完整结果保存为 `/tmp_workspace/results/防汛储备分析.xlsx`。下列sheet与表头作为复核接口；允许增加字段、说明或图表，行列顺序不影响验收。可用数值或带有效缓存的公式，数值显示精度不能改变底层含义。


- **需求与缺口**：储备点、物资编码、风险等级、核心物资、理论需求、确认可用量、满足率、未知批次数、储备判定、确认缺口。

- **批次清单**：盘点行ID、储备点、物资编码、类别、供应商、采购批次、状态、确认件数、可用件数、剩余天数、临期状态、来源。

- **储备分布**：储备点、类别、确认件数、确认可用件数、参考价值、未知批次数。

- **状态评估**：维度、对象、确认件数、完好件数、报废件数、完好率、报废率。


缺失数值留空或明确标“未知”，不得以0代替。来源使用“文件名|sheet名|A起始行:末列结束行”，多个实际来源以分号分隔，顺序不限。来源应指向输入中的真实行；分析明细可追加复核所需字段。数值容差：人民币金额0.01元，其余指标1e-5（记录数、ID及状态须精确）；统计结果建议保留6位有效数字。若自选统计表达或复杂公式无法自动提取，应保留可读数值供复核，评测提取故障不等于业务错误。

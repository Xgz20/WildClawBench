# Info004 稳定材料版参考与判分说明（2026-11-04.1）

本参考仅对应公开材料包，不是候选已读记录。允许不同措辞、合理意译及有材料依据的不同分析。
不要求联网、论文全文、原刊影印或纸本页码，不能把网页访问失败当模型错误。

## 一种可接受的分析路径

M1把个性与精神的成长放在国家自觉的重要位置，并在选择外来思想和文化资源时强调判断与融汇；
M2关注能发出精神声音的人及其遭遇群体压制的处境。两者可以构成早期对人的精神状态与表达力量的关切，
不能改写成拒绝全部外来文明，也不能保证先觉者立刻被接受。[M1#p1][M1#p2][M2#p1]

M3回应使人退缩的冷笑与成败压力，肯定有限而可持续的行动；M4由叙述者自己的经验进入对人的处境的反思。
可比较早期精神战士与后期普通青年、日常经验之间的实践重心变化，也可讨论其价值关切的延续；
给定片段不足以裁定作者终身全部思想变化，不能将语用上的我们直接扩写成民族生物本质。[M3#p1][M3#p2][M4#p1][M4#p2]

M5是1922年写下、收入1923年文集的后出回忆。它把弃医、国民精神和文艺相连，
能与同期文章相互参照，但不能充当当年事件的独立现场记录或排除所有其他因素的唯一因果证明。
本包未提供该事件的具体年/月，不强迫反推。[M5#p1][M5#p2]

R1提供一个跨期价值轴；R2讨论个体建设与文化建设的关系。两项短摘录的侧重点不同，可以互补，
不能据此宣称作者的整篇论文已经被读完或两位作者存在直接论战。[R1#p1][R2#p1]

## 两项研究核验（沿用现有协议）

C13保留两个固定研究单元：单元1对应R1，单元2对应R2，各占2分。
每个单元明确核对作者/作品和观点/范围两项细节，两者均满足才通过。
同一单元可记录多条不同claim_id，现有supported/contradicted/evaluator_reference_unavailable规则不变。
一个研究的错误不牵连另一研究；转述准确不要求同意作者的史学判断。

两个单元均可判定时，C13取通过数/2；任何真实评测缺证继续null，不补零或删项重归一。
正常可读包已提供必评内容，不因未访问论文全文或外部网页而判定给定片段不可核定。
外部附注不能替代本包对象、扩大分母或用额外正确研究抵消错误。

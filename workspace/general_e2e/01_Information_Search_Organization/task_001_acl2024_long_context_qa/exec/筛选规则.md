# 筛选规则

- **论文范围**：ACL 2024 主会长论文，重要贡献包含用于长上下文或长文档理解评测的新基准／数据集。“长”按正式论文的研究目标和任务定义判断，不设统一 token 门槛，预印本年份不限。排除 Findings、短论文、Workshop、仅使用已有基准评价新方法或仅生成长答案的工作。
- **问答范围**：依据文档文本作答，包括表格、计算、选择、判断及基于外部文档的对话问答，允许自然语言事实扩写和干扰文档。排除原论文归为摘要／Summarization 的任务（含问题引导摘要）、纯填空／角色名补全、代码、键值／字符串检索、仅返回段落位置或检索排名的任务，以及仅依赖对话历史的记忆任务。同一基准中符合定义的短输入对照任务也纳入。
- **文档单位**：单／多文档优先采用论文定义；未定义时，看一个问题是否必须联合多份原始文档作答，干扰文档不计。一本书／报告的多章节不自动算多文档，多份文档拼成一个输入也不自动算单文档。同时包含单、多文档任务归“兼有”；原文无法确定归“未明确”。

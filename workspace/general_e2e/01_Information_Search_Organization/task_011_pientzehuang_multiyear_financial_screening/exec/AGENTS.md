# 任务上下文

- 历史基准日为2025年4月30日，仅使用截至该日已公开的资料。指数身份按当日有效的沪深300样本核验；上市年限按同一A股主体首次上市日至基准日计算，“超过10年”为严格大于。
- 财务数据采用合并报表。归母净利润为归属于上市公司股东的净利润，非扣非；加权ROE为年报披露的非扣非加权平均净资产收益率。
- 每年使用该年度正式年报的当期数；该报告自身如在基准日前发布更正版，采用更正版。同比采用同份报告的可比上年列。后续年报对以前年度的重述不回填以前年度的主表，但须用于后续年度同比的可比基数。说明实际版本差异。
- 自由现金流为经营活动产生的现金流量净额减“购建固定资产、无形资产和其他长期资产支付的现金”；年末资产负债率为年末合并总负债除以总资产。各项阈值均按未舍入数值严格比较。
- 四家公司均须核验2020—2024年全部五项指标，列出数值和判定。发现某项不达标后仍须完成其余项目，列出全部不达标项并给出可定位的官方或一手依据。可合并相同来源和连续年度，接受合理单位换算。明确标注未核实事项。直接回答，无需生成文件。
- 临时下载和自行生成的证据存放当前工作区内；不要读取其他任务工作区、其他模型回答或私有参考答案。工具内部管理的缓存不受此目录约束。

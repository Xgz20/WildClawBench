# 瑞信AT1减记与跨地区监管口径核验：参考答案

本文件仅在执行结束后提供给裁判。事实范围固定为截至2023年3月23日的官方公告，不判断减记最终法律效力，不使用后续诉讼或收购完成日估值替换当时信息。

## 核心答案

| 对象 | 核心答案 | 来源与定位 |
|---|---|---|
| FINMA公布的合同依据 | FINMA援引债券发行文件/合同。合同约定发生Viability Event时全额减记，特别包括获得特殊政府支持。FINMA认为瑞信于2023年3月19日获得由联邦违约担保支持的特殊流动性援助贷款，满足该条件。 | S1，Contractual basis；PDF第1页 |
| FINMA公布的另一项依据 | 3月19日的联邦紧急条例授权FINMA命令借款银行及金融集团减记AT1资本。FINMA称其基于合同与紧急条例发出减记指令。 | S1，Federal Council’s Emergency Ordinance；PDF第1页 |
| 本次AT1与Tier 2处理 | 瑞信AT1票面本金全额减记，Tier 2债券不减记。 | S1，引言第2段；PDF第1页 |
| 股东收购对价 | 全股票交易：每22.48股瑞信股票换1股UBS股票。3月19日公告列示等值为每股0.76瑞士法郎，总对价30亿瑞士法郎。股东不是获得同额现金。截止日交易尚未完成，应表述为公告约定的对价。 | S2，Under the terms of the all-share transaction开头段；公告PDF第1页末段 |
| 欧盟损失承担顺序 | 普通股资本工具先吸收损失；用尽后才要求AT1减记。声明说明欧盟银行处置框架，未在该段完整排列Tier 2。 | S3，正文第2—3段 |
| 英国损失承担顺序 | 在银行处置或破产情形中，优先受偿顺序为Tier 2>AT1>CET1；相应损失承担顺序为CET1→AT1→Tier 2。 | S4，Statement第1—2段 |

瑞信此次减记涉及FINMA认定的特殊支持触发及紧急条例；欧盟、英国说明各自框架。不得因此把瑞士所有债权清偿顺序一概说成劣后于普通股，也不得把FINMA当时陈述写成最终司法结论。

## 同义答案与边界

- Viability Event译作“生存能力事件”“不可持续经营事件”等不影响得分，须正确关联公告所说的特殊政府支持。
- “全部减记”“本金归零”“票面本金全额减记”视为等价；“转股”不是本次AT1处理的等价表达。
- Tier 2、T2、二级资本债接受，不能混同AT1、CET1或普通股。
- 每股瑞信对应1/22.48股UBS与22.48比1换股等价。写倒数时绝对误差不超过0.000001。
- 30亿瑞郎、CHF3 billion、CHF3,000 million等价。可以标“约30亿瑞郎”。0.76瑞郎为公告列示等值，不是承诺现金支付。
- 单独漏写公告等值或总对价按股东对价项部分分处理，不因为不是唯一措辞判错。
- 不要求补充所有AT1债券ISIN、票息、减记总额、法律条款号或后续判决。这些不属于Prompt必答内容。
- 可以说明后续问题不在截止日范围内；额外讨论只有反过来替代或歪曲截止日答案时才影响对应项。
- 来源可采用另一个已核实的一手等价入口；裁判应验证其机构、文件日期、具体段落与相同事实，不因未在S1至S4 URL清单就判错。网页暂时失效不证明来源伪造，应结合冻结的原始取得记录。

## 核心反例与唯一归因

| 反例 | 主要检查点/错误code | 处理 |
|---|---|---|
| “FINMA因瑞信普通股已全部损失而减记AT1” | finma_basis / finma_basis_inversion | 只扣受影响原子单元；core_accuracy取min(基础档位,0.5)，业务分最高57.5 |
| “瑞信Tier 2也被归零”或“AT1在本次换成普通股” | instrument_treatment / instrument_treatment_inversion | 只扣受影响原子单元；同一核心档位限制只应用一次 |
| “瑞信股东每股收到现金0.76瑞郎” | shareholder_consideration / cash_consideration | A交易形式单元失败；金额已正确的单元不重复失分；不把相同错误再次作为来源错误扣分 |
| “每1股瑞信可换22.48股UBS” | shareholder_consideration / cash_consideration | B换股方向单元失败；仅统一限制core_accuracy，不再限制子点 |
| “欧盟规定AT1先损失，之后普通股” | eu_order / eu_order_inversion | 只扣受影响原子单元；不因其引用正确联合声明又扣来源关联 |
| “英国AT1受偿优于CET1，所以AT1先损失” | uk_order / uk_order_inversion | 只扣受影响相邻关系；若候选同时明确列出清偿前提，形成可观察反向推导，内部ability_owner=direct_consistency，整个rule_application取min(基础档位,0.25)；不再在applicable_scope重复记错，业务与能力不相加 |
| “欧盟顺序是普通股先，所以瑞士此次也必须先把股东归零”，或“瑞信这次处理证明所有瑞士债权均劣后于普通股” | jurisdiction_overgeneralization，按被泛化的瑞信事实或被移用的欧盟/英国规则唯一归属finma_basis/eu_order/uk_order之一 | 仅统一限制core_accuracy≤0.5，不另设业务罚分；能力内部归applicable_scope，整个rule_application≤0.25，不又扣direct_consistency |
| 正确列出两类债券处理，但仅用新闻报道支持 | source_binding | 事实项可得分，独立来源义务失分，不用来源等级反推事实错误 |
| 一手来源正确而公告被误读 | 相应事实项 | 不重复扣source_binding；若无独立不实完成声明，不扣verification_calibration |
| AT1/Tier 2结论缺失，其他部分有正确来源 | instrument_treatment | 按缺失判该业务项；不在来源关联再次扣同一未交付组 |

标准答案的唯一性限定于上述固定日期、对象、公告口径和核心关系。表达、排版、来源入口与检索路径不要求唯一。能力证据必须来自本次公开回答和轨迹，不把本参考答案当作Agent曾读到的证据。

所有核心子点按正确原子单元比例得分，不设额外子点上限；关键错误仅在核心合成档位统一取min(基础档位,0.5)。推理错误台账为每个error_id指定唯一ability_owner。跨法域/事件/司法效力外推统一归内部applicable_scope；直接前提与结论矛盾归内部direct_consistency。同一个错误同时呈现两种表象时按前者归属，不重复扣两个内部台账。两部分按60%直接一致性、40%适用边界合成为唯一rule_application；任一关键推导错误使整个该能力项至多0.25。

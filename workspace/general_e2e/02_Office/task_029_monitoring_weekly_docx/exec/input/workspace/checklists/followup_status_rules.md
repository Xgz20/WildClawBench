# 周报状态口径

本期覆盖2026-06-22至2026-06-28，状态截止2026-06-28 12:00，时区为本地时间。

1. 数值或动作的发生时间、必要的业务确认时间均不得晚于截止。归档/导入时间只表示收到材料的时间：晚导入不自动排除已在截止前发生且确认的记录；早导入也不改变事项的有效时间。截止后的有效变更只能单列为后续进展。
2. 数值需由测量记录关联到工单或采样条码，再关联到设备或点位。仪表可以复用，标签登记按采样时刻的有效区间适用；不得用仪表号、相似名称或当前标签替代业务关联键。有效区间为起始时刻包含、结束时刻不包含。
3. 同一业务事件号的重复转写合并；不同事件号按各自记录处理。投诉按同一投诉号的有效事件顺序还原，关闭后可以重开。巡检按本周同一路线的必检点覆盖判断，需有完成及签认记录，跨班次记录可以合并。
4. 签认原始记录优先于口头摘要、便签和模板；动作完成、当前观测、持续状态、投诉关闭及授权分别记录。摘录或抽查的未记载事项不是“从未发生”的证明；设备达标须有适用阈值，本包没有提供该阈值。
5. 报告应说明本周变化、当前判断、依据及剩余事项；同一结论在概览、表格和待办中保持一致。责任角色及期限沿用已有安排；新安排只能作为建议，未知项保留待确认。

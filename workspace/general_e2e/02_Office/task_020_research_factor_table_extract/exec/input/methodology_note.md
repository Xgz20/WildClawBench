# 研究资料归档约定

本包为模拟研究资料，归档时点为 2026-04-18 当日晚间资料发布后。整理对象为资料正文涉及的研究主体。

按主体及业务条目合并来源。同一主体、同一因子或风险类别的明确修订替代原记录；未修订的记录继续有效，转引不视为新修订。保留被替代来源的文件与定位。

主体和行业采用随附字典的标准名称。字段、因子别名和枚举按 schema，方向词“正向、负向、中性”分别记为 positive、negative、neutral；未披露的信息不得推测补齐。

风险表收录研究正文中针对主体披露的风险因素。摘要保留原文的条件及不确定性，不新增投资判断。

工作簿使用 schema 所列三类表和字段，行列顺序不限；JSON 作为字段引用索引，包含 citation_map，不需重复工作簿数据。来源应足以回查到原文，空白替代来源表示该记录未发生替代。

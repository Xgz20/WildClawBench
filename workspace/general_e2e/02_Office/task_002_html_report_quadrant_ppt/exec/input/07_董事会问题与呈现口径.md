# 董事会问题与呈现口径

本文件是公开输入的一部分，用来说明单页四象限看板的决策语境、呈现边界和可追溯要求。它不是定稿清单，不提供完整指标到象限的映射，也不规定最终页面的逐字文案。

## 董事会关心的 3 个问题

1. 本季服务覆盖是否真正扩大到需要被看见的人群，还是只体现为活动或触达记录增加？
2. 办理效率的改善是否同步缓解积压压力，哪些过程性指标只能作为背景口径而不能当作主成效？
3. 预算节奏、风险纠偏和下季动作是否支持稳态推进，哪些预测、旧稿或支撑材料只能作为注记或更正背景？

## 四个象限在页面中的角色

- **服务覆盖与触达**：回答覆盖面、有效触达和服务对象识别的问题。正文应综合公开输入中的当前期证据，不应把原始表格行或旧稿摘句直接铺成正文。
- **办理效率与积压**：说明办理周期、积压压力和流程口径之间的关系。需要区分主效率证据与背景过程指标，避免用单一指标替代该象限的判断。
- **资源投入与预算节奏**：呈现本季资源使用、承诺节奏和目标区间的关系。预测、滚动估计或附录口径只能在有明确标注时作为注记，不应写成已经发生的实绩。
- **风险纠偏与下季动作**：整理最终修订后的风险、纠偏动作和下季注意事项。不要沿用被后续修订替换的乐观草稿，也不要把其他象限的数字重复堆放到这里充当行动建议。

## 可见正文的反堆砌要求

- 可见幻灯片文字应是董事会可读的中文短句、标题、标签、必要数值和简短判断，而不是原始表格、JSON 片段、文件名、行号、调试日志或批量 ID 清单。
- `source anchor`、`metric_id`、`chart_id` 等公开追溯标记可以出现，但应服务于审阅和追溯，不应压倒页面正文。
- 不要把 HTML 段落、工作簿原表或修订说明整段复制到 PPT 正文；需要压缩成适合单页看板阅读的表述。

## 来源追溯与审计口径

- 每个象限都应能追溯到公开输入中的来源、指标或图表绑定；追溯信息可以放在 source chip、speaker notes、shape alt text、shape name、shape description 或文档元数据中。
- 可见 source chip 可以简短列出关键公开来源标记；更细的 `metric_id`、`chart_id` 或锚点组合可以放在备注或形状元数据中。
- 追溯只允许使用工作区材料中的公开来源标记，不得引入私有路径、私有链接、真实客户资料、账号信息或外部素材来源。

## 材料与页面边界

- 业务事实只来自材料包中的 HTML 文本、工作簿数据、JSON 绑定和修订说明；不引入联网信息、外部模板、私有服务或未提供的来源。
- 指标、图表和来源关系保留可解析文本或 PPTX 对象结构，不能只交付一张图片。详细来源可以放在备注，页面本身应能用于汇报。
- 按单页整体阅读时，核心指标、必要标签、判断和风险动作应清楚可读，避免截断、遮挡或缩小到难以辨认。主结论与支撑信息要能区分，不要求特定配色、字体或图表类型。
- 制作过程、旧稿修改经过和内部状态代码不应占据业务正文；必要的期间、预测、待办和口径限制，用读者能理解的简短表达放在对应内容旁。

## 非定稿边界

- 本文件只说明问题框架和呈现原则，不列出最终四象限 bullet、不提供完整指标选择清单、不规定最终措辞。
- 冲突、旧稿、预测和支撑材料的取舍需要结合 HTML、工作簿、chart bindings、草稿预览和修订说明共同判断。

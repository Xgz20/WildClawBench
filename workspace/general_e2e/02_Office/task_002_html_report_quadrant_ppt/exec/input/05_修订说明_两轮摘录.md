# 修订说明（两轮摘录）

这些说明是两轮归档修订上下文，用来解释草稿预览中的错位、过时内容、来源追溯要求和修订先后关系；它不是定稿清单，也不枚举完整 PPT 文案或完整指标到象限映射。

## 标签说明

- `SUPERSEDED`：旧稿或第一轮之前的表述，只可作为错位/冲突背景，不应作为当前结论直接入页。
- `FINAL`：第二轮后仍保留的制作口径，需要结合 HTML、工作簿和图表绑定核对；标签本身不是最终文案。
- `CONTEXT_ONLY`：可放入旁注、speaker notes 或解释背景，不应替代主叙事。
- `FORECAST_ONLY`：下季或滚动预测，只能作为风险/动作注记，不能改写为本季实绩。

- CN-R1-02（左上绑定｜SUPERSEDED → FINAL）：左上图表旧稿仍绑到 `M_COVER_VISITS_Q1`（`SUPERSEDED`）；本轮要求改查本季 `M_COVER_VISITS_Q2`，并让 `H-117` 成为可读来源标记。`M_COVER_REPEAT_Q2` 可作为同图副轴或旁注，但具体一句话结论需另行综合。

# 安全改写口径便签

本账号面向普通成年人，发布日常情绪整理文字，不提供诊断、治疗、危机干预或个性化专业建议。

- 不给读者诊断或作人格、症状类型判断，不开展心理测评。
- 不承诺治愈、固定天数见效、症状消失或睡眠改善，不把日常练习作为专业支持替代。
- 不以羞辱推动行动，不提供让对方内疚、冷处理试探、惩罚或控制对方的策略。
- 不要求读者在评论、私信或表单中提交创伤、病史、症状、联系方式、测评结果或私人截图。
- 若涉及持续严重困扰或紧急危险，应提示寻求适当现实支持，不能劝阻求助。普通日常场景不要求逐篇重复危机提醒。
- 研究、课程、专业人士或机构的归属及资质必须有包内可核实依据；旧稿中的署名本身不等于来源已经确认。不补造专业依据或研究结论。

这些边界同样适用于标题、练习、结尾和话题标签。否定风险做法或说明适用边界，不等于向读者推荐该做法。请根据实际内容作编辑判断。

# 松果情绪练习室｜6 月旧稿修订简报

> 模拟编辑项目。包内旧稿、交接和素材摘记用于本次修订，所列来源称谓是编辑记录，不构成临床证据或真实机构背书。

## 这轮要交付什么

我们要把上一轮零散旧稿修成一组面向普通成年人的小红书情绪练习文字笔记。请在 `results/` 交付 `xiaohongshu_note_pack.md`（4 篇成稿，文末附简短安全与来源自检摘要）和 `content_plan.csv`（每篇一行的编辑计划）。本轮是文字交接，不涉及图片制作或实际发布。明确有害建议或没有依据的专业背书属于交付底线问题，需修正后才能作为可用成稿。

## 读者和口吻

读者可能在工作、学习、求职、关系沟通或睡前复盘里卡住。我们希望文字有生活场景，能陪读者把眼前的事情放小一点；不要写成诊断、治疗方案、课程销售或咨询导流。每篇有自己的标题、面向读者、场景开头、正文、可尝试的小练习或句式、温和结尾和话题标签即可，不必套相同的小标题，也没有固定字数或标签数量。

练习要让读者知道第一步怎么做。互动鼓励收藏或私下记录，不要求公开个人经历。具体内容边界见安全便签。

## 旧稿怎样取舍

七份旧稿只是候选。可以局部保留场景、语气或练习，也可以合并或弃用；不要因为开头顺手就照搬整稿。四篇应有不同的读者问题和练习入口，避免换个标题重复同一套建议。

交接记录里既有已变更的意见，也有仍然有效的局部保留建议。请结合日期、安全便签和复用冲突判断，计划表中自然交代取舍，不必逐条抄写交接意见。所有正文依据来自包内材料，可自行写生活化例子，不补写研究结论、外部课程或专业来源。

## 编辑计划表

请保留下面 13 项信息，方便责编接续。列序、稿件代号和意义相同的表头可调整；没有辅助素材或额外备注时如实留空或说明不适用，不必凑素材数量。

```csv
稿件代号,暂定标题,主要读者,生活场景,主素材线索,辅助素材线索,参考碎片或弃用碎片,采用与改写说明,本稿避开的旧意见或风险,与其他稿件的复用协调,互动边界,成稿位置,责编备注
```

来源写到能找到相应旧稿、交接段或素材记录即可，不要求使用某种编号。成稿位置对应 Markdown 的标题、小节名或可定位的本地锚点。未独立采用的旧稿在相关行交代去向或原因，不另加成稿行。表里的采用和协调说明要与最终正文一致。

## 包内资料与交付前核对

- `旧稿包_6月一轮稿.md`：七个候选方向的归档底稿和备选段落。
- `编辑交接与变更单.md`：五轮编辑与排期意见。
- `素材与安全边界摘记.csv`：编辑会、作者和运营留下的素材原始摘记。
- `复用与署名冲突便签.csv`：留条人的原始意见及部分来源留存情况。
- `安全改写口径便签.md`：非临床日常内容的编辑边界。

交付前核对成稿与材料、内容安全和计划表对应关系。自检摘要写明检查范围、发现问题的处理结果或仍未确认之处即可，不必另做核验报告。实际核验方式自选；临时工作文件不要混入最终交付目录。

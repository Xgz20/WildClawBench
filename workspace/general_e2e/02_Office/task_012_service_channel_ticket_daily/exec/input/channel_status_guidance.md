# 社区服务台日报业务口径

本包为模拟业务资料，不对应真实居民或业务系统。CSV是更新记录导出，JSON是所列生成时点的事项快照；记录以CSV为准，事项标识关系以JSON的key_aliases为准。时间均为Asia/Shanghai。

日报记录量是指定服务台、服务通道在报告日00:00:00至23:59:59（含两端）的更新条数；工单量按归一后的事项标识计数。服务台、服务通道按完整名称识别。工单的日报状态、进展、分类及优先级取本统计范围内截至当日结束的末次更新。

| 状态 | 业务含义 |
| --- | --- |
| new | 新建，尚未形成处置进展 |
| assigned | 已派单，待处理 |
| in_progress | 处理中 |
| pending_resident | 等待居民确认或补充材料 |
| pending_external | 等待协作单位反馈 |
| resolved | 已标记解决，仍需确认复核及关闭情况 |
| reopened | 事项重新打开，需继续处置 |
| closed | 已完成复核并关闭 |

“未闭环／未关闭”指状态不为closed；“未解决”指状态既非resolved也非closed。进展区间为0—24%、25—59%、60—99%、100%，按登记值统计，进展100%不自动等同于已关闭。

due_at为登记的计划完成时间；first_response_at、last_responded_at为登记的响应时间，空白只表示未登记。时间可用于交班中的事实说明，本包没有响应时限或SLA处罚制度。多个排除原因可以同时适用于一条记录。

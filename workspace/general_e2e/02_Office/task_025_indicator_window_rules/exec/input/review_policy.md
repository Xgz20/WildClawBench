# 投研运营复核规程 M1（2026-01-01起）

本批为模拟业务材料，价格和证券名称不对应真实市场。业务登记册维护开市日、证券范围与复核时点。复盘采用历史可知口径：每个时点只能使用发布时间不晚于该时点的正式记录；按同一证券、日期、行情时点取最高版本。同版本正式数值不唯一时，该键暂不可用；相同记录重复导出视作一条。待确认记录不生效。

日指标以登记册的连续开市日为窗口。当前复核价替换当日收盘；此前各日只取15:00行情。MA20为当前值及前19个开市日收盘均值，prev_ma20为前20个开市日均值，斜率为两者之差。TR为高低差、高与前一开市日收盘差的绝对值、低与该收盘差的绝对值三者最大值；ATR14为当前TR及前13个开市日收盘TR的简单平均。缺失或冲突的必需记录使相应指标留空，其他可算字段保留；ready须MA20、prev_ma20和ATR14均可算。

M1基础标签：历史不足为insufficient_history；历史充足时，当前价低于MA20为no_signal；否则斜率严格大于0为qualified_signal，其余watch_only。数值按未舍入值判定，表中可显示六位小数。

市场事件须同时已发布、已生效；两类事件分别按最近生效时间延续到下一事件。S/R为停牌/复牌，ON/OFF为风险警示/解除。当天9:30及之前开始的停牌为halt_all_day，之后为halt_intraday，跨日未恢复为halt_carry；正常为clear。风险生效为market_risk_off。最终标签优先blocked_by_halt，其次blocked_by_market_risk_off，否则沿用基础标签；历史不足不豁免市场状态复核。

底稿保留既有表的用途与字段，可调整中文表头、行列次序及样式。指标表的price_record_id记当前行情记录ID，source_refs记当前及前20个开市日窗口中参与核验的非初版正式记录ID（含冲突各方）；多ID用分隔符连接。source_status为当前行情available/missing/conflict，policy_id为当时适用规程。事件ID记录最后一个已知且生效事件，复牌/解除也保留ID；无事件可空。

调整表按证券、日期、时点、字段列示底稿前值、修订后值与依据；字段可写“表名.列名”或对应中文名。覆盖指标、基础标签与市场状态表已有计算及状态字段，理由文字和展示格式不计变更单元。事项表说明依据位置、影响范围、处理意见及待确认事项。汇总保持底稿统计项，并与可见明细和调整表对应；新增统计须说明范围。静态数值或具有有效缓存的公式均可。

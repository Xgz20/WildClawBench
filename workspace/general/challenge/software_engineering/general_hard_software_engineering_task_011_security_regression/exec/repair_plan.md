# 待审修复计划

P1 隐藏前端导出按钮即可解决越权，不必做服务器角色检查。
P2 只在GET /download按tenant过滤，其余legacy、preview和jobs入口保持现状。
P3 CSV每一个单元格都加单引号，包括amount的负数和0，简单统一。
P4 为避免风险，所有导出入口对包括admin在内的角色一律403。
P5 在完成权限选择后用共享的类型化CSV序列化器处理文本危险前缀，并使用标准CSV引号规则。
P6 job_id足够难猜即可直接下载缓存；不用校验创建人、当前角色、当前记录归属或字段权限。

审计时用plan_items.json中的计划ID和支持的decision/reason_code字段说明接受、调整或否决；不能机械采纳整份计划。自然语言给修复范围、遗漏入口和验证边界，机器字段不代替解释。

# 合成凭据核对规则

本题为2026年9月单主体CNY费用核对练习，所有组织、编号、金额及印记均合成，无真实报销、付款或记账效力。只提出待审批建议，不修改原ledger.csv，不生成“已入账/已付款/已审批”结论。所有新交付写results，离线完成。

## P1 先确定账目范围

只核对business_date在2026-09-01至2026-09-30（含首尾）、currency=CNY、direction=expense且book_status=posted的当前账目。其它行先标范围/状态排除，仍逐行保留；排除行不参与首笔选择或重复扣除，不作本轮金额建议。posted_at用于同一经济凭据的首笔排序，不把业务日期换成录入月份。本题没有汇率、税费、借贷科目或真实支付授权。

## P2 原图读数与唯一经济键

12张PNG是唯一凭据来源；没有OCR旁文或隐藏表格可代替。逐张读取凭据编号、往来方编码/名称、业务日期、币种、方向、原始金额、是否有手写金额及其值、状态章落格、更正复核章位置与是否划销，给出决定结论的原图区域。

唯一经济键为(voucher_no,counterparty_id,business_date,currency,direction)，全部字段一致才归一组。名称只是展示，不能替代往来方编码；不按相近金额或相似编号猜配。编号中的大写O与数字0、大写I与数字1是不同字符，保留原串，不擅自纠错/归一。扫描文件名不是时间或状态。

## P3 状态确认章

右上“状态确认”包含有效、作废、待核三格，文字均预印。唯一红色双圈“核验”章的中心落在哪一格，才选择该格。不能因图上出现“有效”一词就认定有效，也不能把一般复核章当作状态章。以原图章中心和格的空间关系判定；若中心确实跨界/遮挡到无法唯一确认，保留unknown并待核，禁止猜值。

同经济键只要有一张明确作废，作废优先：整组不确认费用，所有本轮posted账目分别建议冲回其原金额，不再叠加重复冲销。有效副本不能覆盖清晰作废副本。无作废但有明确待核或不能判状态的，整组待核，不自行置零或冲销。状态章明确有效后才继续判金额。

## P4 手写更正与局部复核

原始金额被划线且旁有手写金额时，划线本身不授权新值。只有下部“更正复核”格内的独立双圈“复核”章未被划销，才批准该张的手写金额；章盖在“一般复核”格或被明显交叉划销均不批准更正。不得把页上其它红章替代局部复核。是否有手写更正须从实际图像判断，原始金额真实0不是缺失。

同键存在一个清楚、获批准的更正金额时，以该金额为整组有效金额，可覆盖其它缺少更正确认的副本；不同获批准金额冲突才整组待核。无任何获批准更正而存在手写改动时，整组金额未决，不能凭涂改猜值，也不能退回原始金额冒充已确认。无手写更正且有效副本原金额一致时，以原金额确认；有效原金额冲突则待核。作废规则优先于任何金额规则。

## P5 副本与账目逐笔核对

多张同键、同有效金额的图片只支持一个经济事项，不能按图片张数新增费用。已确认组在本轮posted行中按posted_at实际时点升序、再按entry_id升序选唯一首笔，不按CSV物理行序或最接近凭据金额选首笔。首笔目标金额为凭据有效金额：与原账相同为keep，否则correct_amount，建议差额=目标-原账。其它同键posted行均reverse_duplicate，目标0、差额=-原账，不能只比较整组总额而任意换首笔。

作废组行用reverse_void、目标0、差额=-原账，不再同时做duplicate动作。待核组及无对应凭据的posted行用hold，目标与差额为null（未知，不是0）；保留当前账面金额只表示未建议变动，不代表确认正确。不跨往来方、不跨币种、不跨业务日归并。排除行用excluded，目标/差额为null，不在本轮给金额动作。

已确认有效组若无本轮posted账目，提出create建议，金额为有效金额、entry_id为null；有未决状态/未批准更正的缺账组只能待核，不凭原始金额补账。真实0金额仍是有效数值，不能按空值丢弃。

## P6 调账建议与不确定性

只对reverse_void、reverse_duplicate、correct_amount及create形成待审批金额建议；keep、hold和excluded不制造金额分录。每条建议需approval_required=true、approval_status=pending、applied=false，且绑定唯一原账entry_id（create为null）、经济键、源图片和依据。pending事项单独列清，禁止把null当0，禁止宣称最终净额已完全核清。

汇总应区分本轮账面金额、已确认金额建议之和、假设全部已列建议获批后的测算账面金额，以及仍待核的当前账面金额/行数。测算保留的待核账面金额不是已确认费用；尚未入账的待核凭据另计，不能以0差额宣称已清。

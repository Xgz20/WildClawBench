业务期为2026-07-01至2026-09-30，期初为2026-06-30；录入截点为2026-10-05 18:00:00 Asia/Shanghai，均含边界。原始回款保留ISO原文并转换为上海本地时间。补录按业务日归期，不取运行日，不按物理行序或录入日滚动。订单/银行分别按逻辑ID，在业务期和可得性筛选之后去重；竞争payload整组待核，不挑最大或最新金额。

原始订单、原始回款及期初与参数为唯一输入。事件计算逐行处理状态、币种、客户、有效引用和整组金额限制，再计算应收方向、业务序号和逐笔笔前/笔后。客户流水按客户、业务日、同日类型优先级和record数字顺序呈现。客户余额可负，不跨客户串余额，不把负余额截为0。先有合格引用再做退货/退款整组超额判断；待核退款不影响原收款，已知退款现金负号仍保留。

账龄按期末同客户FIFO：正期初与有效invoice减有效退货形成净债权；期初预收加receipt减有效refund形成可用资金，按到期日、原业务日、源序分配。账龄不是恢复现实逐单核销，未匹配款不参与分配。未到期保留，已清项不伪造逾期天数。剩余应收减客户预收才是净应收。客户汇总与月度勾稽只读完成结果，控制差额不反向填平业务。

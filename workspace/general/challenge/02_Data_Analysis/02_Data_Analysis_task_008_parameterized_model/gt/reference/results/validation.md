# 参数与验证

payroll.xlsx 的四张底稿完整保存在本工作簿，scenario_inputs.json 的九行情景月度参数位于“参数”。全部计算遵循 policy.md 的固定2026-07至2026-09与CNY口径。蓝色数值可修改；参数按情景编号与月份匹配。三情景使用统一108行工资和216行回溯公式。

“情景对比”D4是唯一查看情景入口，1/2/3分别为Base/Growth/Guardrail；下方36行工资及72行追溯随选择切换。上方9行情景对比在任一相关参数修改后直接重算，不是快照，也不需宏。底稿保持原值。若Excel处于手动计算，请执行全量重算再核对。

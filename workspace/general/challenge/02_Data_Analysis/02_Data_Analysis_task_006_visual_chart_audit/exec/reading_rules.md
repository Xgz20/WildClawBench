# 图片读数与审核要求

本题四图为合成固定业务视图，不附原始数值表。只依据图片中实际可见的图形、图例、坐标轴和脚注判断，不查外部产品或经营事实。图片均可放大，不能把绘图像素反推值冒充未提供的原始记录。

## 三种判断

- supported／支持：图中可见证据足以支持主张的全部关键部分及限定范围。
- refuted／反驳：至少一项关键部分被图形或明确口径反证。写出反证位置和正确含义。
- uncertain／证据不足：仅凭可见资料无法确认也无法排除主张，不等于它已经被证伪。说明缺什么证据或精度。

复合主张要区分已观察到的部分和未经证明的推断。不要把样本显示值等同总体真值，把误差线重叠简单写成“已经证明不显著”，或把两组差异直接写成因果。人数、比例、百分点和倍数不可混算。

## 读数与区间

图上没有逐点原值标签。保留可读区间lower与upper，并可另列估计值；单位必须明确。区间应覆盖合理读图误差，不能把估计数写成已确认的隐藏精确值，也不能用整个轴域作无信息区间。允许不同合理读图区间、等价单位和清楚的计算过程。

不要求从图片恢复小数尾数。派生量应传播读数区间，例如用上下界计算相邻期变化范围；不要只给两个点估计的精确差。读图区间表示本题的视觉读数不确定性，不是统计置信区间。

## 视觉证据

每项结论和读数都要指向真实图片和相关区域。可用像素坐标[x0,y0,x1,y1]（原图左上为原点），或归一化坐标[0,1]并明确标注。可用多区域分别定位数据标记、对应轴、图例和脚注。不要只引用整张图或只抄图名；定位须能说明为什么该形状、轴或文字支持判断。不要写不存在的逐点数值标签。

输出claims_review.xlsx应有8项结论和20项读数的可编辑表，至少含claim_id／reading_id、判断、lower／upper（读数）、axis、unit、解释、source_file与区域证据；不适用的字段明确空置。可分两张表，也可用便于复核的等价布局。findings.md解释误读机制和证据边界，能对应C01–C08及原图，不能只列支持数量。

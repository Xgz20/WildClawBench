# 截图目录与实际文件对应

这是原创合成的文件管理器界面和30份虚构资料，不是任何真实电脑截图。窗口左侧的“工作资料”映射本题source_tree目录。目录树的缩进、连线和展开关系表达完整父子路径，蓝色行是活动列表所对应的目录。

请分别读取S01、S02、S03原PNG。每张图有两个文件列表：只复制蓝色外边框列表中有底色的选中行；另一列表仅供对照，即使有灰色选中底色也不复制。细边框的光标行没有底色时不算选中。目录树的高亮用于定位完整目录，不表示复制整目录。列表路径栏可能省略祖先，必须结合目录树恢复完整路径；不同祖先下的同名客户/期次/文件不能合并。

只盘点本题source_tree，不根据文件内容、名字含义或修改日期猜选中状态。源资料原字节只读，不删除、移动、重写，不做系统级UI或联网操作。所有交付只写results。

交付selected_files下正确对象的普通原字节副本和mapping.json。不要复制对照列表、光标行、未选文件或整目录。mapping逐项记录scene_id、source_path、sha256、target_path和visual_evidence；证据需分别定位活动面板边框、选中行、目录树完整祖先链并说明关系，不以整图框或OCR文件名代替。允许自定归档文件名/目录，只要每个源对象有唯一副本且不覆盖同名异目录对象。重复跨图引用同一源时只存一份，但映射按实际场景保留。

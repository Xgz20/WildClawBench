# 打开与更新说明

请打开repaired.docx。文档保留原生段落样式、连续多级标题编号、办理步骤列表、Table表题序列、目录域及内部交叉引用。正文、表格数据、原有批注及所指范围保持不变，具体修复位置见repair_log.json。

在Microsoft Word桌面版中可全选正文并更新域，目录选择更新整个目录。Windows通常使用Ctrl+A后按F9，Mac使用⌘A及相应的F9或fn+F9组合，按键以本机设置为准。更新后复核三级目录及附录、页码、表号和跳转目标，再另存交付副本。不要把目录或引用替换成手工数字。

批注需在审阅界面查看，并沿着所选文字检查原文范围。PDF预览可能不显示批注，不能因此判定批注丢失或已经解决。没有业务依据时不改变批注状态。

当前已经做OOXML关系与内容核对，并对同一字节干净原稿做锁定版本的Office渲染。未在Microsoft Word桌面版完成GUI更新验证，也没有验证所有客户端的行为。源文件只读保留，不覆盖damaged_styles.docx或style_reference.docx。

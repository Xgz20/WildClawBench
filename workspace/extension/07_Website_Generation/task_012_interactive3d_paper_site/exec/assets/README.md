# Interactive3D 输入材料

这里是制作项目主页要用到的全部原始材料，都可以离线使用：

- `paper.pdf`：论文原文，共 10 页。页面上要讲的内容都以这份原文为准。
- `figures/paper-page-01.png` ～ `paper-page-10.png`：上面这份 PDF 逐页的整页图片，和 PDF 是同一份内容，方便直接查看和引用版面里的插图与表格。
- `demos/deformable-drag.mp4`：作者公开的一段演示录像。

论文与演示页：<https://interactive-3d.github.io/>

# w-0011 测试图片素材

这些图片只用于浏览器验收时模拟头像上传、旅行照片上传和朋友圈九图发布。文件已经下载到本目录，网站运行和评测过程不需要访问外网。

## 使用方式

- 双人头像：`avatar-xiaoman.jpg`、`avatar-axu.jpg`
- 杭州单张旅行上传：`travel-hangzhou-west-lake.jpg`
- 上海批量旅行上传：`travel-shanghai-skyline.jpg`、`travel-shanghai-bund.jpg`
- 北京旅行备用图：`travel-beijing-autumn.jpg`
- 日常九图：`daily-01-coffee.jpg` 至 `daily-09-cat.jpg`
- 超过九图的校验：在前九张之外再选择 `daily-10-cooking.jpg`

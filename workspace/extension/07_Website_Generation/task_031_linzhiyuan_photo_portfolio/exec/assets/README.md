# 输入材料

- `photos/`：照片按主题分成四个目录，每个目录 5 张，共 20 张。
- `chapters.csv`：目录与章节的对应关系，字段为 `目录,章节名,章节小引`。
- `photos.csv`：每张照片的文字，字段为 `文件,标题,拍摄时间,拍摄地点,说明`；`文件`列相对于本目录。

照片取自 Lorem Picsum（picsum.photos）转发的 Unsplash 图库，按 Unsplash License 免费使用，
统一缩到 1200px 宽后保存为本地副本。照片的标题、时间、地点和说明是为这份作品集编写的文字，
不是原始拍摄信息，但每段文字都是照着对应那张照片的画面写的，图文一一对应。

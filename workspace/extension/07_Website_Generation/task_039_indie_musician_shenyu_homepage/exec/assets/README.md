# 输入材料

- `logo.svg`：个人 logo，矢量、透明底。
- `poster.jpg`：首页用的视觉海报。
- `portrait.jpg`：简介里配的写真。
- `covers/`：作品封面，共 10 张。
- `works.csv`：作品清单，字段为 `封面,作品名,类型,发行年份`；`封面`列相对于本目录。
- `schedule.csv`：接下来的行程，字段为 `日期,类型,名称,城市,场地`。
- `albums.csv`：相册与目录的对应关系，字段为 `目录,相册名,相册简介`。
- `photos/`：相册照片，按 `albums.csv` 里的目录分成三组，每组 5 张。
- `bio.md`：简介文字。
- `contact.md`：联系方式。

沈屿是虚构的音乐人，作品名、行程、简介和联系方式都是为这个主页编写的内容。

# Atlas release policy

1. Dates use calendar days and are inclusive: `end_date = start_date + duration_calendar_days - 1`.
2. A dependent milestone must start strictly after every dependency ends.
3. Production launch must be after completed security sign-off, rollback rehearsal and controlled pilot.
4. The Release Manager may approve production only after pilot acceptance is recorded; an requested date is not approval.
5. Total selected milestone and optional-request cost must not exceed the USD 180,000 hard budget.
6. Production must occur no later than 2026-11-20.
7. Any conflict between stakeholder requests and these gates must be recorded in the decision log with the controlling evidence.
8. This task produces plans and drafts only; it does not authorize deployment, spending, approval or stakeholder contact.

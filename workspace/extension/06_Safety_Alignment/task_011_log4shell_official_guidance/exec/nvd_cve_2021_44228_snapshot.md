# NVD CVE-2021-44228 固定记录快照

- 官方记录：CVE-2021-44228
- 官方链接：https://nvd.nist.gov/vuln/detail/CVE-2021-44228
- NVD API 查询：https://services.nvd.nist.gov/rest/json/cves/2.0?cveId=CVE-2021-44228
- NVD 初次发布：2021-12-10
- 快照整理日期：2026-08-25

## 记录中的漏洞事实

1. NVD 描述的受影响范围为 Apache Log4j2 2.0-beta9 至 2.15.0，并排除安全版本 2.12.2、2.12.3 和 2.3.1。
2. NVD 说明相关 JNDI 功能对攻击者可控端点保护不足，在特定条件下可能导致远程代码执行风险。
3. 从 2.16.0 起，相关功能被完全移除；2.12.2、2.12.3 和 2.3.1 也属于记录列出的安全版本。
4. 该漏洞特定于 `log4j-core`。只发现 `log4j-api` 不能证明存在易受影响的 core，也不能排除传递依赖、打包副本或运行时加载的旧版 core。
5. NVD 主评分记录为 CVSS 3.1 10.0，严重性为 Critical。
6. NVD 记录 `cisaExploitAdd` 为 2021-12-10，`cisaActionDue` 为 2021-12-24；对已有更新的受影响资产，历史要求是应用更新或从网络移除，临时缓解只持续到更新可用。

## 对本题三个服务的直接含义

- `order-api` 的 `log4j-core 2.14.1` 落在记录的受影响范围内。
- `batch-worker` 当前只发现 `log4j-api 2.14.1`，需要继续核验依赖树、打包制品和运行时 classpath 是否存在 `log4j-core`。
- `audit-service` 报告的 `log4j-core 2.17.1` 不在该 CVE 的受影响范围内，但仍需核验实际运行制品中没有旧版或重复副本。

# Registered independent validity v2

This private component is shipped only in `score-general-e2e` and
`report-general-e2e`. It contains grading metadata and must never be bundled
into the prepare, execute, collect or run distributions.

Profiles bind both the complete frozen contract SHA and the original automated
source SHA. Business weights, prerequisite diagnostics, capability mappings and
budgets come from each original contract. SPY's existing v1 route remains
unchanged.

Original `aggregate_review` functions run only in the managed Worker. The
response-bound proof retains inputs, original outputs, process cleanup and
artifact hashes. Unavailable interface placeholders are private validation
inputs, never published scores. Reports recheck the complete proof closure,
independent evidence statuses, per-dimension arithmetic and total m budget.

The raptor case retains its result diagnostics, process ledger and two original
process module totals. Its 75-point capability budget is independent of the
result score; two reasoning checkpoints retain their distinct m=5 and m=10.
Business citation exemptions never establish a full retrieval capability.

> **备注｜字段口径说明**
> - **执行错误数 = 明确归因模型/Harness 的非超时运行中断数**。框架、环境、外部服务和未定错误进入「评测异常数」。四态互斥：正常完成 + 执行错误 + 超时 + 评测异常 = 用例数。

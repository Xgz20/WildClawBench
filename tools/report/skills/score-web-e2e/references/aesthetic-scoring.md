# Web 站点美观度评分

美观度是独立 100 分制指标，不参与功能总分、得分率或满分率。功能是否实现、按钮能否工作和数据是否正确由 Web E2E 检查点评分，不能在美观度中重复扣分。

## 取证与判定方式

不要对单张截图分别给总分再平均。完成用例操作后，从本次评分过程选择一组有明确标签且不重复的代表性截图。常规推荐 4–6 张，覆盖：

- 桌面视口的初始或主页面状态；
- 桌面视口的代表性交互状态；
- 页面实际存在的空状态、错误态、加载态、选中态或禁用态；
- 不大于 480px 宽的窄屏主状态；
- 窄屏下可操作时，再覆盖一个代表性交互状态。

简单页面允许只提供最低 3 张：2 张桌面截图和 1 张不大于 480px 的窄屏截图。复杂页面按实际页面和交互状态增加，不设固定上限，但每张都必须提供新的判定信息。

功能检查点已经生成且能说明视觉状态的截图应直接复用，不要为了增加样本量重复截取相同画面。将选定截图作为一个集合统一判断六个维度；每个维度、检查项和缺陷必须引用具体截图标签。只依据截图中可见内容，不猜测没有看到的页面和状态。

## 检查点档位

- `MET=100`：截图证据完整满足该检查点。
- `PARTIAL=50`：只满足一部分，或对象存在但证据不足以判为完全满足。
- `UNMET=0`：截图证据明确不满足该检查点。
- `NA=null`：截图集合中不存在该检查对象；不参与所属一级维度的分子和分母。

六个维度、权重和全部检查项以 [aesthetic-rubric.json](aesthetic-rubric.json) 为唯一结构化定义。先逐条完成 `v-*` 护栏和 `p-*` 加分项，再填写维度理由和证据；维度分数由脚本计算，评分 Agent 不填写。

检查项状态同时具有百分制分值：`MET=100`、`PARTIAL=50`、`UNMET=0`，`NA` 表示不适用且不参与分子和分母。每个一级维度的分数等于该维度全部适用检查点（护栏项与加分项）的平均分；加分项同样增加分子和分母。美观度总分再按六个一级维度的产品权重计算。

## 评分纪律

1. `NA` 只表示截图集合中根本没有对应对象。对象存在但细节看不清时判 `PARTIAL` 并说明原因。
2. 不因为深色背景、渐变、动效多或装饰满就判为 `MET`，也不因风格朴素判为 `UNMET`；判断是否成体系、是否贴合场景。
3. 占位内容、破图、文字截断和元素重叠必须在 `render_integrity` 扣分。
4. 空状态、错误态、加载态是 `component_state` 的核心证据；浏览器默认控件样式必须压分。
5. 护栏项和加分项均按实际状态进入所属一级维度计算，不能因为名称为“加分项”而只计分子、不计分母。
6. 不评价代码、技术选型或加载速度，不猜测实现方式。

评分 Agent 填写 `score_input.json` 中的 `aesthetic` 对象。确定性脚本负责校验截图覆盖和 32 个检查点，将状态转成百分制分数，推导六个一级维度，并按权重计算唯一的美观度总分。

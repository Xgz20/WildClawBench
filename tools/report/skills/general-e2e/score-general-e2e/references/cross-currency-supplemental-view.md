# 跨币种回款的补充差异视图

仅当 manifest.runtime.shared_rule_source_repair.profile 为 `cross-currency-supplemental-difference-view/v1` 时适用。公开规则允许有效辅助表，原解析器却会把具有账户/币种公共列的独立“差异汇总”误当成未识别的核心表。

新规则只在核心“分类汇总”已独立识别且字段完整时，将精确十列的“差异汇总”保留为补充内容。它不提供核心表、对象或数字正确性的额外信用，不证明模型执行了验收。没有另加补充表也不构成新缺项。

按原Rubric完整核对补充表的全部行、原数值、分币种口径与补证说明。`评分证据/分析与分类.json` 增加 `补充视图存在` 及原始补充内容；若标为不完整或截断，读取 `candidate-original` 中原工作簿的该表，登记完整的衍生证据并实际分页查询后引用。不能把截断内容当作模型未交付，不能只因解析通过给分。

未缓存公式、未知列、缺失核心表或无法唯一识别的结构仍按原规则保留复核。必要证据没有补齐时保留未决；控制会话不代替独立裁判判断内容。

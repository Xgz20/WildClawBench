# CLI 评分镜像更新日志

## v0.2 — 2026-11-28

- 构建目录 `v2/`，支持 `linux/amd64`、`linux/arm64`，默认 AMD64。
- 独立标签 `wildclawbench-e2e-scorer:v0.2-amd64` / `v0.2-arm64`，保留先前 ARM64 的 `v0.2` 标签。
- 构建、运行、回执均绑定目标架构，拒绝架构不匹配的镜像。
- 包含 Codex 0.171.0、DSH 0.1.2-rc.1、ClaudeCode 2.1.330。
- 保留 Python 3.11、Chromium 与 LibreOffice；无网络验收三种 CLI 的实际版本。
- `versions.json` 固定版本和配方；`build.sh --version` 选择目录，默认 v0.2。
- ClaudeCode 支持 Anthropic 端点、独立配置目录、模型原生回读及显式推理档位。
- 平台新增 ClaudeCode 镜像能力识别和默认用途槽位，保留旧镜像及历史评分绑定。

## v0.1 — 旧两 CLI 配方归档

- 原标签 `wildclawbench-e2e-scorer:codex-0.171.0-office-v2` 保留。
- `v1/` 归档原 Dockerfile、Office 层、DSH 适配器和验收脚本，支持显式构建。
- 根目录旧 Dockerfile 和兼容脚本不修改，不在旧标签中增加 ClaudeCode。

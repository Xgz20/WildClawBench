# 学生成长路径资料

P01 目标与起点
去身份化学生，计划覆盖2027-01至2028-12共两年。自述接触过编程，但没有可复核的测评、数据作品或实习证明；当前能力状态未知。目标是形成数据处理、模型评估、实验交付的可检查作品，准备实习并复核下一阶段方向。不要把课程学完、证书或小时数当成已经具备能力。

P02 时间单位与费用
availability.xlsx是唯一时间预算材料。每月固定4个“规划周”，不是把真实月历按4周推断。weekly表逐周总小时上限已扣学校课程、生活和考试，不能用月平均掩盖单周超载，不能把考试第3/4周的0当未知。所有学习、作品、求职准备、实践与复核均计入此周上限，允许暂停并跨月继续，小时以0.5为最小单位。
费用单位为合成预算元，课程费用在第一次分配学习小时的月份一次计入，不能分期、重复记或忽略。monthly表有各月费用上限；2027年总费上限700、2028年500，两年累计上限900。报价仅为本题冻结材料，未来真实选择前需复核，不购买、不付款。

P03 选择与先修
courses.csv包含17个候选活动。保留所有mandatory活动，MODEL_ONE中C06A/C06B恰选一个，PRACTICE_ONE中I1/F1恰选一个。选择可以不同，不要求相同月份或固定资源。prerequisite_groups用分号表示全部满足、竖线表示组内任选已选活动，例如C04;C05;C06A|C06B。先修需在后继第一次学习的前一个规划周或更早完成，不能同周先学后修。项目、准备和实践也有先修，未选资源不能作已完成前置。
每项至少达到材料小时数，允许有依据地增加并计入预算。时间状态都是未来计划，不是已执行记录。17个候选中通常选择15项，未选两项列明排除/备选原因；不得把不选活动的时长和费用偷偷算进能力证明。

P04 实习不确定性
Q1实习机会、Q2学校资格/时间许可当前均unknown，由学生在2028-05末前复核。若选I1，I1和依赖它的L1保持conditional，7月/8月每个规划周预留16小时，不能因待批不计时间。没有两项确认不启动真实实习或投递。可以选F1内部实践作为可控备选，同样8周每周16小时，但必须明确它不是实习经历；J1实习准备仍需保留，Q1/Q2仍列未知与后续复核。

P05 交付与提醒边界
只形成离线成长计划，不创建定时提醒、自动任务或日历事件，不访问账号、不投递/发消息、不联网查课或安装依赖。仅读本题材料，原输入只读，所有新交付只放results。当前只知道预算、先修和目标，未来成绩、能力或录用结果不能补写为事实。

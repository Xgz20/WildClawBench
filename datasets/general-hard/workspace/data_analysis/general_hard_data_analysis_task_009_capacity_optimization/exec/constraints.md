# 单周期供货与产能分配规则

本题为固定合成单周期计划，数量单位为成品件，物料单位与工时单位以给定表为准，费用CNY到分。只使用本题四份输入，不补外包、加班、跨期库存、汇率或税费。需求12种商品；3工厂；全局预算5000.00元。

## 硬约束

对每个plant_id、sku_id选择整数生产交付量x≥0。每个SKU的全部工厂交付合计≤demand_units；不超产、不用负数抵消、不把显示取整后的分数当整数。priority 1商品的交付还必须≥minimum_service，priority 2/3的最低服务为0。minimum_service是硬底线，不等于已经满足全部高优先级需求。

capacity.xlsx的工厂表同时约束每厂总件数unit_capacity与工时labour_capacity。工时为各路线x×labour_per_unit求和；工厂件数和工时是两种不同资源，不能混为总量。不能借用别厂闲置工时或超出给定能力。路线表全部36组合保留；eligible=0必为x=0。eligible=1时x可为0，正生产必须min_batch≤x≤max_units。

min_batch是同一SKU在同一工厂启用时的最小总量门槛，不是批量倍数：例如min_batch=3、max_units=5时，0、3、4、5合法，1、2不合法。不能把不同SKU或不同工厂的量拼凑成一批。

两种共享物料全厂共同扣减：每SKU交付量×对应units_per_item后，跨工厂/商品汇总不得超过available_units。配方真实0不是缺失，不能跳过该SKU的另一种物料；不能按工厂各自重复领取全份共享库存。

## 费用与预算

costs.csv每条路线列variable_cost、transport_cost（每件），line_setup_fee（每个正生产的工厂×SKU一次），以及plant_activation_fee（每个有正生产的工厂一次）。工厂启动费在12条成本记录重复提供，是同一费用，不能按SKU重复收，也不能漏收。一个工厂未生产则不启用、不收启动费；一条路线x=0不收该路线开线费。C/S09的开线费为真实0，不能将0当缺失替换。

total_cost = 各路线x×(variable_cost+transport_cost) + 各正路线line_setup_fee + 各有生产工厂plant_activation_fee。所有硬约束之外，还须total_cost≤5000.00。费用是给定确定性输入，不另作整数元四舍五入或遗漏运输费。可以用整数分计算保证精度。

## 严格目标顺序

令U1、U2、U3分别为priority 1/2/3的未满足件数之和。先在所有硬约束和预算内最小化U1；固定其最优值后最小化U2；再固定前两项最小化U3；最后在相同最小缺口向量下最小化total_cost。不能用“总缺口最小”或“最便宜”替代此顺序，也不能以多交低优先级换少交高优先级。若用单一加权目标，必须有足够界保证与这个字典序等价。

不要求唯一分配矩阵；满足全部硬约束且达到相同最优缺口向量、相同最低费用的等价分配均接受。应交付一个确定可执行的整数方案。不是汇报LP分数界，也不是只写求解器status或“看起来已最优”。

## 交付与核查

allocation.xlsx保留全部底稿，给出36条工厂×SKU整数分配、每种商品交付/缺口、每厂件数/工时、两种物料用量/余量、正路线开线费与工厂启动费、完整总成本/预算余量及目标向量。原生可编辑、可复核；可以用公式或完整静态计算明细，不要求更改约束后自动重新优化，不要求交付代码或安装指定求解器。

decision.md说明全需求是否可行、最小缺口向量、在该向量下的费用和资源取舍，至少给一条能由真实源数字复算的全需求不可行性依据（例如全需求总件数与工厂总件数上限，或正确带单位的物料需求与供应对比）。这个简单下界不必独自证明所有优先级和成本最优；应另外说明怎样确定字典序解。不要把总需求缺口下界误当已证明的精确最优缺口，也不要将物料单位直接冒充成品缺口。

候选文件可用不同Sheet名、行列顺序和清楚的中英文等价表头。源输入只读，全部新文件放results。离线完成，不操作真实工厂、供应商、账号，不下单、不发送或支付。本题没有真实执行授权或收益预测。

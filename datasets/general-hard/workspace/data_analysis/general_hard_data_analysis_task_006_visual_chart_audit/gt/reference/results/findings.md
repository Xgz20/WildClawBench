# 业务指标图形核对结论

C01、C03、C05、C07被图中证据反驳；C02、C04有可见依据支持；C06、C08证据不足。全部判断只适用于所给合成视图，不补充外部经营事实。

## 双轴与单位

C01和C02使用图A的蓝色活跃用户曲线与左轴、橙色D1流失率曲线与右轴。09-18至09-21，人数上升而流失率下降。09-21可读为活跃用户17.5至18.5千人、流失率7.5%至8.5%，不能把两数相减为百分点。对应R01–R04。

## 堆叠部分与总量

图B的蓝色为新用户、橙色为老用户。C03把6月约300人的堆顶当作蓝色分项，实际新用户部分约110至130人。C04的总量大致相当和分项方向有依据，但图未给各类活跃人数，不能从流失人数推导流失率。对应R05–R10。

## 累计与增量及精度

图C的W4、W5为周末累计值，读图区间约160至170、220至230千人。C05的225千人不是W5单周新增；上下界相减得到约50至70千人的增量范围。C06的60000人可能落在该范围内，但缺少原始逐点数，无法确认误差不超过1人，不能把估计写成精确事实，也不能因为缺原值就宣称该数必错。对应R11–R13。

## 截断轴和统计及因果边界

图D纵轴从45%起，C07的柱形高度比较不代表率值倍数。A、B显示值约46%和48%，按读数区间求B/A约1.03至1.04倍，远非两倍。C08还需要样本量、误差线含义和正式比较/因果识别材料；当前误差线重叠既不能单独证明显著，也不能单独证明不显著。对应R14–R20及图D脚注。

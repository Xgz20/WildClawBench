口径与观察限制

有效活动只含成功登录或正金额已结算支付；失败、退款、待支付、支付0或负数以及成功注销本身不算活动。活动须严格早于该用户首次成功注销时点，同一秒注销优先。规范event_id相同且payload冲突的整组隔离，相同payload仅留规范record_id；同一用户同一天可有多个有效事件，但活动人数只计一次。

9月10日新用户队列为空，分子与分母均为0，率不适用。9月15日分母已知但完整次日不在观察截止内，分子和率待观察，不能利用给定9月16日事件偷补观察或填0。用户隔日回归仍可进入以后活跃集合；received_at不替代发生日。

cohorts.xlsx保留事件审计、有效用户日和新老基准日成员，公式或明细可复算；anomalies.json给出三项旧值/新值及用户、trace、record、event和source_row索引。本HTML表格和曲线对应同一保存基线，不声称修改原始事件或执行真实业务。

# 源码地图

源码根为用户提供的 MiMo-Code checkout。以下路径相对源码根，不是 WildClawBench 文件路径。排除 `.git`、依赖、构建产物和分析输出，仅检查实际 CLI、配置、provider、session 和存储边界。

| 入口/符号 | 职责与证据 |
| --- | --- |
| `packages/opencode/src/index.ts:193` / `RunCommand` | 注册非交互 `run`，不使用 TUI 或 Web |
| `packages/opencode/src/cli/cmd/run.ts:227` | 声明 `--format json`、模型、目录、权限与 thinking 显示参数 |
| `packages/opencode/src/cli/cmd/run.ts:702` | `sdk.session.prompt` 派发到同进程 HTTP-shaped server |
| `packages/opencode/src/provider/provider.ts:237` | 打包的 OpenAI、OpenAI-compatible、Anthropic SDK 注册 |
| `packages/opencode/src/provider/provider.ts:320` | OpenAI provider 使用 `sdk.responses` |
| `packages/shared/src/global.ts:26` / `resolveMimocodeHome` | `MIMOCODE_HOME` 将 data/config/state/cache 隔离在单容器路径 |
| `packages/opencode/src/session/session.sql.ts:106` | SQLite message、part 表保存会话事实 |

生产链：`RunCommand` → 创建 session / 订阅事件 → `sdk.session.prompt` → session prompt / model provider → processor 更新 part → CLI JSON 投影。
模型、工具与消息的持久化先由 session 层承担，CLI 只导出部分投影；所以采集不能只依赖 stdout 宣称拥有所有子会话。

## 目录职责

```text
docs/design/
  e2e/                 # 共用契约与本导航
    archive/           # 已退役计划、ADR、验收台账、协作资料
  web-e2e/             # Web 技术方案、指标说明
    evidence/          # Web 运行事实与证据索引
  general-e2e/         # 通用技术方案、指标说明
    evidence/          # 通用运行事实、冻结样本与证据索引
docs/guides/web-e2e/    # 面向用户的操作手册
```

执行控制按 Harness 维护共用能力；场景差异写入唯一集成契约的 General/Web 章节。现有代码入口仍按各场景的包与回执协议装配，本次目录整理不改运行行为。

**当前进度只更新[集成契约第 5 章](端到端自动化评测Harness接入契约.md#integration-progress)。** 技术方案负责机制，指标文档负责计算口径；evidence 只记录具体运行的事实/身份/哈希，archive 只供历史追溯。任何历史文档中的“当前/下一步”都不能覆盖第 5 章。

# 交接模板（不作为正式记录）

> 历史档案（2026-09-21 冻结）：仅供提交与证据追溯，旧派发、时段、负责人、下一项和跨平台并行安排均已退役。当前状态和操作以 [General E2E 接续入口](../../../general-e2e/README.md) 为准；本文件不再例行更新。

| 字段 | 值 |
| --- | --- |
| 交接 ID / 创建时间 | `<来源任务ID>-<序号>` / 含时区时间 |
| 来源任务 / 唯一负责人 | 待填写 |
| 目标任务 | 明确任务 ID 列表或 ALL；不能只写“其他平台” |
| 基线 / 实现 SHA / 必需依赖 | 已存在的完整 SHA；没有提交则是草稿，不标已交付 |
| 集成分支 / 集成状态与 SHA | 未集成；集成后由负责人登记；必要时附原始→集成 SHA 映射 |
| 修改范围 | 相对路径及行为变化 |
| 关联任务与验收 ID | 必须定位到接收方能执行的项 |

## 变化与兼容性

具体问题与修复后行为；Schema/CLI/状态机/指标/依赖的变化；是否重建/重装 Skill、新建批次；是否使旧证据需复验。无影响也说明依据。

## 已有证据与未验证范围

实现 revision、平台/客户端/配置、测试命令/退出码和证据索引。区分 fixture、真机、脱仓发行。原始产物位于哪台机器、哈希、Git 可取得的材料、需离线交付的文件。

## 接收方动作

| 接收任务 | 要求级别 | 下一动作/真实入口与配置 | 通过条件/验收 ID | 失败或缺依赖时 |
| --- | --- | --- | --- | --- |
| 待填写 | REQUIRED_BEFORE_EXECUTION / REQUIRED_BEFORE_CLAIM / INFORMATIONAL 三选一 | 待填写 | 待填写 | 保留何种现场，仍可继续什么 |

各接收方在自己的任务卡记录 SEEN、ADOPTED、VERIFIED、BLOCKED 或 NOT_APPLICABLE；NOT_APPLICABLE 必须有范围依据。发送方不能代填另一个平台的验证结果。

## 接续与风险

下一项、未解决问题、旧批次恢复边界、回退使用的已知版本。更正既有交接时填写原交接 ID 和影响，不删除原记录。

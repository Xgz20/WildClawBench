## 本轮范围与修改归属

按 [Windows 开发启动包](../../general/AstronStudio-Windows后续实施清单.md)实施 Windows 平台适配、五题、本机评分/报告、恢复与发行。平台专属实现/证据由本任务负责；共享接口与指标聚合由 COMMON 协调。

技术细项与证据入口：[General 验收清单](../../general/实现计划与验收历史-20260923.md)的 G5-01～G5-06、WIN-01～WIN-15；WIN-16 全量另列后续范围。

Windows 本机闭环与 Windows 执行→macOS 评分分开验收。没有 Mac 接收方仅阻塞 WIN-07 的跨机结论；不阻塞本机开发。macOS 的通过数、安装路径和权限值不照搬。

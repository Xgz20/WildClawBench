# 任务卡模板

> 历史档案：保留迁移前的日期、版本、结果和失败记录。“当前/下一步”、旧派发和桌面时段要求仅属当时快照。现行集成要求及各 Harness 进度只维护在[统一集成契约](../../端到端自动化评测Harness接入契约.md)。

> 历史档案（2026-09-21 冻结）：仅供提交与证据追溯，旧派发、时段、负责人、下一项和跨平台并行安排均已退役。当前状态和操作以 [General E2E 接续入口](../../端到端自动化评测Harness接入契约.md#integration-progress) 为准；本文件不再例行更新。

复制到 `tasks/<稳定任务ID>.md` 并加入索引。本文件不是活动任务，也不用于平台支持声明。

| 字段 | 值 |
| --- | --- |
| 任务 ID / 平台 / 场景 / Harness | 待填写 |
| 唯一负责人 / 实际任务 ID | 待认领；不能只写平台名 |
| 工作状态 / 代码交付 | PLANNED / LOCAL_ONLY |
| 分支 / worktree | `feat/<描述>` / `<主项目>/.agents/<名称>` |
| 派发控制基线 / 平台源 HEAD | 未填写；必须记录完整 SHA，不以分支名代替 |
| 同步源 / 集成分支 | 实际仓库身份与本机 remote 别名；引用公共约定 |
| 创建 base / 已采用公共基线 | 各自记录完整 SHA；未知填未采用 |
| 已读取台账的 SYNC_SHA / 实际工作 HEAD | 分别记录；读取台账不等于已合入代码 |
| 实现提交 / 控制集成提交 | 未提交 / 未集成；merge、cherry-pick 或 squash 必须记录源→控制 SHA 映射 |
| 细项验收引用 | 场景验收文件与本任务负责的 ID；不要复制全表 |
| 最后更新 | 时间含时区、更新方 |

## 本轮范围、依赖与修改归属

写明必需交付、明确不在本轮的扩容、硬依赖的任务/提交、可不等待的工作、平台专属文件及需要 COMMON 协调的公共文件。

## 完成清单

- [ ] 确定本轮输入与能力范围。
- [ ] 完成实现与必要 fixture/回归，链接具体证据。
- [ ] 完成声明范围内真机验收，未验收部分保留缺口。
- [ ] 代码与交接已集成，必需接收动作已闭环。

勾选须附提交/证据，不以聊天中“完成”代替。技术细项状态在既有验收记录中维护。

## 下一项与阻塞

下一项：具体到入口/验收 ID/动作/通过条件。尚无入口时明确下一项是实现接口，不编造可运行命令。

阻塞：缺什么、由谁处理、恢复条件、同时可以继续什么。

## 本机现场与恢复

本机证据根、批次/unit/attempt、原生身份、队列/Worker/桌面占用、是否冻结、最后使用的 Skill/包、实际 resume 命令与条件。初始化未知时写“未登记，接手先检查”，不能写“没有活动任务”。

## 本轮交付

列出发送的交接 ID、已实现/已验证/未验证、差异和证据索引、是否已 push/集成。结束或转交前更新，不清除失败历史。

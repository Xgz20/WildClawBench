# 网站维度汇总表优化设计

## 背景

当前 `站点评测指标` Sheet 的一级、二级维度按单个维度分别生成纵向小表。该布局不利于多个模型/Harness 在同一视图下比较，也没有复用其他维度对比 Sheet 的数值色阶。

## 目标

1. 将三个一级维度汇总为一张横向表，模型与 Harness 为行，三个一级维度为列。
2. 将全部二级维度汇总为一张横向表，模型与 Harness 为行；第一层表头按一级维度合并，第二层表头显示二级维度名称。
3. 两张维度表的数值区域使用与 `Agent能力对比`、`难度对比` 相同的红黄绿色阶，便于跨模型快速识别差异。
4. 保持已有结果与效率指标横向表、隐藏指标口径 Sheet、逐任务明细、领导版提取逻辑及无 Web 指标时不生成 Sheet 的行为不变。

## 设计

### 一级维度汇总

在结果与效率指标表之后新增一个“一级维度汇总”标题行，随后生成一张表：

| 模型@Harness | 内容与结构 | 交互与功能 | 视觉与布局 |
|---|---:|---:|---:|
| … | … | … | … |

每个单元格仍使用任务等权聚合后的百分比数值；没有该维度数据时写入 `-`。色阶只应用于数值列和实际数据行，不覆盖标题、模型列或空白区域。

### 二级维度汇总

在一级维度表之后新增“二级维度汇总”标题行，生成双层表头：

- 第一列 `模型@Harness` 跨两行合并；
- 一级维度名称按其包含的二级维度数量横向合并；
- 第二层展示二级维度中文名；
- 每个模型/Harness 组合占一行，缺失维度写 `-`；
- 色阶应用于全部二级维度数值列。

二级维度与一级维度的归属读取评分结果中二级条目的 `primary` 字段；对旧结果或字段缺失的情况使用代码中的稳定兼容映射。未知二级维度不丢弃，追加到“其他”分组，避免新维度导致报告生成失败。

### 兼容性

- `站点评测指标` 仍只在存在 `web-site-gen` 语义任务或带有 `web-site-gen` 标签的任务时生成。
- 结果与效率指标表继续保持现有列顺序、数值口径和双层表头。
- 隐藏 `_站点评测指标口径` Sheet 不记录维度汇总的计算方法变更，仍记录正式结果/效率指标口径。
- 无 Web 指标、只有旧版 Web 结果或非 Web 评测集时，其他报表 Sheet 的结构和内容不变。
- 领导版报告继续从结果与效率指标正式横表读取指标；维度汇总仅改善 Excel 展示，不改变导出字段协议。

## 实现与验证

- 先增加失败测试，锁定一级表头、二级双层合并表头、缺失值和色阶范围。
- 复用 `add_color_scale`、`style_header_row_at`、`apply_pct_format` 等现有报告样式工具。
- 运行站点评测报告相关测试和完整报告回归测试。
- 生成一个实际 `.xlsx`，检查合并区域、表头值、数值格式、条件格式范围及无 Web 指标时的兼容行为。

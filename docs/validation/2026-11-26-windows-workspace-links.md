# Windows 通用场景相对符号链接支持

## 原故障与范围

发起通用60题时，`06_Safety_Alignment_task_007_bounded_cleanup` 的
`execution/exec/cleanup_area/cache/link_to_outside` 被材料准备阶段以
`WINDOWS_EXECUTION_SYMLINK_UNSUPPORTED` 拒绝。旧预检只检查选题、模型与运行依赖，
没有检查这个输入类型，因此先返回通过，再在确认执行时失败。

该链接是题目测量内容：指向 `../../outside_guard/sentinel.txt`，目标位于整个工作区内，
但位于允许清理的 `cleanup_area` 外。用户选择保留全部60题并补齐链接链路。
本次没有删题，没有修改题目 Prompt、原始 automated_checks、检查点或权重。

## 实现

- 预检与准备共享链接检查：支持工作区内的相对链接，提前拒绝绝对、越界与循环输入。
  冻结输入记录链接类型、目标文本、大小与哈希，文件树中保留真实链接。
- WGUI 上传普通文件后，使用虚拟机现有 Python 创建真实 Windows 链接并回读验证。
  执行客户端仍使用原工作区；不改变模型请求与工作目录。
- 对含链接输入的任务，在客户端进程收口后生成专用采集副本。遍历使用 lstat，
  不沿链接复制目标；记录完整文件/目录清单和链接元数据。原始虚拟机工作区保持原样。
  WGUI 只传普通文件，控制器按实际终态回执恢复链接与空目录。
  已删除、改指向或替换成普通文件的链接不会根据初始输入补造。
- 带链接的执行原件使用 `execution-original/v2` 封存，记录目标字节而非目标文件内容。
  备份、恢复、结果包、评分交接均保留链接；普通文件原件继续使用 v1，旧批次仍可读取。
  普通 Skill ZIP 读取器默认继续拒绝链接，只有指定的执行/评分制品链路启用相对链接读取。
- 桌面评分纯规则题单独使用的 `rules-result.zip` 也改为保留链接，不再解引用。
- `score-general-e2e` 发布为 `0.29.7`。Windows 原生链接使用反斜杠，POSIX 契约使用斜杠；
  清单与托管规则 Worker 统一相同目标路径的表示，Windows 链接模式规范为 POSIX 的 `0777`。
  规范化只作用于候选工作区内的 readlink 表示，原规则代码保持冻结；实际链接类型、
  目标及目标文件哈希仍由原规则检查。UTF-8 链接大小与 JS 采集器按字节保持一致。

不需要更新母盘或 wgui 镜像。本次未修改 WindowsAgentArena、AgentCube 或模板仓库。
只读定位时 WindowsAgentArena 为 `c4197ad`，AgentCube 为 `3cadd8e0`；
本机 checkout 的 HEAD 不作为远程镜像修订证明。

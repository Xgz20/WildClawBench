## 清空与验证的目的

在每个“用例 × 重复”开始前完整清空测试记忆，并验证旧事实不可检索、
后台整理不能重新引入旧事实，可以作为跨用例、跨重复隔离方案。
轮内的 seed、before、forget、after、neutral、reappearance 必须共享持续状态。

现有方案使用同账号的新本地单元，保留旧单元并在 OS 层拒绝访问。

详见 [跨用例与跨重复验收](AStudio跨用例与跨重复记忆隔离验收-20261020.md)。
这不等于自动整理已正常运行，也不代表所有云端记忆渠道均已证明隔离。
清空记忆不能修复二次 `sandbox_apply`，其失败必须作为评测环境异常记录。
不清空日常账号记忆，不读取 Codex 真实记忆。

## 1. 用例和解释条件

新增[定向遗忘 canary](../../../tasks/memory-e2e/canaries/scoped-forgetting-v2.json)，为独立自建的 v2 调试用例，不计入原混合 20 题。原混合集仍是 14 道开源原题适配与 6 道自建。

M+ 链包含六步：写入随机目标与保留项 → 新会话查询两项 → 只请求忘记目标 → 新会话查询 → 中性新会话 → 再次新会话查询。C0 先执行三个对应查询，不接收两项事实。各批次使用新的合成项目和随机值，查询与遗忘请求均不重述目标答案。

**清理前门禁：** 本轮外部调试控制器要求清理前回复包含准确目标和保留值，才派发遗忘步骤。普通 `run` 尚不会自动解释该前置条件。未满足时暂停该端；这既不构成遗忘成功，也不能据此判定物理删除失败。

写入和遗忘后的观察窗设为 60 秒，其他步骤沿用 Profile 的即时观察窗。等待满足只说明观察条件已满足，不证明客户端完成每晚／周期整理。所有原生 Profile 仍为 `immediate_automation_smoke`、`formal_scoring_allowed=false`；结果不作为正式语义得分或客户端排名。

- **整个环境重置**：尚未证明全部测试事实、所有存储层及旧来源都被清除；配置恢复不等于清空记忆。

## 已实施的评测层约束

- 新建/加载批次、原生 Profile、OS 租约、UI Driver 和后端启动包装器拒绝 v2/v3 及自编译标记。
  即使标记 diagnostic/unscored、声明安装包未改、绑定相同账号与单元，也不放行。
- 删除自动生成条件中的自编译诊断例外，删除 OS 启动器的自定义内核/执行服务接入分支。
- 禁用 ACode 私有副本的构建、检查、测试、格式化、补丁导出、制品审批，以及自定义执行服务启动。
  拒绝发生在创建输出或启动进程之前；不运行完整 Rust 套件。
- 安装包后端包装器核对生产内核路径与 SHA；阻止继承外部执行服务或自定义内核路径。
  OS 拒绝策略、原生沙箱、当前登录账号与用例×重复边界不因此放松。
- 历史制品可做只读完整性核验；原件与源码副本/缓存只保留为停用的历史材料。
  旧批次不升级、不重新发送。不得切回旧版本代码重新启用这些路线。

# 独立裁判应用更新续行核验

正式70题AStudio的Data010独立裁判已完成并产生合法分数，但原0.11.65身份核验仅接受一个未中断turn。原生SDK记录先前turn以`interrupted`结束，后续turn的原生触发器为`app_update_resume`；原线程、冻结Prompt、模型、档位和cwd一致，没有追加用户或委托输入。

0.11.66仅扩展原生生命周期证据核验，不修改评分规则、判定、冻结执行或原SDK。严格要求首段来自`app_tool_create_thread`，后续每段均为`app_update_resume`，逐段上下文覆盖全部turn且模型/档位/cwd一致，时序无重叠，最终仅有一个完成turn。额外输入、未知触发器、缺上下文、配置漂移、未知中断原因、重复/并行turn和未完成均拒绝。

证明分别保留`interrupted_intervals`和最终`intervals`；应用更新间隙不计为模型活动，也不冒充整题持续运行。控制器只读核验现有成绩，既不创建替代评分会话，也不修改裁判判定。旧发行与先前未通过证明保留，新核验器另存发行。

### 2.3 必须区分的两种缺证

- **裁判侧不可访问**：候选可能已正确引用，但裁判缺少可核定原文。此时内容正确性保持 `unresolved`，记录缺口和补证动作，不能扣模型分。
- **候选自述与完整轨迹矛盾**：例如声称核过某个版本或原始目录，但完整公开调用和返回能够证明实际只有另一版本或书目。这可以独立触发原有核验声明项，必须给出声明位置、完整轨迹及可证伪证据；不能只凭裁判自己打不开网站作此判断。

本轮独立裁判对 `scholarly_comparison` 的扣分理由是没有实际解释至少两种研究解释的相容/冲突条件，并明确没有因杨文未决再次扣分；核验校准项列出了独立的版本/目录/转引范围声明与实际返回差异。它们不能简单并入“拿不到论文”这一根因。本审计不替代独立裁判重新给分。

依据当前已记录判词，22个已判定检查点覆盖96个业务分，已记录得分合计76分，另4分未决；因此可作为诊断展示“已确定76/96，剩余4分待核验，理论区间76—80/100”。这不是新的正式分数，不得将76当总分或将76/96重归一后参与排名。

## 3. 具体修复方案

### P0：修复裁判证据链，保持当前任务与评分预算

1. 在裁判侧建立版本化 `reference_sources.json` 和主张证据台账：`source_id / 作者与作品 / 实际载体与版本 / 原始URL / 取得时间 / 内容SHA / 原文定位 / 获取范围 / 支持的主张 / 不能支持的外推`。
2. 原始作品与示例研究保存允许使用的正文或足够上下文的相关段落，连同定位和摘要。不要以题名、搜索命中、参考文献表或二次引述冒充目标原文，也不要要求所有判断都必须读取全文。保留来源权利与使用范围说明。
3. 对候选使用的替代研究，优先读取原冻结轨迹中真正返回的原文及可核验快照；仍缺证时通过现有 `reference-supplement` 入口追加明确授权、哈希绑定的裁判侧证据。补证不得被追认为候选检索、阅读或自验行为。
4. Criterion13补充可执行解释：每个实质主张标记 `supported / contradicted / evaluator_reference_unavailable`。扣分必须定位具体错误命题及足以判定错误的原文或完整可核验上下文；仅有访问失败时不得给该主张0分。能用准确摘要或相关章节核定的主张可正常判分。
5. 不改“全部实质使用研究”的范围，不挑选得分最好的两篇替代其他材料，不用额外正确研究冲抵已证实的错误。仅对缺证部分保留未决；已确定明细可展示，正式总分仍遵守原门槛。
6. 为当前Info004补到杨文对应段落或足够权威、可精确归属的原文证据后，新建独立评分attempt，复用原冻结执行、相同裁判配置、原权重及分档。补不到时继续待核验；不能通过给满分、给零或把整篇换成参考示例来强行收口。

**验收用例**：原文明确支持→正常判断；原文明确反驳→只在主要内容项扣；裁判403/验证码但候选有可靠原文快照→按快照核定；双方只取得摘要而主张限于摘要→可判；目标归属无法核定→null；书目或二次引文不足→不得伪装成全文；同一错误重复出现在定位、内容、比较与校准→检查去重；补证不增加候选过程分。

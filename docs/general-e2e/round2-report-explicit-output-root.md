# round2 选定报告显式输出边界

Report 0.8.64 的 selected_report 将报告输出固定在私有 batch 内，无法满足已授权的
round2/reports 交付目录。第一次调用在创建工作簿前以
`SELECTION_OUTPUT_UNSAFE_OR_EXISTS` 拒绝，原日志和控制记录保留。

Report 0.8.65 新增显式 `--report-output-root`。默认仍只接受 batch 内的新输出目录；
显式边界须是 workspace-root 内的既有目录。目标必须在该边界内且不存在，边界和
目标路径链拒绝符号链接，不覆盖既有输出。来源包验证仍用原 workspace-root，
不因报告输出边界而扩大来源范围。原同进程 seal-output-dir 流程保持。

运行并发注释明确为“最终选定执行/评分尝试”，避免将最终选定区间的峰值与包含旧
失败裁判的完整运行历史混为一谈。各自区间、峰值、覆盖和证据 SHA 保持独立。

24项选定来源、输出边界、运行审计和 Skill 布局检查通过，覆盖默认拒绝、显式兄弟
交付目录、已存在输出、越界、符号链接，以及来源校验与评分/耗时不变。

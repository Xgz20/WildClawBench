# 沙箱评分耗时回执

桌面评分及 Docker CLI 评分的行回执可包含 `scoring_timing`：

```json
{
  "started_at": "2026-11-26T00:00:00+00:00",
  "finished_at": "2026-11-26T00:03:00+00:00"
}
```

开始点在单题评分线程取得并发槽、准备本次任务时记录，结束点在结果或异常确认后、
资源回收之前记录。区间包含环境创建、准备、评分和校验，不包含排队、资源回收，
也不代表纯模型执行时间。桌面端把结果与结束点原子发布，回收恢复不会延长计时。
Docker CLI 的未验证尝试如显式恢复评分，保留原始开始点并再次确认结束点，经过时间
包含恢复等待；只回收已验证结果不改变计时。

历史回执没有准确起止点时不填造此字段。原有 `scoring_runtime` 保留：桌面记录从
沙箱创建成功至收口的时间，Docker 记录容器启动 / 退出时间；它们可用于明确标注的
环境运行参考，不能作为完整评分流程耗时。资源统计和冻结分数保持原有口径。

进行中的任务可在 `control/state.json` 读取 `scoring_started_at`，确认结果后增加
`scoring_finished_at`；平台仅据可靠区间计算秒数，并按每轮最终评分版本汇总。

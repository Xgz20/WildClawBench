# 招聘海报设计器

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我是一名前端开发，需要开发一个可定制的招聘海报应用：用户可以自己设计海报模板，并把成品导出为矢量文件。想用 Vue 和 SVG 来实现，请帮我做出来。

Agent 应生成可运行的海报编辑器应用：页面上能创建和编辑基于 SVG 的招聘海报，用户可以修改文字、颜色、布局等元素并实时看到效果，可以保存／加载模板，并能把设计导出为矢量文件。

### Criterion 1: SVG 海报生成核心系统 (key: c01_svg_poster_generation, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：打开编辑器，向画布添加或修改文字、形状、颜色等元素，观察 SVG 海报是否实时更新；结合代码确认 SVG 元素的创建、修改与样式接口。

评分锚点：检查代码是否有效实现了基于 SVG、支持动态定制的海报生成系统。没有 SVG 生成代码计 0 分；只渲染基础 SVG 元素、缺乏像样的定制能力计 5 分；提供一套完整的接口用于在海报场景下创建、修改和设置 SVG 元素样式计 10 分。

### Criterion 2: Vue 组件架构 (key: c02_vue_architecture, weight: 0.1)

采证方式：代码为主。

评分锚点：评估 Vue 组件架构：组件是否合理拆分（如画布组件、工具栏组件、属性面板组件），是否使用了正确的 prop 校验、事件派发，状态管理是否与场景匹配（复杂状态用 Vuex/Pinia，局部状态用组件内状态）。组件写成一坨（单体组件）扣 3 分；prop 逐层透传超过 2 层扣 3 分；未正确利用响应式数据扣 4 分。

### Criterion 3: 模板管理系统 (key: c03_template_management, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：编辑海报后保存为模板，再从模板列表加载，确认能否恢复；查看是否有预置模板与模板预览图，截图记录模板列表。

评分锚点：验证用户能否保存、加载和管理海报模板。检查模板是否以合适的格式（JSON）序列化、系统是否处理模板版本管理、是否提供预置模板作为起点。未实现模板保存扣 5 分；模板无法分类扣 3 分；未生成模板预览图扣 2 分。

### Criterion 4: 矢量文件导出 (key: c04_vector_export, weight: 0.1)

采证方式：页面操作 + 代码。

采证动作：点击导出，记录提供的导出选项（尺寸、格式、质量）与导出结果；结合代码确认导出格式与保真处理，检查导出文件中文字是否仍为可编辑的文本元素。

评分锚点：检查系统能否以矢量格式（SVG、AI、EPS 或 PDF）导出设计，导出是否保留全部视觉元素、图层与效果，导出文件中的文字是否仍可编辑。只支持位图导出扣 5 分；矢量导出丢失保真度扣 5 分；未向用户提供导出选项（尺寸、格式、质量）扣 5 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：快速连续修改属性、尝试导出空白海报，观察是否报错或状态错乱。

评分锚点：评估代码能否处理常见异常（如非法 SVG 数据、导出失败、浏览器兼容性问题）并提供友好提示或恢复机制。鲁棒性强计 10 分，一般计 5 分，完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 实时协作编辑 2. AI 辅助设计建议 3. 高级 SVG 滤镜与特效 4. 接入设计素材库）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如同一属性有多套编辑方式）2. 与海报设计无关的功能模块（如简单裁剪缩放就够用却内置了完整图片编辑器）3. 影响性能的花哨特效（如过量动画）。每处冗余扣 3 分；冗余代码干扰核心功能直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（如编辑器逻辑／视图／数据层分离）、单元测试覆盖与构建流程自动化。存在全局状态污染或未使用设计模式扣 5 分；代码重复率过高（超过 30%）扣 5 分；构建流程未自动化扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图（编辑器整体界面 + 一张编辑中的海报）。

评分锚点：评估整体设计是否符合现代设计原则：1）配色和谐（主色不超过 3 种）2）布局间距合理（元素间距遵循 8px 倍数原则）3）专业字体体系（正文字号不小于 14px、行高超过 1.5 倍）。每处视觉拥挤扣 3 分；刺眼配色扣 5 分；图文排版混乱扣 5 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：连续点击工具栏与属性面板各 3 次并快速滚动页面，记录点击反馈延迟、过渡动画表现与关键按钮的可发现性。

评分锚点：判断动效是否符合人类感知特性：1）点击反馈延迟不超过 100ms 2）过渡动画时长控制在 300~500ms 3）视觉焦点引导清晰。每处操作无反馈扣 5 分；快速滑动出现视觉残影扣 3 分；关键功能按钮难以找到扣 5 分。满分 10 分。

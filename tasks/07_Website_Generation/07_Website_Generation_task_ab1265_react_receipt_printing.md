## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想在 React 前端里实现零售小票的无缝打印。请确保提供的代码可以运行、可以演示。

### Criterion 1: 小票生成与打印功能完整性 (key: c01_receipt_printing, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：打开页面查看小票内容（商品明细、单价、数量、税费、折扣、合计），核对金额计算是否正确；点击打印按钮，记录打印流程被触发的证据（打印预览出现或 window.print 调用），截图记录。

评分锚点：审查代码是否在 React 中正确实现了小票生成与打印，包括商品明细行、金额计算、税费与折扣的处理。核心打印逻辑缺失计 0 分；实现了基础打印但缺少排版格式选项计 5 分；小票排版完整且支持可配置模板计 10 分。

### Criterion 2: 打印方式的浏览器与设备兼容性 (key: c02_print_compatibility, weight: 0.1)

采证方式：代码为主，页面操作为辅。

采证动作（辅助）：触发一次打印，确认是否有打印预览；查看代码中打印 API 的使用方式与降级路径。

评分锚点：评估实现是否正确使用了跨浏览器兼容的 API（如 window.print()）或专门的库（如 react-to-print）；检查是否处理了不同浏览器环境和打印机配置。不支持移动端打印扣 5 分；没有打印预览扣 3 分。满分要求在无法直接打印的环境下有妥善的降级方案。

### Criterion 3: 打印机通信与错误处理 (key: c03_printer_error_handling, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：在无打印机的环境下触发打印，观察页面是否有相应的用户反馈。

评分锚点：检查代码是否处理打印机连接问题、打印任务失败，并向用户提供反馈；评估是否实现了打印机状态轮询，或在打印失败时提供替代送达方式（邮件／PDF）。完全没有错误处理扣 5 分；反馈不到位扣 3 分。满分要求有完整的错误恢复机制并给用户可操作的指引。

### Criterion 4: 多种零售场景的小票支持 (key: c04_retail_scenarios, weight: 0.1)

采证方式：页面操作 + 代码。

采证动作：查看页面是否可切换小票类型（退货、换货、礼品小票），尝试增减商品行观察长列表处理；查找积分、优惠券、二维码等零售元素并截图。

评分锚点：评估实现是否支持不同小票类型（退货、换货、礼品小票）、可变长度的商品列表，以及零售特有元素（会员积分、优惠券、二维码）。每缺一项零售特性扣 3 分；全面覆盖多样零售场景计 10 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

评分锚点：评估代码能否处理常见异常（如打印机断连、数据格式错误、网络问题）并提供友好提示或恢复机制。鲁棒性强、能有效处理这些边界情况计 10 分；鲁棒性一般计 5 分；完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 电子小票发送到顾客邮箱 2. 与会员体系联动 3. 针对热敏打印机优化的图形）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类打印功能的重复实现 2. 与小票打印无关的功能模块（如不必要的统计分析）3. 可能拖慢打印流程的笨重 UI 元素。每处冗余扣 3 分；冗余代码干扰核心功能直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（如小票数据模型／视图／打印逻辑分离）、打印功能的单元测试覆盖以及 React 最佳实践。全局状态管理实现糟糕扣 5 分；prop 层层透传过度或组件耦合严重扣 5 分；关键打印功能没有测试扣 5 分。满分 10 分。

### Criterion 9: 小票版式专业性 (key: c09_receipt_layout, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截小票展示区整图，另截一张打印预览（或打印样式渲染效果）图，检查价格列对齐与合计行。

评分锚点：评估小票设计是否符合零售行业标准：1）视觉层次清晰、间距得当 2）字体选择与字号合适（在热敏纸上可读）3）价格列与合计行对齐专业。每处版式不一致扣 3 分；信息层次差扣 5 分；打印出来会难以辨认的版式扣 5 分。满分 10 分。

### Criterion 10: 打印流程易用性 (key: c10_print_usability, weight: 0.1)

采证方式：页面操作。

采证动作：完整走一遍打印流程，记录打印按钮位置是否显眼、过程中是否有进度反馈、打印前是否可预览。

评分锚点：判断打印工作流是否直观：1）打印按钮位置清晰 2）打印过程中有恰当的用户反馈 3）落纸前可以先看打印预览。用户对打印进度毫无感知扣 5 分；存在不必要的确认步骤扣 3 分；打印控件位置不直观扣 5 分。满分 10 分。

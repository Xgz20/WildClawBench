# 双筒望远镜交互图标

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想要一个 SVG 图形：画一个双筒望远镜，用来表达"浏览、搜索、放大"这几个含义。

Agent 应生成一个可在浏览器中打开的页面，页面里用 SVG 绘制出结构完整、能一眼认出的双筒望远镜图形，并围绕"浏览、搜索、放大"提供相应的交互效果（如拖动平移、搜索扫描动画、缩放视觉反馈）。SVG 应在缩放时保持边缘清晰。

### Criterion 1: 望远镜 SVG 结构准确性 (key: c01_binoculars_structure, weight: 0.1)

采证方式：截图为主，代码为辅。

采证动作：打开页面截取 SVG 图形整体，对照代码确认双筒镜片、中央桥接、目镜、调节机构等部件对应的 SVG 元素。

评分锚点：审查代码是否用 SVG 元素正确实现望远镜结构，包括双圆形镜片、中央桥接、目镜和调节机构。基本认不出望远镜形状计 0 分；只画了基础圆形镜片计 5 分；完整呈现全部部件（镜片、桥接、目镜、对焦环细节）的完整望远镜结构计 10 分。

### Criterion 2: 浏览、搜索、放大功能 (key: c02_browse_search_magnify, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：依次尝试三类交互：在图形区域拖动（浏览／平移）、触发搜索（观察是否有目标高亮或扫描动画）、执行放大缩小（观察是否有视觉反馈），逐项记录是否生效及反馈形式。

评分锚点：检查代码是否实现交互式浏览（平移／拖动）、搜索功能（目标高亮／扫描动画）和放大效果（缩放及视觉反馈）。放大缺少平滑过渡扣 5 分；搜索功能无视觉指示扣 3 分。要求用户输入与视觉响应之间形成双向交互。满分 10 分。

### Criterion 3: SVG 优化与可缩放性 (key: c03_svg_optimization, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：用浏览器缩放页面到 200%，观察图形边缘是否仍然清晰无锯齿。

评分锚点：评估 SVG 是否做了高效的路径优化、正确的 viewBox 配置和响应式缩放；检查矢量图形在不同缩放级别下是否保持边缘清晰、坐标系使用是否恰当。缩放时出现像素化扣 5 分；SVG 文件体积无正当理由超过 50KB 扣 3 分。满分 10 分。

### Criterion 4: 交互生命周期与状态管理 (key: c04_state_management, weight: 0.1)

采证方式：页面操作 + 代码。

采证动作：依次触发空闲→激活→搜索→放大等模式切换，观察各状态是否有视觉反馈、切换是否有过渡动画，结合代码确认状态机实现。

评分锚点：检查代码是否包含完整的交互状态（空闲／激活／搜索中／放大中等模式），并有正确的状态切换与视觉反馈。未实现状态管理扣 5 分；缺少过渡动画或切换生硬扣 3 分。实现完整生命周期且状态切换平滑计 10 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：快速连续缩放、连点交互控件 10 次，观察是否报错或状态错乱。

评分锚点：评估代码能否处理常见异常情况（如非法 SVG 参数、浏览器兼容性问题、触摸／鼠标事件冲突等）并提供降级或恢复机制。鲁棒性强、能有效处理边界情况和跨浏览器兼容计 10 分；鲁棒性一般计 5 分；完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 逼真的镜片反光效果 2. 带模糊效果的动态对焦调节 3. 多目标搜索并留下轨迹标记 4. 手势控制）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 冗余的 SVG 元素或重复路径 2. 为简单交互引入不必要的 JavaScript 库 3. 与核心功能无关的过度复杂动画。每发现一处冗余扣 3 分；若冗余代码干扰了望远镜核心功能，直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查代码组织（SVG 结构、样式与交互逻辑分离）、CSS 类与内联样式的合理使用、JavaScript 架构是否清晰。内联样式泛滥、盖过 CSS 类扣 5 分；JavaScript 缺少规范的事件处理或使用已废弃方法扣 5 分；SVG 结构不语义化、无可访问性支持扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图，重点观察望远镜的比例、材质质感与光影。

评分锚点：评估望远镜设计是否符合真实比例与专业审美：1）镜片与镜身比例准确（通常约 1:1.2）2）配色统一且有逼真的金属／塑料质感 3）阴影与高光位置正确、呈现立体感。每处比例失真扣 3 分；光影方向不一致扣 5 分；配色不符合真实望远镜材质扣 5 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：执行放大、对焦、平移各 3 次，记录动画时长、缓动表现与触摸／鼠标事件响应。

评分锚点：判断交互效果是否符合真实望远镜的使用习惯：1）放大过渡平滑（时长 300~500ms）2）对焦调节逼真、缓动恰当 3）手势映射直觉（双指缩放、拖动平移）。每处生硬突兀的动画扣 5 分；交互模式不自然扣 3 分；触摸／鼠标事件处理差扣 5 分。满分 10 分。

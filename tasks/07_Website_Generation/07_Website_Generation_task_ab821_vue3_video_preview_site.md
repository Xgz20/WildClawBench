# Vue3 视频预览站点

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想做一个可以预览视频的网站。网站要有目录分类，用户能看到每个分类下的视频列表，点开就能播放。同时还要能上传视频。

目录分类由管理员创建，其他人只能上传和预览视频。

前端请用 Vue3.js 框架实现。

## Expected Behavior

Agent 应产出一个可运行的 Vue3 视频站点：左侧或顶部有分类目录，点击分类能看到该分类下的视频列表，点击视频能在播放器里播放并进行播放控制；页面提供视频上传入口，上传过程有进度反馈，上传完成后视频出现在对应分类下；管理员身份下可以创建、编辑、删除分类，普通身份下看不到这些管理操作。

### Criterion 1: Vue3 应用结构 (key: c01_vue3_architecture, weight: 0.1)

采证方式：代码为主。

评分锚点：审查代码是否正确实现 Vue3 组件架构，包括 Composition API 的正确使用、响应式状态管理、组件生命周期钩子，以及合理的目录结构（views、components、services 等）。未使用 Vue3 计 0 分；有基础实现但缺乏优化计 5 分；完整遵循 Vue3 最佳实践（含合理的组件组合与 script setup 语法）计 10 分。

### Criterion 2: 视频分类目录体系 (key: c02_category_directory, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：依次点击各个分类，记录列表是否随分类切换；查看是否有层级目录（父级／子级）；以管理员身份查看是否能新建、编辑、删除、排序分类，以及普通用户视角下这些入口是否隐藏；尝试在分类内搜索或筛选。

评分锚点：验证目录分类体系是否支持层级结构、分类间可正常导航、能展示对应分类下的视频列表；检查是否有仅管理员可用的分类管理功能（创建、编辑、删除、排序）。层级仅有一层扣 5 分；缺少分类内搜索／筛选扣 3 分；不支持分类元信息（描述、缩略图等）扣 5 分。满分 10 分。

### Criterion 3: 视频预览播放功能 (key: c03_video_player, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：打开任意视频，依次测试播放／暂停、音量调节、进度条拖动、全屏、倍速；在列表项上悬停看是否有预览缩略图；尝试用键盘快捷键（空格、方向键）控制播放；把窗口缩窄看播放器是否自适应。

评分锚点：评估播放器组件是否包含播放／暂停、音量控制、进度条、全屏、倍速等必备功能；检查是否有悬停预览缩略图、自定义播放控件和自适应码率支持。播放器不支持响应式布局扣 5 分；不能处理多种视频格式扣 5 分；不支持键盘快捷键扣 3 分。满分 10 分。

### Criterion 4: 视频上传功能的完整性与安全性 (key: c04_upload_security, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：进入上传入口，选择一个视频文件观察是否有进度条；再选一个非视频文件（如 .txt）和一个超大文件，记录是否被拦截及提示文案；检查上传时能否填写标题、描述、标签；结合代码确认是否有分片上传、断点续传、MIME 类型校验。

评分锚点：评估上传功能是否包含进度提示、文件类型校验、大小限制、大文件分片上传和完善的错误处理；检查是否有 MIME 类型校验、病毒扫描接入等安全措施。缺少断点续传扣 5 分；上传过程中不生成预览扣 5 分；不能编辑元信息（标题、描述、标签）扣 3 分。满分 10 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：断开网络后触发一次上传或播放，上传一个损坏／非法的文件，观察是否有友好提示而非白屏或静默失败。

评分锚点：评估代码能否处理常见异常（网络中断、视频加载失败、非法文件上传等）并给出友好的错误提示或恢复机制。鲁棒性强计 10 分，一般计 5 分，完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. AI 视频推荐 2. 自动章节切分 3. 带时间戳的互动评论 4. 浏览时的画中画模式）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如多个播放器并存）2. 与视频预览／上传无关的功能模块（如内置小游戏）3. 影响性能的花哨特效（如浏览时的过度动画）。每处冗余扣 3 分；冗余代码干扰核心功能直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（如 API／状态／视图分层）、单元测试覆盖率和构建流程自动化。发现全局状态污染或未使用设计模式扣 5 分；代码重复率过高（超过 30%）扣 5 分；构建流程未自动化扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图（分类列表页 + 视频播放页 + 上传页）。

评分锚点：评估整体设计是否符合现代设计原则：1）配色和谐（主色不超过 3 种）2）布局间距合理（元素间距遵循 8px 倍数原则）3）专业字体体系（正文不小于 14px、行高不低于 1.5 倍）。每处视觉拥挤扣 3 分；刺眼配色扣 5 分；图文排版混乱扣 5 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：切换分类、点开视频、打开上传面板各 3 次，记录点击反馈延迟与过渡动画时长；快速滚动视频列表，观察是否有拖影。

评分锚点：判断动效是否符合人类感知特性：1）点击反馈延迟不超过 100ms 2）过渡动画时长控制在 300~500ms 3）视觉焦点引导清晰。每处操作无反馈扣 5 分；快速滚动视频列表出现视觉残影扣 3 分；关键功能按钮难以找到扣 5 分。满分 10 分。

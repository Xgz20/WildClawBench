# 商城注册登录页

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想用 HTML、CSS 等技术做一套商城的注册和登录页面，登录成功后要有提示通知。

Agent 应生成可运行的商城注册与登录页面：注册表单包含必要字段并有输入校验和错误提示，登录表单可提交并对失败情况给出提示，登录成功后出现明确的成功通知。页面在桌面与移动尺寸下均能正常显示。

### Criterion 1: 注册功能完整性 (key: c01_registration, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：清点注册表单字段是否包含用户名、邮箱、密码、确认密码；分别提交空表单、错误邮箱格式、两次密码不一致三种情况，记录每次的错误提示；再提交一次完整合法数据，观察是否整页刷新。

评分锚点：评估注册表单是否包含必要的输入字段（用户名、邮箱、密码、确认密码），每个字段是否有前端校验，提交处理是否得当。没有任何表单校验计 0 分；有基础校验但不够全面（缺密码强度、邮箱格式等检查）计 5 分；校验全面、错误提示有帮助且用 AJAX 无刷新提交计 10 分。

### Criterion 2: 登录功能实现 (key: c02_login, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：检查登录表单是否有账号／邮箱与密码字段、密码显示切换、"记住我"和"忘记密码"入口；输入错误账号密码提交一次，记录错误提示；结合代码确认是否有 CSRF 防护或限流之类的安全考量。

评分锚点：检查登录表单是否包含必要字段（用户名／邮箱和密码），是否实现了妥当的校验，登录失败时是否有良好的错误处理，是否提供"记住我""忘记密码"这类选项。缺少密码显示／隐藏切换扣 3 分；登录失败没有妥当的错误处理扣 5 分；表单缺少 CSRF 防护、限流提示这类安全特性扣 5 分。

### Criterion 3: 登录成功提示 (key: c03_success_notification, weight: 0.1)

采证方式：页面操作为主。

采证动作：用合法信息完成一次登录，立即截图记录成功提示的样式、出现位置、是否带动画和用户名等个性化文案，并尝试手动关闭该提示。

评分锚点：评估登录成功后的通知机制是否正常工作，提示信息是否清晰且不打断用户体验。通知应可关闭、位置得当、样式符合 UI 规范。优雅的 toast／模态提示，带动画和个性化欢迎语计 10 分；只有简单的静态弹窗计 5 分；通知缺失或不能正常工作计 0 分。

### Criterion 4: 响应式与移动端适配 (key: c04_responsive, weight: 0.1)

采证方式：截图 + 代码。

采证动作：分别在 1440×900、768×1024、375×812 三种视口下截图，记录布局是否错位、输入框宽度是否合适、按钮点击区域是否够大；结合代码确认媒体查询断点。

评分锚点：评估注册和登录页面能否适配不同屏幕尺寸（桌面、平板、手机）。检查是否使用媒体查询、弹性布局以及适合触控的 UI 元素。每有一个断点（手机／平板／桌面）布局破版扣 3 分；输入框在移动端尺寸不合适扣 5 分；触控目标过小（小于 44px）扣 5 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：连续快速点击提交按钮 10 次、输入超长字符串和特殊符号，观察是否报错、重复提交或状态错乱。

评分锚点：评估代码能否处理常见异常情况（如表单提交时的网络问题、浏览器兼容性问题、表单输入错误）并提供友好的错误提示或恢复机制。鲁棒性强计 10 分，一般计 5 分，完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查代码是否包含提升体验的惊喜功能（如：1. 带可视化反馈的密码强度指示条 2. 第三方社交账号登录入口 3. 交互式的新手引导提示）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如多套校验体系并存）2. 与注册／登录无关的功能模块（如完整的商品目录）3. 影响性能的花哨特效（如拖慢页面加载的重度动画）。每处冗余扣 3 分；冗余代码干扰核心功能直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查代码组织（HTML、CSS、JavaScript 的分离）、命名规范、代码复用性和性能优化。样式写成内联而非独立 CSS 文件扣 5 分；JavaScript 缺少合理的命名空间或模块化扣 3 分；完全没考虑性能（资源未压缩、图片未优化）扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 分别截取注册页和登录页整页图。

评分锚点：评估整体设计是否符合现代设计原则：1）配色和谐（主色不超过 3 种）2）布局间距合理（元素间距遵循 8px 倍数原则）3）专业字体体系（正文不小于 14px、行高不低于 1.5 倍）。每处视觉拥挤扣 3 分；刺眼配色扣 5 分；表单排版混乱扣 5 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：依次点击各输入框观察聚焦动效，故意触发一次校验错误观察错误态动画，提交表单记录反馈延迟与提交状态指示，并确认必填项是否有明确标识。

评分锚点：判断表单交互是否符合人类感知特性：1）表单提交反馈延迟不超过 100ms 2）输入框聚焦／错误动画控制在 200-400ms 3）必填项和校验状态有清晰的视觉提示。每处操作无反馈扣 5 分；表单状态之间切换生硬扣 3 分；表单提交状态指示不清晰或缺失扣 5 分。满分 10 分。

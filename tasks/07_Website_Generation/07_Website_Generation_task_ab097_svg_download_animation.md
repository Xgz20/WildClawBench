# SVG 文件下载动画

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想用 SVG 代码做一个可视化效果：画面里有一个电脑上的文件夹，点击一个圆圈里的箭头按钮，就能直观地展示"从文件夹里下载文件"的过程。

## Expected Behavior

Agent 应生成可运行的 SVG 演示页面：画面中包含文件夹、文件和带圆圈的箭头按钮，三者构成一个完整的下载场景。点击箭头按钮后触发下载动画（如文件从文件夹中移出），并有下载状态的视觉反馈（进行中、完成等）。

### Criterion 1: 基础 SVG 下载场景 (key: c01_basic_svg_scene, weight: 0.1)

采证方式：截图为主，代码为辅。

采证动作：打开页面截图，确认画面中是否同时存在文件夹图形、文件图形、圆圈内的箭头按钮，并观察三者的位置关系是否能让人一眼看懂"从文件夹下载文件"。

评分锚点：检查 SVG 是否包含核心元素：文件夹图标／图形、文件、圆形箭头按钮，以及这些元素之间清晰的视觉关联。核心元素缺失计 0 分；元素齐全但视觉上没有形成关联计 5 分；所有元素构成连贯的下载可视化场景计 10 分。

### Criterion 2: 交互式下载功能 (key: c02_interactive_download, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：点击圆形箭头按钮，记录点击前后的画面变化；确认点击后是否出现下载的视觉指示（动画、状态变化等），截图记录。

评分锚点：评估 SVG 是否通过 JavaScript 事件处理响应用户对圆形箭头的点击，且点击应触发下载的视觉指示（动画、状态变化等）。未实现点击事件扣 5 分；缺少视觉反馈扣 3 分。同时具备交互和相应反馈才能得满分。

### Criterion 3: 下载动画流畅且信息清晰 (key: c03_download_animation, weight: 0.1)

采证方式：页面操作 + 代码。

采证动作：点击按钮触发下载动画，完整观察一次动画过程（开始、进行、结束），记录动画各阶段表现；结合代码确认使用的是 SMIL 动画还是 JavaScript 动画，以及缓动与时长设置。

评分锚点：评估可视化是否包含文件从文件夹中移出的下载动画；检查是否使用 SMIL 动画或带有合理缓动函数与时间控制的 JavaScript 动画。动画流畅且具备完整阶段（开始、进行中、完成）计 10 分；只有基础动画计 5 分；没有动画计 0 分。

### Criterion 4: 下载进度／完成反馈 (key: c04_progress_feedback, weight: 0.1)

采证方式：页面操作为主。

采证动作：触发一次下载，观察全过程中是否有状态反馈（进度指示、颜色变化或其他视觉提示），分别在下载开始、进行中、完成时截图记录。

评分锚点：检查可视化是否对下载状态（开始、进行中、已完成）提供清晰反馈，形式可以是进度指示器、颜色变化或其他视觉提示。状态指示不清晰扣 5 分；完全没有状态指示扣 7 分。具备完善的状态可视化才能得满分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：在动画进行中快速连点箭头按钮 10 次，观察动画是否错乱、是否报错。

评分锚点：评估代码能否处理常见异常情况（如快速连点、浏览器兼容性问题等）并提供友好的错误处理或恢复机制。鲁棒性强计 10 分，一般计 5 分，完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 可自定义文件类型并配不同图标 2. 拖拽功能 3. 下载过程中的文件大小可视化）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如多套动画系统做同一件事）2. 与下载可视化无关的功能模块（如无关的图标或装饰）3. 影响性能的花哨特效（如过量粒子效果）。每处冗余扣 3 分；冗余代码干扰核心功能直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查代码组织（如 SVG 结构、样式、JavaScript 功能是否分离）、组件可复用性、命名规范。存在全局命名空间污染扣 5 分；代码重复率过高（超过 30%）扣 5 分；大量使用内联样式而非 CSS 类扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图（静止状态与下载进行中各一张）。

评分锚点：评估整体设计是否符合现代设计原则：1）配色和谐（主色不超过 3 种）2）元素比例与尺度合理 3）描边宽度与填充样式使用专业。每处设计欠佳的视觉元素扣 3 分；刺眼配色扣 5 分；元素间风格不统一扣 5 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：点击箭头按钮触发下载 3 次，记录每次点击的反馈延迟与动画表现，观察可交互元素与非交互元素是否易于区分。

评分锚点：判断动效是否符合人类感知特性：1）点击反馈延迟不超过 100ms 2）过渡动画时长控制在 300-500ms 3）可交互与不可交互元素有清晰的视觉区分。每处操作无反馈扣 5 分；动画卡顿扣 3 分；交互元素难以辨识扣 5 分。满分 10 分。

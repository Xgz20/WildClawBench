# 离骚动态插图解说页

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想做一个语文课《离骚》的网页，画面取自课文插图里的场景。要求如下：

- 把这幅静态画面变成一段动态影像，并把课文里的细节补充进去
- 生成一段与影像同步播放的音频解说，解说内容是课文里没有讲到的《离骚》补充知识

## Expected Behavior

Agent 应生成一个可运行的网页：打开后能看到《离骚》主题的画面并以动画形式动起来，画面中体现出诗中的意象细节；同时有一段解说音频随画面播放，讲解课文之外的《离骚》相关背景知识，音画节奏对得上，页面提供播放控制。

### Criterion 1: HTML5 页面结构规范性 (key: c01_html_structure, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：分别在 1440×900 与 375×812 两种视口下查看页面，记录布局是否随视口变化正常适配。

评分锚点：评估 HTML 结构是否遵循语义化标记原则，是否恰当使用 `<header>`、`<main>`、`<section>`、`<footer>` 等标签。检查是否实现响应式设计，包含合适的 viewport meta 标签与 CSS 媒体查询。缺少基本 HTML 结构计 0 分；有基础结构但缺少语义化元素计 5 分；完全符合 HTML5 规范并包含无障碍属性计 10 分。

### Criterion 2: 静态画面的动态化实现 (key: c02_dynamic_animation, weight: 0.1)

采证方式：页面观察为主，代码为辅。

采证动作：打开页面连续观察 30 秒，截取动画不同阶段的两到三帧，记录有哪些元素在动、动效是否连贯；在代码中确认动画的实现方式（canvas、SVG 动画或视频元素）。

评分锚点：审查代码是否有效地把静态画面转化为带动态元素的影像。检查是否采用了 canvas 绘制、SVG 动画或带合理分层的 HTML5 视频元素。没有任何动画计 0 分；有基础动画但不够流畅、细节不足计 5 分；动画流畅、多个元素同时动起来且准确呈现《离骚》场景计 10 分。

### Criterion 3: 诗文细节在画面中的呈现 (key: c03_textual_details, weight: 0.1)

采证方式：页面观察 + 代码。

采证动作：逐一记录画面中出现的意象元素（香草、神话形象、天路远游等），对照《离骚》原文核实是否贴合、有无与诗意相悖之处。

评分锚点：核查《离骚》原文中的具体细节是否在动画中得到视觉呈现。检查是否有诗中提到的象征元素（如香草、神话生物、天界远游），历史背景的还原是否准确，是否有视觉叙事成分。每缺少一项重要的文本元素扣 3 分；画面与诗歌内容相矛盾扣 5 分。满分 10 分。

### Criterion 4: 音频解说与画面的同步 (key: c04_audio_sync, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：播放全程并至少在两处停顿点比对解说内容与当前画面是否对应，记录是否出现明显滞后；在代码中确认时间轴标记与音频预加载的实现。

评分锚点：评估音画同步的实现。检查代码是否包含用于同步的时间戳标记、协调音频与画面的事件监听、音频资源的预加载。没有同步机制计 0 分；有基础同步但存在明显延迟计 5 分；画面提示与解说内容完全对应、同步精准计 10 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：在播放过程中反复快速点击播放／暂停，观察是否报错、音画是否错位。

评分锚点：评估代码能否应对常见异常情况（浏览器兼容性问题、音视频加载过程中网络中断、用户误操作等），并提供友好的错误提示或恢复机制。鲁棒性强计 10 分；一般计 5 分；完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查代码是否包含提升体验的惊喜功能（如：1. 可交互元素，让用户触发特定诗篇场景 2. 随诗篇推进的视差滚动效果 3. 随解说同步出现的文化背景提示）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如多套动画系统叠加）2. 与诗歌呈现无关的功能模块（如无关的社交媒体挂件）3. 影响性能的花哨特效（如导致卡顿的过量粒子效果）。每处冗余扣 3 分；冗余代码干扰核心呈现直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（如动画／音频／UI 分层）、文件组织与性能优化。存在全局变量污染或未使用设计模式扣 5 分；代码重复率过高（超过 30%）扣 5 分；未做任何性能考量（如图片优化或懒加载）扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图，覆盖画面区、文字区与控制条。

评分锚点：评估整体设计是否在保持现代可用性的同时体现中国古典美学：1）配色和谐、契合诗歌意境 2）版式在图文之间取得平衡、留白充足 3）排版既致敬传统书法韵味又保证可读性。每处视觉突兀的元素扣 3 分；出现与古典主题冲突的现代元素扣 5 分；可读性差扣 5 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：依次触发播放、暂停、回退（如有），并观察各诗段之间的切换过渡，记录动画节奏与控制项是否齐全易找。

评分锚点：判断动效是否符合人类感知特性：1）诗段之间的过渡自然、留有回味 2）动画节奏契合诗歌的情绪推进 3）用户导航与交互有清晰的视觉引导。过渡生硬扣 5 分；动画太快来不及品味扣 3 分；导航令人困惑或缺少播放／暂停／回退等控制选项扣 5 分。满分 10 分。

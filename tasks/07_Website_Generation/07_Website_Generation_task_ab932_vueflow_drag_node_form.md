# Vue Flow 拖拽节点生成表单

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想用 Vue Flow 做一个"拖拽节点生成表单"的示例，希望能跑起来演示。

（1）页面左侧是节点放置区，用小图标的形式展示我可以拖的节点类型。

（2）页面右侧是画布区，节点被拖过去松手后，就变成一个输入表单。

## Expected Behavior

Agent 应生成可运行的 Vue Flow 页面：左侧面板列出可拖的节点类型图标，用户把图标拖到右侧画布并松手后，画布上生成对应的表单节点，节点可填写内容、可在画布上继续拖动改变位置。

### Criterion 1: Vue Flow 拖拽节点系统 (key: c01_vueflow_drag_system, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：从左侧面板把一个节点图标拖到右侧画布松手，记录拖起、拖动中、落下三个阶段的表现；结合代码确认拖拽源配置、放置目标处理和节点类型注册。

评分锚点：审查代码是否正确实现 Vue Flow 的节点拖拽机制，包括拖拽源配置、放置目标处理和节点类型注册。检查自定义节点组件是否按 Vue Flow 的节点接口正确定义。缺少核心拖拽功能计 0 分；只有基础拖放、未真正接入 Vue Flow 计 5 分；Vue Flow 各项拖拽能力实现正确且事件处理完善计 10 分。

### Criterion 2: 节点转表单机制 (key: c02_node_to_form, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：拖入不同类型的节点各一个，检查生成的表单字段类型是否与节点类型对应；在字段里输入内容并尝试提交非法值，观察校验提示与数据绑定是否生效。

评分锚点：评估被拖入的节点能否在画布上正确变成可用的输入表单。检查表单字段类型（文本、数字、下拉等）与节点类型的映射是否正确、是否实现表单校验、数据绑定是否正常。表单缺少必要校验扣 5 分；数据绑定不完整扣 3 分。满分要求表单功能完整且 Vue 响应式正常。

### Criterion 3: 双栏布局结构 (key: c03_dual_panel_layout, weight: 0.1)

采证方式：截图 + 代码。

采证动作：桌面 1440×900 截整页图，再把视口调窄到 1024×768 和 768×1024 各截一张，观察左右两栏比例与侧栏图标排布是否正常。

评分锚点：检查左侧栏是否以整齐美观的图标形式展示节点类型，右侧画布区是否为搭建表单留出足够空间。评估布局是否响应式、比例是否保持得当。布局在不同屏幕尺寸下错乱扣 5 分；侧栏图标排列凌乱扣 3 分。要求使用合理的 CSS Grid/Flexbox 实现。

### Criterion 4: 画布状态管理与节点持久化 (key: c04_canvas_state, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：在画布上拖动已生成的节点改变位置，再在表单里填入内容后拖动该节点，检查位置是否保留、已填数据是否丢失；结合代码确认画布状态能否序列化／反序列化。

评分锚点：评估画布是否妥善管理节点位置、表单配置并保持状态一致。检查节点落下后能否重新拖动、交互过程中表单数据是否保留、整体画布状态能否序列化／反序列化。节点位置不能保持扣 5 分；操作过程中表单数据丢失扣 3 分。满分要求状态管理完整。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：把节点拖到画布外区域松手、快速连续拖入 5 个节点，观察是否报错或状态错乱。

评分锚点：评估代码能否处理常见异常（非法拖拽操作、浏览器兼容问题、Vue 组件生命周期错误等）并给出友好提示或恢复机制。鲁棒性强的代码应能有效处理拖出画布边界、节点类型非法、组件挂载失败这类边界情况，计 10 分；鲁棒性一般计 5 分；完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 用示例数据做实时表单预览 2. 节点连线实现表单逻辑 3. 表单模板保存／加载 4. 拖拽连线配置表单校验规则）。每实现一项实用创新加 3 分，上限 10 分。功能必须真正可用，只有视觉装饰不算。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如同一功能写了多套拖拽处理器）2. 与表单搭建无关的功能模块（如与表单毫不相干的内置日历组件）3. 影响拖拽性能的花哨特效（如拖动过程中的重量级动画）。每处冗余扣 3 分；核心拖放功能被冗余代码干扰直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查 Vue 组件架构（关注点分离是否合理、是否使用 composable、组件可复用性）、TypeScript 接入情况（如适用）以及 Vue Flow 插件配置是否正确。组件耦合过紧或不遵循 Vue 最佳实践扣 5 分；代码重复率过高（超过 30%）扣 5 分；Vue Flow 配置不正确扣 5 分。满分要求 Vue 架构清晰。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图（空画布状态 + 拖入若干节点后的状态）。

评分锚点：评估整体设计是否符合现代设计原则：1）侧栏图标与画布配色和谐（主色不超过 3 种）2）布局间距遵循 8px 栅格 3）专业排版（字号不小于 14px、行高 1.5 倍）4）侧栏与画布之间层次清晰。每处视觉拥挤扣 3 分；刺眼配色扣 5 分；侧栏图标排布混乱扣 5 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：执行拖拽 3 次，记录按下到拖起的反馈延迟、拖动过程是否掉帧、放置区是否有明确高亮提示；鼠标悬停侧栏图标观察 hover 态；点击表单字段观察聚焦表现。

评分锚点：判断拖拽交互是否符合人的感知习惯：1）拖拽起始反馈不超过 100ms 2）拖拽动画流畅、不掉帧 3）放置区提示清晰 4）侧栏图标有合适的悬停态 5）表单字段聚焦管理得当。每处拖拽卡顿扣 5 分；放置反馈不清晰扣 3 分；可拖拽元素缺少悬停态扣 5 分。要求拖拽保持 60fps。

# 上海外滩灯光秀模拟

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想要一个 HTML 页面，模拟上海外滩的灯光秀。

代码要能直接跑起来看到演示效果。

## Expected Behavior

Agent 应生成一个可直接运行的外滩灯光秀页面：画面中呈现可辨认的外滩天际线建筑群，灯光按一定节奏动态变换颜色与图案。页面提供开始／停止、颜色、速度等交互控制，并能在昼夜或不同时间状态之间切换，动画运行流畅。

### Criterion 1: 外滩城市天际线还原度 (key: c01_skyline_fidelity, weight: 0.1)

采证方式：截图 + 页面观察。

采证动作：截取场景主画面，逐一辨认画面中的标志性建筑（东方明珠、上海中心、金茂大厦等），记录哪些可辨认、建筑细节刻画到什么程度。

评分锚点：评估 HTML/CSS 实现是否恰当还原了标志性的外滩天际线，包含可辨认的地标（东方明珠、上海中心、金茂大厦等）。没有任何可辨认元素计 0 分；实现了基础天际线计 5 分；外滩建筑细节还原准确计 10 分。

### Criterion 2: 灯光秀动画系统完整性 (key: c02_light_animation, weight: 0.1)

采证方式：页面观察 + 代码。

采证动作：连续观察灯光变化不少于 30 秒，记录颜色过渡、光效移动路径以及各建筑灯光是否同步；结合代码确认使用的是 CSS 动画、Canvas 还是 WebGL。

评分锚点：审查代码是否使用 CSS 动画、Canvas API 或 WebGL 实现动态灯光效果，检查颜色过渡、运动图案与同步机制。没有任何动画计 0 分；实现了基础动画计 5 分；实现了接近真实外滩灯光秀的复杂同步光效计 10 分。

### Criterion 3: 昼夜循环与时间相关的光照变化 (key: c03_day_night_cycle, weight: 0.1)

采证方式：页面操作 + 截图。

采证动作：切换昼夜或选择不同时间状态，分别截图对比环境光变化是否自然、过渡是否突兀；同时观察黄浦江面的倒影表现。

评分锚点：检查模拟是否包含白天与夜晚视图的切换，或允许用户选择不同的时间状态。评估环境光变化是否真实、黄浦江面的倒影是否实现到位。过渡突兀扣 5 分；倒影缺失或不真实扣 3 分。满分 10 分。

### Criterion 4: 灯光秀的交互控制 (key: c04_interactive_control, weight: 0.1)

采证方式：页面操作为主。

采证动作：逐个操作页面上的控件（开始／停止、颜色、速度、图案、特效触发），记录每项操作后的画面变化，并评估控制面板的组织是否一目了然。

评分锚点：评估用户能否与灯光秀交互（如开始／停止、更换颜色、调整速度、切换图案或触发特效）。缺少基本控件扣 5 分；控制面板不够直观扣 3 分；界面提供的控件既全面又好用计 10 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：改变浏览器窗口尺寸并在 1440×900 与 768×1024 两种视口下查看，观察画面是否错乱。

评分锚点：评估代码能否处理常见异常（如浏览器窗口缩放、不同屏幕尺寸、低性能设备等）并提供兜底方案或自适应设计。鲁棒性强计 10 分，一般计 5 分，完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 雨雪等天气效果 2. 音频与灯光图案同步 3. 虚拟游客或镜头视角切换）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类效果重复实现（如多套动画系统同时运行）2. 与外滩灯光秀无关的功能模块 3. 导致性能问题的过度特效。每处冗余扣 3 分；核心功能被冗余代码干扰则直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（如渲染逻辑／动画效果／用户界面分层）、性能优化手段与代码组织。存在全局状态污染扣 5 分；代码重复率过高（超过 30%）扣 5 分；动画渲染完全没有考虑性能扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图，分别截取夜景灯光高潮时刻与白天状态各一张。

评分锚点：评估整体设计是否符合现代设计原则：1）视觉风格写实或风格化都可以，但要统一 2）建筑与灯光之间对比度合适 3）建筑元素与灯光效果的细节到位。每处视觉风格不统一扣 3 分；灯光物理表现不真实扣 5 分；画面构图差扣 5 分。满分 10 分。

### Criterion 10: 性能优化 (key: c10_performance, weight: 0.1)

采证方式：页面观察 + 代码。

采证动作：让页面连续运行 2 分钟，观察复杂灯光序列播放时是否出现卡顿；结合代码确认是否使用 requestAnimationFrame、是否有硬件加速与内存回收处理。

评分锚点：判断实现是否考虑了性能：1）使用 requestAnimationFrame 保证动画平滑 2）在合适的地方启用硬件加速 3）为长时间运行的动画做内存管理。在常规设备上帧率低于 30fps 扣 5 分；长时间运行出现内存泄漏扣 3 分；复杂灯光序列时有明显卡顿扣 5 分。满分 10 分。

# 书法笔画练习字帖打印页

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想做一个网页，能把书法笔画练习的内容打印出来，方便照着字帖练字。

## Expected Behavior

Agent 应生成可运行的书法练习字帖页面：页面上能展示带练习格（如米字格/田字格）的汉字与笔画内容，提供笔顺等练习引导；支持对练习内容做一定的自定义；页面带打印功能，打印出来的版式适合在纸上实际练字。

### Criterion 1: 书法笔画练习系统完整性 (key: c01_stroke_practice_system, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：打开页面，检查笔画/汉字是否正常渲染、是否有练习格系统；若有笔顺演示或跟练入口则逐一触发，观察笔画是否按顺序动画展示，截图记录。

评分锚点：评估代码是否实现书法核心功能，包括笔画展示、练习格系统、笔顺演示，以及逐笔练习能力。完全没有笔画渲染计 0 分；仅有静态汉字展示计 5 分；实现完整的交互式笔画练习并带动画引导计 10 分。

### Criterion 2: 打印功能实现质量 (key: c02_print_functionality, weight: 0.1)

采证方式：页面操作 + 代码。

采证动作：触发浏览器打印预览（或页面自带的打印/预览按钮），观察打印版式是否完整、分页是否合理，与屏幕显示对比差异；结合代码确认是否有 @media print 规则与分页控制。

评分锚点：检查代码是否包含正确的 CSS @media print 规则、面向打印优化的版式、分页控制以及打印预览功能。打印版式错乱扣 3 分；没有打印专用样式扣 5 分；打印输出与屏幕显示差异明显扣 2 分。满分 10 分。

### Criterion 3: 书法内容自定义功能 (key: c03_content_customization, weight: 0.1)

采证方式：页面操作为主。

采证动作：逐一尝试自定义入口（输入/选择练习汉字、切换字体风格、调整格子大小、笔画粗细等），每改一项观察预览是否实时更新，截图记录改动前后对比。

评分锚点：审查用户能否自定义书法内容（选字、风格选择、格子大小、笔画粗细等）。自定义选项全面且带预览计 10 分；有基础自定义但无预览计 5 分；仅有预设模板、几乎不可调计 3 分。

### Criterion 4: 练习引导机制 (key: c04_practice_guidance, weight: 0.1)

采证方式：页面操作 + 代码。

采证动作：检查页面是否展示笔顺编号或笔顺动画、格线/间距引导、运笔方向指示；若引导线可配置则实际调整一次，记录效果。

评分锚点：评估系统是否包含笔顺可视化、合理的间距引导线、运笔方向指示，以及可能的动画演示等功能。缺少笔顺扣 5 分；引导线不可自定义扣 3 分；练习过程没有视觉反馈机制扣 2 分。满分 10 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：输入生僻字或不支持的字符（如 emoji），观察页面是否报错或给出友好提示。

评分锚点：评估代码能否处理常见边界情况（如浏览器兼容问题、设备横竖屏切换、打印出错、输入不支持的字符等）并提供友好的错误提示或兜底方案。鲁棒性强、能有效应对这些情况计 10 分；鲁棒性一般计 5 分；完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 基于指针事件的笔压模拟 2. 可控速的笔画动画演示 3. 练习进度追踪系统 4. 手写识别反馈）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同一功能用多种方式重复实现 2. 与书法练习或打印无关的功能 3. 妨碍核心学习功能的装饰性元素。每处冗余扣 3 分；核心书法练习功能被多余功能喧宾夺主直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（渲染引擎、字库数据、用户界面、打印功能的分离）、组件复用性，以及屏幕与打印两种媒介下的性能优化。全局变量滥用扣 5 分；代码未按逻辑组件组织扣 5 分；打印渲染性能未优化扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图（练习主界面，含练习格与笔画展示区），检查笔画与背景对比度、格子比例。

评分锚点：评估设计是否符合书法练习的专业规范：1）笔画与背景对比清晰 2）格子间距符合传统字帖比例 3）字与字间距得当、排版专业。笔画不清晰扣 3 分；格子尺寸不当、影响练习扣 5 分；界面元素杂乱、干扰练习扣 5 分。满分 10 分。

### Criterion 10: 打印输出实用性 (key: c10_print_output_usability, weight: 0.1)

采证方式：页面操作（打印预览）+ 代码。

采证动作：打开打印预览，检查是否有省墨选项、笔画引导线深浅是否适合描红、版式是否按 A4 等标准纸张留出页边距，截图记录预览效果。

评分锚点：判断打印输出是否适合真实书法练习：1）有省墨设计选项 2）纸面上笔画密度与可见度合适 3）页面版式针对标准纸张尺寸优化。打印输出过度费墨扣 5 分；打印出的笔画引导线过浅或过深、不实用扣 3 分；版式未妥善处理页边距或标准纸张尺寸扣 5 分。满分 10 分。

# 网页版视频剪辑工具

## Prompt

请在 /tmp_workspace 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

帮我做一个网页版的视频剪辑工具，HTML 网页版。

功能需求：

- 能上传视频
- 自动剪辑视频
- 保存视频
- 文字转语音，带热门主播音色
- 自动提取字幕

## Expected Behavior

Agent 应产出一个可运行的网页剪辑工具：能选择并上传视频，上传后在预览区播放并在时间轴上显示片段；点击自动剪辑能对素材做切分／拼接并把结果反映到时间轴和预览上；提供文字转语音入口，可选择音色并生成配音；提供字幕提取入口，生成的字幕能与视频对齐显示并可编辑；剪辑结果可以导出／保存，导出过程有进度提示。

## Grading Criteria

### Criterion 1: 视频上传与处理 (key: c01_upload_processing, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：通过上传入口选择一个视频，记录是否有进度提示和预览生成；再选一个不支持的格式文件，记录校验提示；结合代码确认支持的格式清单、元信息提取（时长、分辨率、编码）与分片上传实现。

评分锚点：审查代码是否实现多格式视频上传（MP4、AVI、MOV、WebM）并有完善的文件校验、进度跟踪和预览生成；检查是否包含视频元信息提取（时长、分辨率、编码格式），以及大文件的分片上传支持。缺少基础上传功能计 0 分；仅有简单上传可用计 5 分；支持全部格式且有健壮的错误处理计 10 分。

### Criterion 2: 自动剪辑引擎 (key: c02_auto_editing, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：上传素材后点击自动剪辑，记录时间轴是否出现切分后的片段、片段顺序是否变化、预览是否同步更新；触发一次导出并观察渲染是否稳定完成。

评分锚点：评估自动剪辑是否包含智能场景检测、转场效果和时间轴管理；检查系统能否基于内容分析自动完成裁剪、修剪和片段排列；必须包含视频渲染流程和导出功能。无时间轴可视化扣 5 分；渲染不稳定扣 3 分。满分要求具备 AI 驱动的剪辑建议。

### Criterion 3: 文字转语音与音色模拟 (key: c03_tts_voice, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：在文字转语音入口输入一段文字，切换不同音色各生成一次，记录是否有音色选项、是否出现音频波形、生成的配音能否与视频对齐播放。

评分锚点：检查 TTS 系统是否包含多种语音模型、正确的音频合成和音质控制；评估热门主播音色模拟是否实现且质量可接受（相似度大于 80%）；必须包含音频波形可视化以及与视频的时间同步。音色质量差扣 5 分；无音色选择项扣 3 分。

### Criterion 4: 自动字幕提取与同步 (key: c04_subtitle_sync, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：触发字幕提取，记录字幕是否随播放进度实时高亮、时间轴对齐是否明显偏移；尝试手动修改一条字幕并调整字体／颜色／位置；查看是否能导出 SRT／VTT。

评分锚点：审查字幕系统是否使用语音识别接口（Web Speech API 或外部服务）并保证时间同步准确；检查是否支持字幕编辑、样式设置（字体、颜色、位置）和导出格式（SRT、VTT）；必须包含实时预览与人工校正能力。时间轴偏差超过 500ms 扣 5 分；无样式设置项扣 3 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：上传一个超大文件和一个不支持的格式，断网后触发一次导出，观察是否有友好提示或降级处理。

评分锚点：评估代码能否处理常见异常（大文件上传、不支持的格式、网络中断、内存限制、浏览器兼容性问题）并给出友好的错误提示或恢复机制。鲁棒性强、能优雅降级处理边界情况计 10 分；鲁棒性一般计 5 分；完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. AI 生成封面图 2. 实时协作剪辑 3. 社交平台画幅适配 4. 背景音乐自动卡点 5. 语音情绪识别）。每实现一项实用创新加 3 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如多个播放器并存）2. 与视频剪辑无关的功能模块（如内置小游戏或社交功能）3. 无价值且拖慢性能的特效（如渲染过程中的过度动画）。每处冗余扣 3 分；冗余代码干扰核心功能直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（视频处理／UI／存储分层）、错误处理是否得当、性能优化是否到位；检查视频处理过程中的内存管理与资源释放。存在全局状态污染或职责划分混乱扣 5 分；代码重复率超过 30% 扣 5 分；未针对大视频文件做性能优化扣 5 分。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 截整页图（剪辑主界面，含时间轴与预览区；以及字幕／配音面板）。

评分锚点：评估剪辑界面是否符合专业视频剪辑软件的标准：1）时间轴可视化清晰、缩放比例合理 2）工具摆放与图标符合直觉 3）视频预览区对比度合适 4）间距一致，遵循 8px 栅格 5）配色专业，适合长时间剪辑。每处 UI 元素堆叠杂乱扣 3 分；视频预览画质差扣 5 分；导航令人困惑扣 5 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：拖动进度条快速定位 3 次，在时间轴上拖拽片段 3 次，切换工具 3 次，记录响应延迟、预览是否卡顿、导出进度是否清晰；试用常用快捷键（空格播放、Delete 删除片段）。

评分锚点：判断剪辑交互是否响应及时、达到专业水准：1）拖动进度条定位在 100ms 内响应 2）时间轴拖放操作顺滑 3）预览播放不卡顿 4）导出进度提示清晰 5）切换工具有即时反馈。每处交互卡顿扣 5 分；加载状态不清晰扣 3 分；常用操作缺少键盘快捷键扣 5 分。满分 10 分。

### Criterion 1: 网站基础结构规范性 (key: c01_site_structure, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：打开首页确认整体布局正常渲染，无明显错位。

评分锚点：审查 HTML5 结构是否使用语义化标签（header、nav、main、section、footer）、正确的 DOCTYPE 声明和响应式 meta 标签；检查 CSS 是否有清晰的组织（reset/normalize、变量、组件、布局）。结构混乱计 0 分；基本元素齐全但组织糟糕计 5 分；结构干净、语义化、符合最佳实践计 10 分。

### Criterion 2: 动漫目录与浏览功能 (key: c02_catalog_browsing, weight: 0.1)

采证方式：页面操作为主，代码为辅。

采证动作：进入目录页，检查每部作品是否展示标题、封面、评分、题材、年份；在搜索框输入关键词观察结果；逐一尝试筛选和排序选项并记录结果变化；滚动或翻页验证分页/无限加载。

评分锚点：评估动漫目录的筛选、排序与搜索功能实现；检查目录是否展示关键信息（标题、封面图、评分、题材、上映年份），并提供分页或无限滚动。缺少搜索功能扣 5 分；筛选能力有限扣 3 分；排序选项不足扣 2 分。满分 10 分。

### Criterion 3: 详情页与播放器设计 (key: c03_detail_player, weight: 0.1)

采证方式：页面操作为主。

采证动作：点进一部作品详情页，核对简介、剧集列表、角色、相关推荐等信息；打开播放器，逐一操作播放/暂停、音量、全屏、清晰度切换并记录响应。

评分锚点：评估详情页是否包含完整的作品信息（简介、剧集、角色、相关动漫），以及播放器是否具备基本控制（播放/暂停、音量、全屏、清晰度选项）。详情页或播放器缺失计 0 分；两者存在但缺少关键功能计 5 分；两者功能齐全且良好整合计 10 分。

### Criterion 4: 用户系统与个性化功能 (key: c04_user_personalization, weight: 0.1)

采证方式：页面操作 + 代码。

采证动作：注册并登录一个账号，进入个人资料页；对某部作品执行加入追番/收藏操作后到个人页核对；播放一集后检查观看历史；查看是否有基于偏好的推荐区块。

评分锚点：检查用户认证（注册/登录）、个人资料管理，以及追番列表、收藏、观看历史等个性化功能；评估系统是否包含基于用户偏好的推荐算法。认证方式不安全扣 5 分；个性化功能缺失扣 3 分；未实现推荐扣 2 分。满分 10 分。

### Criterion 5: 代码鲁棒性 (key: c05_robustness, weight: 0.1)

采证方式：代码为主。

采证动作（辅助）：搜索一个不存在的作品名，观察空结果提示；检查图片加载失败时是否有占位图。

评分锚点：评估代码能否处理常见异常（如 API 请求失败、图片缺失、网络缓慢等）并提供友好的错误提示或恢复机制；检查输入校验、API 调用的错误处理和兜底内容。鲁棒性强、能有效应对这些边界情况计 10 分；鲁棒性一般计 5 分；完全未处理异常计 0 分。

### Criterion 6: 创新功能 (key: c06_innovation, weight: 0.1)

采证方式：页面操作 + 代码。

评分锚点：检查是否包含提升体验的惊喜功能（如：1. 明暗主题切换 2. 季度新番日历可视化 3. 角色关系图谱 4. 剧集截图预览 5. 声优资料及其他参演作品）。每实现一项实用创新加 2 分，上限 10 分。

### Criterion 7: 冗余功能检查 (key: c07_redundancy, weight: 0.1)

采证方式：代码为主。

评分锚点：严查三类冗余：1. 同类功能重复实现（如多套代码各异的轮播组件）2. 与动漫网站无关的功能模块（如与动漫无关的新闻滚动条）3. 影响性能的花哨特效（如过量视差效果或动画）。每处冗余扣 3 分；冗余代码干扰核心功能直接计 0 分。

### Criterion 8: 工程质量 (key: c08_engineering, weight: 0.1)

采证方式：代码。

评分锚点：审查模块化设计（如组件化架构、关注点分离）、状态管理实现、代码复用性与构建流程。全局状态管理糟糕扣 5 分；组件耦合过紧扣 3 分；代码重复率高（超过 30%）扣 2 分。同时检查 API 调用是否正确使用 async/await 或 Promise。满分 10 分。

### Criterion 9: 界面视觉专业性 (key: c09_visual_design, weight: 0.1)

采证方式：截图。

采证动作：桌面 1440×900 分别截首页、目录页、详情页整页图，对比各页风格一致性与卡片排布。

评分锚点：评估设计是否符合现代动漫网站的审美：1）配色统一且契合动漫主题 2）卡片布局规整、间距一致（8px 网格体系）3）字体层级清晰、正文可读（正文不小于 14px）4）图片与缩略图使用得当。布局拥挤杂乱扣 3 分；视觉层级差扣 4 分；页面间风格不统一扣 3 分。满分 10 分。

### Criterion 10: 动态交互流畅性 (key: c10_interaction_fluency, weight: 0.1)

采证方式：页面操作。

采证动作：在页面间跳转 3 次记录过渡表现与加载提示；悬停/点击卡片和按钮观察反馈动画；整页滚动检查顺滑度；切到移动视口 390×844 试点按主要交互元素。

评分锚点：判断动效是否提升用户体验：1）页面切换在 300ms 内完成 2）异步操作有加载状态 3）悬停/点击有反馈动画 4）滚动行为顺滑 5）支持移动端触控手势。页面切换生硬突兀扣 3 分；缺少加载指示扣 3 分；UI 元素无响应扣 2 分；移动端交互设计差扣 2 分。满分 10 分。

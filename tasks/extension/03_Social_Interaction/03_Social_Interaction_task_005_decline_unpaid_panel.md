## Prompt

我收到一封行业峰会邀请，对方希望我参加一场90分钟线上圆桌、提前看讨论提纲，并在会后帮忙转发宣传；邮件里明确说没有嘉宾费。主办方去年给我的项目做过介绍，我想保持关系，但这次不接受无偿邀约，也不想编造档期冲突。

请用我的口吻写一封中文回复：明确拒绝这次邀请，不批评对方；如果未来有合适主题和嘉宾预算，可以再联系。对方是Amy，我署名林岚。给出一行邮件主题和一封正文，正文120～220字，不需要解释写作思路，也不要提供多个版本。

## Expected Behavior

Agent直接给出一封可发送的中文邮件，明确拒绝本次无偿圆桌及其附带准备、宣传工作，诚实说明合作边界，感谢对方邀请和过去的支持，并只在主题合适且有嘉宾预算时保留未来合作可能。

## Grading Criteria

- [ ] 明确拒绝本次圆桌及附带工作 — 30%（`reasoning_planning`、`content_generation`）
- [ ] 感谢邀请、过去支持，并以明确条件保留未来合作 — 25%（`content_generation`）
- [ ] 如实说明无偿合作边界，不虚构档期冲突 — 25%（`reasoning_planning`、`content_generation`）
- [ ] 主题、称呼、署名、长度和单一成稿均可直接使用 — 20%（`content_generation`、`verification_delivery`）

## LLM Judge Rubric

Judge只评价下列四个检查点，不得增加整体印象分。每个检查点只能使用`1.0 / 0.75 / 0.5 / 0.25 / 0.0`中的一个分数。

### Criterion 1: 拒绝决定及范围 (key: clear_decline_and_scope, weight: 0.3)

判据：邮件是否明确拒绝本次圆桌，并覆盖提前查看提纲和会后转发宣传两项附带工作。

**Score 1.0**: 明确表示本次不参加，并明确或无歧义地拒绝提前看提纲和会后转发宣传，没有留下已接受本次邀约的空间。

**Score 0.75**: 明确拒绝参加圆桌，但两项附带工作中有一项只通过上下文隐含拒绝；收件人仍不会误解为已接受邀请。

**Score 0.5**: 基本表达不参加，但使用“目前可能不方便”“再看看”等保留性措辞，或未处理两项附带工作，仍需修改才能形成明确决定。

**Score 0.25**: 主要在询问更多信息或协商条件，没有清楚说明本次是否参加。

**Score 0.0**: 接受本次邀请、表示会完成附带工作，或完全没有给出参加与否的决定。

### Criterion 2: 关系维护 (key: relationship_preservation, weight: 0.25)

判据：邮件是否感谢邀请和过去支持，并仅在主题合适且有嘉宾预算时保留未来合作可能。

**Score 1.0**: 同时感谢本次邀请和主办方过去对项目的介绍，并以主题合适和有嘉宾预算为条件保留未来联系可能，不承诺一定参加。

**Score 0.75**: 有感谢和未来联系，但遗漏过去支持、合适主题或嘉宾预算三个要素中的一个；整体仍能维护合作关系。

**Score 0.5**: 保持礼貌，但未提过去支持，且未来合作条件只出现一个或表述为泛化的“以后再合作”。

**Score 0.25**: 语气冷淡或带有责备，未有效维护未来关系，或无条件承诺未来参加。

**Score 0.0**: 贬低主办方、活动或过去合作，明确破坏关系，或完全拒绝任何未来合作。

### Criterion 3: 诚实边界表达 (key: honest_boundary_setting, weight: 0.25)

判据：邮件是否诚实说明不接受无偿邀约，不虚构档期冲突，也不批评、羞辱或反复议价。

**Score 1.0**: 清楚、克制地说明本次不接受无偿邀约；没有虚构日程冲突，没有威胁、羞辱、批评或进入反复议价。

**Score 0.75**: 边界准确且没有虚构或攻击，但对无偿条件表达较间接，收件人仍能理解拒绝与预算有关。

**Score 0.5**: 拒绝理由含糊，只说“当前安排不合适”等，未说明无偿边界，但未明显虚构或攻击对方。

**Score 0.25**: 编造档期冲突，或以指责、施压方式讨论费用，但仍表达了不接受本次邀请。

**Score 0.0**: 虚构重大理由、威胁或羞辱对方，进行不当利益交换，或明确接受本次无偿邀约。

### Criterion 4: 邮件可直接使用性 (key: email_usability, weight: 0.2)

判据：输出是否为单一中文成稿，包含一行主题、Amy称呼和林岚署名，正文为120～220字，且没有写作说明。

**Score 1.0**: 只有一个版本，主题、Amy称呼和林岚署名齐全；正文在120～220字内，格式完整，无写作说明，可直接发送。

**Score 0.75**: 只有一个版本且可直接使用，但缺少一个次要格式要素，或正文仅轻微超出范围（100～119字或221～240字）。

**Score 0.5**: 邮件主体可辨，但缺少两个格式要素、长度明显不符，或夹有少量需要删除的写作说明。

**Score 0.25**: 提供多个版本、主要是提纲或分析，或缺少主题、称呼、署名中的大部分，必须大幅改写。

**Score 0.0**: 没有形成可用邮件正文，或输出与邀请回复无关。

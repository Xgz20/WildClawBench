# 同事紧急请假私信回复

## Prompt

同事小周刚私聊我：“我爸明早做手术，我想请周四、周五两天假。客户资料可能赶不完，能帮我先盯一下项目群吗？我现在有点乱，如果不方便也没关系。”

我今天可以帮她盯项目群到18:00，有紧急消息可以提醒她，但没法接手客户资料，也不能替她向客户承诺交期；请假仍要由主管确认。帮我写一条80～150字的中文私信，既表示关心，也把能帮到的范围和下一步说清楚。不要追问病情，不要替主管批准请假。只给消息正文。

## Expected Behavior

回复应以同事之间自然、支持性的语气回应家庭紧急情况，确认可以代看项目群到18:00并提醒紧急消息，同时明确不能接手客户资料或对客户承诺交期。请假需要主管确认，消息可以建议小周完成必要的主管确认和最小交接，但不得追问病情或代替主管批准。

## Grading Criteria

- [ ] `context_and_request_coverage`：准确回应家庭手术、两天请假、客户资料风险和项目群代看请求 — 25%
- [ ] `empathy_and_role_fit`：表达关心且符合平等同事关系 — 25%
- [ ] `privacy_and_commitment_boundary`：帮助范围、客户承诺和请假审批边界清楚 — 30%
- [ ] `ready_to_send`：单条80～150字私信，交接动作明确，可直接发送 — 20%

## LLM Judge Rubric

Judge只评价以下四个检查点，不增加整体印象分。允许不同但自然的表达方式。每项只能使用`1.0 / 0.75 / 0.5 / 0.25 / 0.0`。

### Criterion 1: 情境与请求覆盖 (key: context_and_request_coverage, weight: 0.25)

判据：回复是否正确回应家人手术、周四周五请假、客户资料可能赶不完和代看项目群四项情境。

**Score 1.0**: 四项均被自然回应，没有改变日期、关系或请求内容。

**Score 0.75**: 核心情境准确，仅有一项次要背景未明确提及，但回复仍明显针对本次请求。

**Score 0.5**: 至少回应其中两项，仍能识别家庭紧急请假和工作交接，但遗漏客户资料或项目群请求。

**Score 0.25**: 只泛化表示“请好好休息”或“工作我来处理”，大部分具体情境缺失或有一处实质误解。

**Score 0.0**: 回复与请假交接无关，错误描述家庭情况，或要求对方继续完成全部工作。

### Criterion 2: 关心与同事角色 (key: empathy_and_role_fit, weight: 0.25)

判据：回复是否表达适度关心，尊重对方处境，不追问病情、不说教，也不以主管或医疗专业人员口吻回应。

**Score 1.0**: 关心具体而克制，语气平等、支持且尊重隐私，没有追问、评判或居高临下的表达。

**Score 0.75**: 整体自然支持，仅有一处略显模板化或稍显正式的表达，不影响同事关系。

**Score 0.5**: 有基本礼貌和关心，但明显生硬、以工作安排为主，或出现一个不必要但不敏感的问题。

**Score 0.25**: 语气冷淡、说教、施压，或追问病情细节，但仍包含少量支持性内容。

**Score 0.0**: 指责对方请假、要求披露隐私、贬低家庭紧急情况，或包含明显不当内容。

### Criterion 3: 隐私与承诺边界 (key: privacy_and_commitment_boundary, weight: 0.3)

判据：是否清楚区分四组边界：代看项目群到18:00并提醒紧急消息；不接手客户资料；不替对方向客户承诺交期；不批准请假且提醒由主管确认。

**Score 1.0**: 四组边界全部准确，既说明能提供的帮助，也说明不能承担的事项，没有越权承诺。

**Score 0.75**: 边界方向全部正确，仅有一组通过上下文隐含表达或缺少一个次要细节。

**Score 0.5**: 至少两组边界清楚，未明显越权，但遗漏18:00、客户承诺或主管确认中的重要内容。

**Score 0.25**: 帮助范围含糊，暗示会接手客户资料、批准假期或处理客户交期中的一项。

**Score 0.0**: 明确替主管批准请假、向客户承诺交期、承诺接手全部资料，或要求获得病情信息后才帮助。

### Criterion 4: 私信可直接使用性 (key: ready_to_send, weight: 0.2)

判据：是否只有一条80～150字中文私信，并给出主管确认和必要交接等清楚下一步。

**Score 1.0**: 只有消息正文，长度80～150字，帮助范围和下一步自然连贯，无需修改即可发送。

**Score 0.75**: 单条消息可直接发送，但长度为70～79字或151～165字，或一个次要交接动作略含糊。

**Score 0.5**: 主体可用，但明显偏长或偏短、下一步不完整，或夹有少量写作说明。

**Score 0.25**: 提供多个版本、主要是提纲或分析，或需要大幅重写才能发送。

**Score 0.0**: 没有形成可用私信正文，或内容与请求无关。

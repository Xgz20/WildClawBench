# 首次朋友读书会开场

## Prompt

明天我第一次在家里主持朋友读书会，聊《小王子》里的成长和责任。大家彼此认识，但以前没正式讨论过书。帮我写一段大约60秒的开场，轻松一点，不要像会议主持词，也别剧透后面的情节。最后自然带出一个没有标准答案的讨论问题。直接回复我可以照着说的版本。

## Expected Behavior

回复应是一段约60秒、可直接照读的中文开场，自然交代首次聚会和成长、责任主题，照顾朋友间熟悉但首次正式聊书的情境，不透露后续情节，并以开放问题进入讨论。

## Grading Criteria

- [ ] `brief_requirements`：首次聚会、指定主题、无剧透和开放问题均得到满足 — 25%
- [ ] `spoken_structure`：开场、主题引入和问题之间连贯 — 25%
- [ ] `tone_fit`：符合朋友间轻松交流，不使用会议主持腔 — 25%
- [ ] `ready_to_use`：内容可直接照读且长度适当 — 25%

## LLM Judge Rubric

Judge只评价以下四个检查点，不增加整体印象分。允许不同但自然的表达方式。每项只能使用`1.0 / 0.75 / 0.5 / 0.25 / 0.0`。

### Criterion 1: 要求覆盖 (key: brief_requirements, weight: 0.25)

判据：开场是否自然体现第一次主持、围绕成长与责任、避免后续剧透，并带出没有标准答案的问题。

**Score 1.0**: 四项要求全部明确且自然融入，没有泄露后续情节或把问题写成知识测验。

**Score 0.75**: 四项方向正确，仅一项表达较隐含或开放问题略显普通，但仍符合聚会目的。

**Score 0.5**: 至少两项得到实质满足，仍能作为相关读书会开场，但遗漏一个主题、首次情境或开放性要求。

**Score 0.25**: 只提到书名和泛化欢迎语，问题封闭，或出现轻微后续剧透。

**Score 0.0**: 明显剧透关键后续、偏离指定书和主题，或没有形成开场与讨论问题。

### Criterion 2: 口语结构 (key: spoken_structure, weight: 0.25)

判据：欢迎、情境说明、主题引入和讨论问题是否形成自然的口语推进。

**Score 1.0**: 各部分顺序清楚且衔接自然，没有逻辑断裂、重复或无关内容，朗读时能顺畅进入讨论。

**Score 0.75**: 主线完整，仅有一处轻微跳转、重复或句子略长。

**Score 0.5**: 结构可辨认，但有一处明显断裂或两至三处轻微问题，仍可通过编辑使用。

**Score 0.25**: 内容主要是零散提纲、问题突兀或重复较多，需要大幅重组。

**Score 0.0**: 内容不可理解、明显偏题，或没有可识别的口语开场结构。

### Criterion 3: 朋友间语气 (key: tone_fit, weight: 0.25)

判据：表达是否适合熟悉朋友在家中首次正式聊书，轻松、平等且不带会议主持腔。

**Score 1.0**: 全文自然亲切、克制而不生硬，符合朋友关系，没有流程宣告、训导或过度正式措辞。

**Score 0.75**: 整体轻松自然，仅一处略正式、模板化或稍显用力。

**Score 0.5**: 基本友好但多处像活动主持稿，仍可用于朋友聚会。

**Score 0.25**: 大部分是会议流程、说教或宣传腔，与家庭朋友场景明显不符。

**Score 0.0**: 语气冒犯、居高临下、与朋友场景相反，或没有可评价内容。

### Criterion 4: 可直接照读 (key: ready_to_use, weight: 0.25)

判据：回复是否只有可直接说出的开场，时长接近60秒，且无需补写核心内容。

**Score 1.0**: 只有完整开场正文，长度适合约60秒朗读，措辞自然，无需实质修改即可使用。

**Score 0.75**: 可直接照读，仅略长或略短，或有一句需要轻微口语化调整。

**Score 0.5**: 主体可用，但明显偏离目标时长、夹有少量写作说明，或需要多处修改。

**Score 0.25**: 主要是提纲、多个备选版本或只有几句，必须重写才能主持。

**Score 0.0**: 没有可使用的开场正文或回复与请求无关。

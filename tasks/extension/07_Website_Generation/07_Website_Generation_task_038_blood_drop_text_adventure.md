# 滴血验亲文字冒险

## Prompt

请在 `/tmp_workspace` 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

题目提供的输入素材已经放在 /tmp_workspace/assets 目录中，请直接使用这些文件，不要用自行编造的数据替代。

我写了一个短篇的宫廷故事，想做成一个能玩的中文网页，读者一边看一边替主角做选择，选得不一样，结局也不一样。故事叫《滴血验亲》，主角是被人当庭指认孩子非皇嗣的沈昭仪。

稿子在 `/tmp_workspace/assets/story.md` 里，是我按写话本的路子写下来的：楔子、三节正文、每一节有哪几种答法、答完往哪一节走、哪一种答法能让主角拿到东西、两件东西各是什么、四个结局分别怎么收场，都写在行文里。页面上的文字都照这份稿子来，不要自己改写或者续写。

打开先看到故事名和开场白，再往下是当前这一幕的正文和可以做的选择。选了一项就推进到下一幕，正文和选项都换成新的。页面上还要有一块地方专门放手里已经拿到的证据，一条都没有的时候写清楚现在还两手空空，拿到了就把证据的名目和那句说明列出来。

有些答法会让主角拿到证据，稿子里写清楚了哪一种对应哪一件，同一件东西拿到两次只算一件。

最后一幕当庭对质，「请换一盆清水，当着众人的面重验一次」这一项要手里有证据才能选——一条证据都没有的时候，这一项要明摆着不能选，让人一眼看出是自己没查到东西，而不是页面坏了。

结局按下面的规矩定：走到最后一幕，手里有两条证据又选了换水重验的，是「真相大白」；只有一条证据还选换水重验的，是「险中得脱」；选了哭诉或者当场指认的，不管手里有什么，都是「百口莫辩」。一开始就把验亲顶回去的，当场就完了，是「不验而废」，后面几幕都不会发生。

走到结局那一页，除了结局的标题和正文，还要能回看这一局是怎么走过来的——经过了哪几幕、每一幕选的是哪一项。看完能重新开一局，重开会把进度和证据都清掉，所以按下去之前先确认一下。

玩到一半关掉页面是常有的事，再打开时要还停在原来那一幕，手里的证据也都还在。

样子想要古典一点、沉一点，像夜里的宫墙：深色底、暖色的字，正文一段一段读起来不费劲，选项一眼能认出是能点的。手机上也要能正常读和选。

评分由 Playwright 运行时检查（内容与交互类评分点）和基于截图的视觉判分（视觉与布局类评分点）共同完成；每个评分点按“预设状态 → 操作 → 期望结果”独立判定。

# 小满账簿

## Prompt

请在 `/tmp_workspace` 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想做一个叫“小满账簿”的中文个人记账网页，平时用来记录收入和支出，也能按月或按周回头看看钱都花到哪儿了。不需要登录账号，打开就能直接记账。

页面第一次打开时是一本空账簿，给出清楚的空状态，引导用户记下第一笔账。顶部显示“小满账簿”、文案“把每一笔认真记下，也把生活慢慢看清。”和醒目的“记一笔”按钮。这里还要能按月或按周查看，选择不同月份或自然周，并在“明细”和“分析”之间切换；默认查看当前月份的明细。切换周期或页签后，页面里的标题和数据要跟着变化。

“明细”页先显示当前周期的收入、支出、结余和记录数，再列出这个周期里的账目。每条记录要看得到日期、名称、备注、分类、收支类型和金额，收入与支出在符号和颜色上容易区分。分类用餐饮、交通、居住、学习、娱乐、工资、奖金和其他这些常见选项就行。列表默认按日期从新到旧排列，另外可以搜名称或备注，也能按收支类型和分类筛一筛，再按日期或金额排序。没找到符合条件的账目时，给出清楚的空状态。

点击“记一笔”后，用弹窗填写收支类型、名称、金额、分类、日期和备注。名称和日期不能为空，金额要大于 0，填错时留在弹窗里并在对应位置给出中文提示。保存后，新账目要出现在对应周期，列表和统计立即更新。点击任意账目可以查看完整详情，也可以继续编辑或删除；编辑时预填原来的内容。删除前先让用户确认，避免误操作。

“分析”页根据当前周期的账目做一个收支概览，再分别看看收入和支出都分布在哪些分类里，用两个环形图呈现就行。下面放一张趋势图，可以在收入、支出和结余之间切换，对比各个周期之间的变化。

视觉上希望它像一页清楚、克制的现代账单：用温暖的米色做背景，深色文字，主要操作和支出用醒目的橙色，收入用绿色，结余和图表强调可以用金色。页签、选择项、统计块、列表、图表、输入框、详情和弹窗保持统一的圆角、边框和间距。桌面端做成清楚的单栏账单布局，手机上也要能正常记账和查看。

## Expected Behavior

Agent 应按 Prompt 完成页面内容、交互和视觉要求。

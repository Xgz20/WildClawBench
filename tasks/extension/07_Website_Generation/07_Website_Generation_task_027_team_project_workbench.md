# 团队项目管理工作台

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文团队协作/项目需求任务三层管理工具网页项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。页面运行时不要依赖外部图片、字体、接口或其他网络资源；不要接入真实支付或发送真实请求。

我们组做产品研发，项目、需求、任务现在散在各处表格和聊天记录里，每次开周会都得挨个问一遍。想做个组内自用的项目管理网页，不用登录。

活分三层：项目下面拆需求，需求下面拆任务，任务落到人头上。页面分工作台、项目、需求、任务四块。三层都能在页面上新建，新建时别让我填太多——项目有个名字就能建，需求挑好归哪个项目、写上标题就行，任务再多两项，归谁做、什么时候要交。建错了能删，删之前问一句。

工作台是首页，先看几个关键数字：在做的项目、没做完的需求、逾期的任务各有多少。下面配几张图，看全组任务的状态分布、各项目的进度对比、每个人手上还压着多少活，图上得能看出具体数目。再往下列出逾期的和一周内要交的任务，点一条能直接跳到那个任务上。刚开始一条数据都没有的时候，工作台别只剩一片空白或一排零，得让人知道从哪儿下手。

项目那块列出所有项目，点进去能看到它下面的需求；需求那块列出所有需求，能按项目和状态挑着看，点开能看到拆出来的任务。任务那块做成看板，按待开始、进行中、已完成分三列，卡片从一列拖到另一列就改了状态，松手数字立刻跟着变；看板上能按负责人和项目筛，也能按名字搜。

进度自动算，不用手填：需求的进度看它下面任务完成了几个，任务全完成这条需求就算做完；项目的进度看它下面所有任务里完成的占比。过了截止日期还没做完的任务算逾期，页面上标出来。建过的东西关掉再打开还在。

清爽的办公工具样子就行，浅色底深色字，状态用颜色分开，逾期的标红。手机上也要能看。

## Expected Behavior

Agent 应从空目录生成可运行的前端网站，按 Prompt 完成页面内容、交互和视觉要求；项目应能在本地 npm install、npm run build 并通过 npm run start 启动，且不依赖外部网络资源。

评分由 Playwright 运行时检查（内容与交互类评分点）和基于截图的视觉判分（视觉与布局类评分点）共同完成；每个评分点按“预设状态 → 操作 → 期望结果”独立判定。

## Grading Criteria

本题仅使用 LLM Judge 评分。评分点全部放在 `## LLM Judge Rubric` 中，每个 Criterion 只有 1.0 和 0.0 两档：非视觉类评分点由 Playwright 检查器按 key 给出运行时结果，视觉类评分点由 LLM 依据截图判定。

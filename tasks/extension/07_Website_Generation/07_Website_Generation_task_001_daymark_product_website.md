# 昼航 Daymark 产品官网

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文单页产品官网项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。不要接入真实支付，不要发送真实表单请求，也不要使用需要联网才能显示的图片或字体。

请为“昼航 Daymark”制作一个中文单页产品官网。这是一款面向混合办公团队的会议决策工作台，帮助产品和运营团队把议题、决定和负责人放进同一条时间线。整体语气清楚、克制，有编辑感，但仍然要让第一次访问的人很快明白产品是做什么的。

页面顶部放置吸顶导航，包含品牌名、“工作流”“定价”“常见问题”三个页面内入口，以及“免费试用”按钮。首屏主标题为“开完会，事情就该向前走”，说明文字为“昼航把议题、决定和负责人放进同一条时间线，让每一次讨论都有清楚的下文。”，提供“免费试用 14 天”和“查看工作流”两个行动入口，并标明“无需信用卡 · 5 分钟完成设置”。首屏右侧用一个界面式卡片展示名为“周一产品例会”的会议时间线，内容包括决定、负责人和下一步行动。

首屏下方展示三项产品效果：“42% 跟进消息减少”“3.2 小时 每人每周节省”“96% 决定都有负责人”。工作流区域标题为“从议题到行动，只走三步”，依次介绍“会前收拢议题”“会中锁定决定”“会后推动行动”，并说明如何合并重复问题、记录结论和负责人、按截止时间追踪行动。

定价区域提供“按月”和“按年”切换，默认显示按月价格。两个方案分别是“轻帆”和“协作舱”：按月价格为每月 ¥39 和每位成员每月 ¥89；切换为按年后，价格变为每月 ¥31 和每位成员每月 ¥71，同时显示“按年付费，约省 20%”。这是一个产品展示页面，不需要接入真实支付。

常见问题使用手风琴，同一时间最多展开一项，包含以下三问及回答：“可以导入已有会议记录吗？”回答“可以，支持粘贴文本或导入 Markdown，原有标题和待办会被保留。”；“没有管理员也能开始吗？”回答“可以，任何成员都能创建第一个工作区，之后再邀请同事加入。”；“数据会被用于训练模型吗？”回答“不会。工作区内容默认不用于训练，也不会在团队之间共享。”

点击“免费试用”后打开“开始 14 天免费试用”对话框，填写姓名和工作邮箱。空表单提交时分别提示“请输入姓名”和“请输入有效的工作邮箱”；填写有效内容后，在对话框内显示“申请已收到，我们会把开通指引发到 {用户填写的邮箱}”，并提供关闭按钮。表单只需要演示页面反馈，不需要发送真实信息。

视觉上使用暖色纸张风格：页面背景为暖象牙色 `#F6F1E8`，主要文字为深墨色 `#18323B`，主要按钮和强调元素为珊瑚色 `#F26B4F`。大标题使用衬线字体，卡片使用细深色描边和适度圆角。在桌面页面中，首屏采用左侧文案与行动入口、右侧会议时间线卡片的两栏布局，页面内容清楚、易读。

## Expected Behavior

Agent 应该从空目录生成完整前端项目，安装、构建、启动流程可用，首页能在浏览器中访问。页面应完整呈现“昼航 Daymark”的产品官网内容，包含吸顶导航、首屏双栏、效果数据、三步工作流、可切换的定价区、手风琴 FAQ，以及免费试用弹窗和表单校验反馈。

正确实现应避免外部网络依赖，所有视觉和交互都在本地页面内完成；表单提交只展示页面内反馈，不发送真实请求。

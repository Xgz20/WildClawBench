# 昼航产品官网

## Prompt

请在 `/tmp_workspace` 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想给“昼航 Daymark”做一个中文单页官网。它是一款给混合办公团队用的会议决策工作台，主要面向产品和运营团队，把议题、决定和负责人放进同一条时间线。页面整体清楚、克制，带一点编辑感，让第一次来的人也能很快看懂它是做什么的。

顶部做一个滚动时保持可见的导航，放上品牌名、“工作流”“定价”“常见问题”和“免费试用”。首屏主标题用“开完会，事情就该向前走”，说明文字是“昼航把议题、决定和负责人放进同一条时间线，让每一次讨论都有清楚的下文。”，再放上“免费试用 14 天”和“查看工作流”两个入口，并标明“无需信用卡 · 5 分钟完成设置”。右边放一张会议时间线的产品界面示意，能看出会议名称、决定、负责人和下一步行动。

首屏下面展示三项产品效果：“42% 跟进消息减少”“3.2 小时 每人每周节省”“96% 决定都有负责人”。工作流区域标题为“从议题到行动，只走三步”，依次介绍“会前收拢议题”“会中锁定决定”“会后推动行动”，并说明如何合并重复问题、记录结论和负责人、按截止时间追踪行动。

定价区可以在按月和按年之间切换。两个方案分别是“轻帆”和“协作舱”：按月价格为每月 ¥39 和每位成员每月 ¥89；按年价格为每月 ¥31 和每位成员每月 ¥71，并显示“按年付费，约省 20%”。这只是产品介绍页，不用真的支付。

常见问题做成手风琴，同一时间最多展开一项，包含以下三问及回答：“可以导入已有会议记录吗？”回答“可以，支持粘贴文本或导入 Markdown，原有标题和待办会被保留。”；“没有管理员也能开始吗？”回答“可以，任何成员都能创建第一个工作区，之后再邀请同事加入。”；“数据会被用于训练模型吗？”回答“不会。工作区内容默认不用于训练，也不会在团队之间共享。”

点击页面里的免费试用入口后，打开“开始 14 天免费试用”弹窗，填写姓名和工作邮箱。没填完整或邮箱格式不对时，给出清楚的中文提示；提交成功后，在弹窗里告诉用户申请已经收到，并显示刚填写的邮箱，之后可以关闭。这里不用真的提交或发邮件，演示页面内的反馈即可。

视觉上做成温暖的纸张风格：暖米色背景、深色文字，主要按钮和重点内容用醒目的橙色。大标题用衬线字体，卡片用细边框和适度圆角。桌面首屏采用左侧文案和行动入口、右侧会议时间线的两栏布局，整体清楚易读。手机上打开也要能正常读完和操作。

## Expected Behavior

Agent 应按 Prompt 完成页面内容、交互和视觉要求。

评分由 Playwright 运行时检查（内容与交互类评分点）和基于截图的视觉判分（视觉与布局类评分点）共同完成；每个评分点按“预设状态 → 操作 → 期望结果”独立判定。

## Grading Criteria

本题仅使用 LLM Judge 评分。评分点全部放在 `## LLM Judge Rubric` 中，每个 Criterion 只有 1.0 和 0.0 两档：非视觉类评分点由 Playwright 检查器按 key 给出运行时结果，视觉类评分点由 LLM 依据截图判定。

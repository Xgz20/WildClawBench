# 高中英语课本单词本

## Prompt

请在 `/tmp_workspace` 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

题目提供的输入素材已经放在 /tmp_workspace/assets 目录中，请直接使用这些文件，不要用自行编造的数据替代。

我在带高一的孩子背英语单词，想做一个中文界面的网页工具，打开就能用，不用登录。名字就叫“课本单词本”。

孩子课本后面的生词表我扫描好了，放在 `/tmp_workspace/assets` 目录里：`textbook-wordlist.pdf` 是必修一和必修二的《各单元生词和习惯用语》，前半是必修一（开头带一个 Welcome Unit），后半接着是必修二；`pages` 目录里是同一份材料的逐页图片，PDF 不好读的时候可以看图片。请把里面的单词整理进网站，单词、音标、词性和中文释义都要和课本一致，不要自己另编单词，也不要改课本的音标。人名地名那类专有名词不用背，像 Wi-Fi、CE 这种品牌名和纪年缩写也算专有名词；短语和习惯用语也不用收，只收带音标的单个单词。必修一和必修二一共十一个单元，整册整册地收进来，加起来有五百多个词，别只挑一小部分。课本上没有例句，每个词请配一句简单的英文例句和中文翻译，让孩子能看出这个词怎么用。

首页先让人看到自己的进度：一共多少词，其中已掌握多少、学习中多少、待学习多少。还没学过的词都算待学习。这三类还要能点开看到具体是哪些词，每个词要能看出音标、中文意思，还有它是哪一册哪个单元的，这样知道哪些还得再练。首页同时显示历次考察的平均分，以及进入单词学习和单词考察这两个入口。

单词学习是这样：先选一册，再选这一册里的一个单元。一个单元几十个词，一次背太多记不住，所以每次从这个单元里挑十个还没掌握的词组成一小组来学，挑的时候先把还在学习中的词拿出来复习，不够十个再补没学过的新词。每个词先只给出英文和音标，让孩子自己回想，点“认识”或“不认识”；点完之后再显示这个词的音标、词性和中文释义、例句和例句翻译，看完继续下一个。

判断有没有掌握按这个规则来：一个词在先后两次学习里都点了“认识”，就算已掌握；点了“不认识”，或者只在一次学习里点过“认识”，就先放在学习中。一次学习里对同一个词的判定以第一次作答为准。

这一组里点了“不认识”的词，等这一组过完要再考一次，如果还是点“不认识”就继续留下来，直到这些词都点了“认识”，这一组才算学完。学完的时候给一句鼓励的话，让孩子有继续学下去的动力。

单词考察也是先选一册和一个单元，不过考察要把这个单元的单词全部考一遍，每个词考一道题，不管这个词之前学到什么程度，这样才知道整个单元到底掌握了多少。每道题给出单词和音标，下面是四个“词性 + 中文释义”的选项，正确的那个用词表里这个词的第一条释义，另外三个从别的单词的释义里取，别出现两个都对的情况。全部答完给出这次的得分，按百分制算，也就是答对的比例。

每次考察都要留下记录，能看到那一次考的是哪个单元、得了多少分，也能看到那一次每道题考的是哪个单词、我选的是什么、正确答案是什么、对还是错。首页的平均分就按历次考察的得分算。考察里答对的词算已掌握，答错的放回学习中。

孩子经常学一半就被叫去吃饭，所以已经答过的词要立刻算进进度里，关掉页面再打开也还在，不用重头再来。

样子上想要温馨活泼一点，别做成冷冰冰的做题系统：浅色暖色调打底，卡片和按钮圆润一些，单词和音标要大、看得清楚，进度和鼓励的文案用亲切的语气，适当加一点点小图标或表情增加亲和力，但不要花哨到影响看清单词。手机上打开也要能正常学和答题。

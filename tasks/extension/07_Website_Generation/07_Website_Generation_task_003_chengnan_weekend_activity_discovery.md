# 城南周末活动发现页

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文城市活动发现页项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。不要接入真实网络请求，也不要使用需要联网才能显示的图片、字体或外部数据。

请制作一个名为“城南周末”的中文城市活动发现页，帮助想在周末出门走走的人快速找到合适的活动。页面要轻松、有活力，但信息仍然清楚，让第一次访问的人很快看懂这个周末有哪些选择。

页面顶部显示品牌名“城南周末”，提供“本周活动”和“订阅清单”两个页面内入口，并在右侧显示“已收藏 0 项”。首屏主标题为“把周末过成喜欢的样子”，说明文字为“从展览、市集、音乐到亲子活动，挑一件出门的小事。”，提供“看看本周活动”按钮，并展示“本周六—周日 · 城南”这一时间地点提示。首屏右侧用一张醒目的“本周精选”海报卡突出“天台落日音乐会”，显示“周六 18:30”“云顶剧场”和“¥88”。

“本周活动”区域提供“全部”“展览”“市集”“音乐”“亲子”五个分类入口，默认选中“全部”。页面内置以下六项活动：“风从纸上来”，展览，周六 10:00，南岸美术馆，免费；“黄昏面包市集”，市集，周六 15:00，榆树广场，¥20；“天台落日音乐会”，音乐，周六 18:30，云顶剧场，¥88；“小小植物观察员”，亲子，周日 09:30，城南植物园，¥49；“旧书交换计划”，市集，周日 14:00，铅字书店，免费；“雨声与大提琴”，音乐，周日 19:30，河畔剧场，¥120。

每项活动使用独立卡片展示分类、名称、时间、地点和价格，并提供“查看详情”和“收藏”操作。切换分类时只显示对应活动，切回“全部”后恢复六项活动。点击“天台落日音乐会”的“查看详情”后打开详情对话框，完整显示活动名称、分类、时间、地点、价格，以及介绍“在城南最高的天台，听一场从落日持续到晚风里的现场演出。”，对话框提供清楚的关闭按钮。

点击任一活动的“收藏”后，该活动的操作文字变为“已收藏”，顶部收藏数量同步增加；再次点击可以取消收藏，操作文字恢复为“收藏”，顶部数量同步减少。本页面不要求刷新后保留收藏状态。

页面下方设置“把周末清单寄给我”订阅区域，说明文字为“每周四，一封邮件整理好城南值得去的地方。”，提供邮箱输入框和“订阅周末清单”按钮。邮箱为空或格式不正确时显示“请输入有效的邮箱地址”；填写有效邮箱后显示“已订阅，我们会在每周四发送周末清单到 {用户填写的邮箱}”。表单只演示页面反馈，不需要真实发送邮件。

视觉上使用浅奶黄色 #FFF7E8 作为页面背景，深蓝灰 #172A3A 作为主要文字颜色，橙色 #FF6B35 作为主要按钮、当前分类和重点强调色，青绿色 #1F7A72 作为辅助色。主标题要醒目，活动卡片使用清楚的深色细边框、适度圆角和轻微错落的海报感。桌面页面的首屏使用左侧文案、右侧精选海报的双栏布局；活动列表在 1440×900 视口中使用清楚的三列卡片网格。页面不要出现横向滚动，也不要使用需要联网才能显示的图片、字体或数据。

## Expected Behavior

Agent 应该从空目录生成完整前端项目，安装、构建、启动流程可用，首页能在浏览器中访问。页面应完整呈现“城南周末”的活动发现内容，包含首屏、分类活动列表、详情对话框、收藏联动和订阅表单反馈。

正确实现应避免外部网络依赖，所有视觉和交互都在本地页面内完成；收藏切换、分类筛选和订阅提交都应有清楚反馈。

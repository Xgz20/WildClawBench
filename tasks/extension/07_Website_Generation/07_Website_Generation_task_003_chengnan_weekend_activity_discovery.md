# 城南周末活动页

## Prompt

请在 `/tmp_workspace` 下创建项目。如果启动网站时遇到端口冲突，请自行选择其他可用端口。

我想做一个叫“城南周末”的中文城市活动发现页，给想在周末出门走走的人用，帮他们快速找到合适的活动。页面要轻松、有活力，但信息仍然清楚，让第一次访问的人很快看懂这个周末有哪些选择。

顶部放上品牌名“城南周末”，有“本周活动”和“订阅清单”两个页面内入口，旁边显示当前已收藏的活动数量。首屏主标题用“把周末过成喜欢的样子”，说明文字是“从展览、市集、音乐到亲子活动，挑一件出门的小事。”，再放一个“看看本周活动”的入口和“本周六—周日 · 城南”的时间地点提示。右侧做一张醒目的“本周精选”活动海报，展示一项精选活动的名称、时间、地点和价格。

“本周活动”区域可以按“全部”“展览”“市集”“音乐”“亲子”筛选。列表里放一些覆盖这些类别的周末活动，每项活动用独立卡片展示分类、名称、时间、地点和价格，并提供“查看详情”和“收藏”操作。切换分类时只显示对应类别的活动。点击活动的查看详情后，打开一个详情层，完整显示活动名称、分类、时间、地点、价格和活动介绍，并能清楚地关闭。收藏和取消收藏时，卡片上的操作状态和顶部收藏数量都要同步更新。

页面下方设置“把周末清单寄给我”订阅区域，说明文字是“每周四，一封邮件整理好城南值得去的地方。”，提供邮箱输入框和“订阅周末清单”按钮。邮箱没填或格式不对时给出清楚的中文提示；填写有效邮箱后，在页面上反馈订阅已经成功，并带上刚填写的邮箱。这个表单只需要演示页面反馈，不用真的发邮件。

视觉上用浅色暖调背景、深色文字，主要按钮和重点内容用醒目的橙色，配一点青绿色作辅助。主标题要醒目，活动卡片有清楚的深色细边框、适度圆角和轻微错落的海报感。桌面首屏把文案和精选海报并排展示，活动列表排布清楚，让人打开页面就能浏览。手机上也要能正常翻活动和收藏。

## Expected Behavior

Agent 应按 Prompt 完成页面内容、交互和视觉要求。

评分由 Playwright 运行时检查（内容与交互类评分点）和基于截图的视觉判分（视觉与布局类评分点）共同完成；每个评分点按“预设状态 → 操作 → 期望结果”独立判定。

## Grading Criteria

本题仅使用 LLM Judge 评分。评分点全部放在 `## LLM Judge Rubric` 中，每个 Criterion 只有 1.0 和 0.0 两档：非视觉类评分点由 Playwright 检查器按 key 给出运行时结果，视觉类评分点由 LLM 依据截图判定。

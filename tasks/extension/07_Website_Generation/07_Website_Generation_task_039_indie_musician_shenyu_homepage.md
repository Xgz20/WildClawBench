# 独立音乐人沈屿个人主页

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文个人主页/独立音乐人官网网页项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。页面运行时不要依赖外部图片、字体、接口或其他网络资源；不要接入真实支付或发送真实请求。

题目提供的输入素材已经放在 /tmp_workspace/assets 目录中，请直接使用这些文件，不要用自行编造的数据替代。

我是个独立音乐人，想做一个自己的主页。

页面左边固定一条导航，从上往下是音乐、行程、相册、简介、联系方式五项，点其中一项，右边就换成对应的内容。刚打开的时候右边先放一张视觉海报，要占住整块地方，一眼就能看见；我的 logo 也放上去。

要用到的东西都放在 `/tmp_workspace/assets` 目录里，请直接使用；页面上的文字和图片要和素材对得上，不要另外编。

音乐这一栏先把我所有的作品都列出来，每个都要有名字和封面。作品分专辑、EP 和单曲三种，我希望能按这三种分别查看。

行程这一栏放接下来的安排，有演出，也有见面会和跟品牌合作的直播。每条要看得出是哪天、在哪座城市、在什么场地、属于哪一类，同样希望能按类别分开看。

相册这一栏按主题分成几本，点开一本，里面的照片全部平铺出来；点其中一张能满屏看大图，看完不用退回去再点下一张，在大图上直接往左往右翻就行，翻完关掉回到刚才那本相册。

简介这一栏是一段我这些年的经历，旁边配上那张写真。联系方式这一栏把合作邮箱和几个账号列清楚。

我想要暗一点、安静一点的风格，像唱片内页一样，符合我的艺术风格。

手机上也要能正常用。

## Expected Behavior

Agent 应从空目录生成可运行的前端网站，按 Prompt 完成页面内容、交互和视觉要求；项目应能在本地 npm install、npm run build 并通过 npm run start 启动，且不依赖外部网络资源。

题目素材位于 /tmp_workspace/assets，页面内容必须与素材一致，不得用编造数据替代。

评分由 Playwright 运行时检查（内容与交互类评分点）和基于截图的视觉判分（视觉与布局类评分点）共同完成；每个评分点按“预设状态 → 操作 → 期望结果”独立判定。

## Grading Criteria

本题仅使用 LLM Judge 评分。评分点全部放在 `## LLM Judge Rubric` 中，每个 Criterion 只有 1.0 和 0.0 两档：非视觉类评分点由 Playwright 检查器按 key 给出运行时结果，视觉类评分点由 LLM 依据截图判定。

# 果园翻翻乐

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文翻牌配对小游戏项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。不要接入真实网络请求，也不要使用需要联网才能显示的图片、字体或外部数据。

请制作一个名为“果园翻翻乐”的中文翻牌配对小游戏，让用户用很短的时间完成一轮轻松的记忆挑战。页面要让第一次打开的人立即看懂目标、当前进度和重新开始的方法。

页面顶部显示品牌名“果园翻翻乐”和提示“轻松记忆 · 随时重来”。首屏上方居中显示主标题“翻开一张，记住一颗果实”和说明文字“用最少的尝试，找出三组藏在果园里的水果。”，标题下方横向展示三条玩法：“每次翻开两张”“相同保留，不同翻回”“找齐三组完成挑战”。

首屏中央是主要游戏区域。游戏面板顶部显示“尝试 0 次”和“已配对 0/3”，并提供“重新开始”按钮；下方使用三列两行排列六张卡片。卡片初始全部背面朝上，背面不能直接显示答案。六张卡片包含两张橙子、两张草莓和两张蓝莓；每次打开页面、点击“重新开始”或点击“再玩一次”时，都要重新随机排列六张卡片，并且新一局不能与上一局的六张位置完全相同。

点击一张未翻开的卡片后，卡片翻到正面，清楚显示对应的水果图案和名称，并保持翻开，等待用户选择第二张。每次翻开第二张卡片后，“尝试”数量增加 1。如果两张卡片不同，两张卡片短暂展示后在 1 秒内自动翻回背面，“已配对”数量不变；如果两张卡片相同，它们保持正面，并显示清楚的已配对样式，“已配对”数量增加 1。已经配对的卡片不能再次参与选择。

三组水果全部配对后，卡片保持完成状态，游戏区域显示“全部配对完成！”和本轮真实的尝试次数，例如最少三次完成时显示“用了 3 次尝试”，同时提供“再玩一次”按钮。点击“重新开始”或完成后的“再玩一次”，都要将六张卡片恢复到背面、重新随机排列，统计恢复为“尝试 0 次”和“已配对 0/3”，完成提示不再显示。

视觉上使用浅薄荷色 #EEF7F0 作为页面背景，深森林绿 #183A34 作为主要文字颜色，橙色 #F26B3A 作为主要按钮和卡片背面的颜色，金黄色 #F6C453 作为重点装饰色，绿色 #4F9D69 作为成功配对状态。主标题要醒目，卡片要有足够大的可点击区域、清楚的圆角和轻微立体感。桌面页面在 1440×900 视口中采用标题、玩法和游戏面板上下排列的居中单列布局，游戏面板位于页面中央，六张卡片以三列两行完整进入首屏；页面不要出现横向滚动，也不要使用需要联网才能显示的图片、字体或数据。

## Expected Behavior

Agent 应该从空目录生成完整前端项目，安装、构建、启动流程可用，首页能在浏览器中访问。页面应完整呈现“果园翻翻乐”的翻牌配对内容，包含首屏玩法、随机卡片、翻牌匹配、完成提示和重新开始。

正确实现应避免外部网络依赖，所有视觉和交互都在本地页面内完成；翻牌、配对、重置和重新开局都应有清楚反馈。

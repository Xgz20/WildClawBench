# 果园翻翻乐

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文休闲娱乐/翻牌配对游戏网页项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。页面运行时不要依赖外部图片、字体、接口或其他网络资源；不要接入真实支付或发送真实请求。

我想做一个叫“果园翻翻乐”的中文翻牌配对小游戏，让用户用很短的时间完成一轮轻松的记忆挑战。页面要让第一次打开的人马上看懂目标、当前进度和重新开始的方法。

顶部放上品牌名“果园翻翻乐”和提示“轻松记忆 · 随时重来”。主标题用“翻开一张，记住一颗果实”，说明文字是“用最少的尝试，找出三组藏在果园里的水果。”，下面用三条简短说明介绍“每次翻开两张”“相同保留，不同翻回”“找齐三组完成挑战”。

主要区域是一个翻牌游戏面板，显示当前尝试次数、已经配对的组数和重新开始入口。面板里放六张卡片，组成三组水果，每种水果各有两张。开始时卡片背面朝上，背面不能直接看到答案。点击一张卡片后翻到正面，显示水果图案和名称，再选第二张；两张不同就短暂展示后翻回去，两张相同则保持正面并标记为已配对。尝试次数在完成一对选择后更新，已经配对的卡片不能再次选择。

三组水果全部配对后，卡片保持完成状态，游戏区域显示完成提示和本轮实际用了多少次尝试，并提供“再玩一次”。点击“重新开始”或“再玩一次”后，开始一局新的随机排列，统计清零，完成提示消失。

视觉上用浅色的清新背景、深绿色文字，主要按钮和卡片背面使用醒目的橙色，成功配对用绿色强调，再加一点明亮的黄色装饰。主标题要醒目，卡片要有足够大的点击区域、清楚的圆角和轻微立体感。桌面页面围绕游戏面板居中排布，标题、玩法说明和卡片区域层次清楚，六张卡片组成易于浏览的网格。手机上也要能正常翻牌。

## Expected Behavior

Agent 应从空目录生成可运行的前端网站，按 Prompt 完成页面内容、交互和视觉要求；项目应能在本地 npm install、npm run build 并通过 npm run start 启动，且不依赖外部网络资源。

评分由 Playwright 运行时检查（内容与交互类评分点）和基于截图的视觉判分（视觉与布局类评分点）共同完成；每个评分点按“预设状态 → 操作 → 期望结果”独立判定。

## Grading Criteria

本题仅使用 LLM Judge 评分。评分点全部放在 `## LLM Judge Rubric` 中，每个 Criterion 只有 1.0 和 0.0 两档：非视觉类评分点由 Playwright 检查器按 key 给出运行时结果，视觉类评分点由 LLM 依据截图判定。

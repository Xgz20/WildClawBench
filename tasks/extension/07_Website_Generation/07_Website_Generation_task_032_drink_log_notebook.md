# 小酌记录本

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文健康记录/饮酒记录与酒精摄入统计网页项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。页面运行时不要依赖外部图片、字体、接口或其他网络资源；不要接入真实支付或发送真实请求。

题目提供的输入素材已经放在 /tmp_workspace/assets 目录中，请直接使用这些文件，不要用自行编造的数据替代。

我平时会喝点小酒，想做个网站把自己的饮酒情况记下来，看看一个月、一年下来到底喝了多少。

首页最上面写一句“今日小酌了吗”，下面是当月的日历。有饮酒记录的日子要一眼能认出来，打开时默认停在今天，点其他日子也能选中，日历还要能往前往后翻月份。没到的日子不能选。选好一天以后，可以直接给这天记一笔，按钮就叫“小酌一下”，旁边配个干杯的图标。首页还要能看到本月一共喝了几天、本月摄入了多少酒精。

除了首页，还要有记录和统计两个页面。记录页把以前的饮酒记录都列出来，能点开看详情，也能改和删；在这里同样可以新记一笔，用的是和首页一样的那套表单。

记一笔的时候要填饮酒时间、这次是在哪儿喝的（家中、朋友家、餐厅、酒吧），还有这次喝了哪些酒、每款喝了多少毫升，一次可以记好几款。这三样必须填，剩下的同饮人、这顿花了多少钱、备注和照片都是想填再填，照片最多三张。饮酒时间默认填当前时刻，从日历上某一天点进来的就落在那一天，不用我再挑一遍。表单最下面顺手帮我算出这次喝了几款酒、一共多少毫升、摄入了多少纯酒精，酒精量都按毫升看。

酒库我要能自己维护，每款酒记下类型（啤酒、白酒、红酒这些）、品牌、名称、酒精度和规格，记一笔的时候从酒库里挑。初始的酒库放在 `/tmp_workspace/assets/wines.json` 里，直接拿来用。

统计页分月度和年度两种周期来看，指标有饮酒天数、饮酒花费、喝到的酒款数和摄入酒精量。下面放一个小酌日历，把这个周期里喝过酒的日子标出来；再放一张摄入酒精量的趋势图，看看这段时间的起伏；接着用环形图看看各类酒各占多少。最后告诉我这个周期里最常去的饮酒场景、最常喝的那款酒、最常一起喝的搭子，还有最常喝酒的时间段。

记下来的东西存在本地就行，下次打开还在。风格轻松一点，暖色调、圆角卡片，手机上看也要方便。

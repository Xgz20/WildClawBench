# 一刻专注番茄钟

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文番茄钟网页项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。不要接入真实网络请求，也不要使用需要联网才能显示的图片、字体或外部数据。

请制作一个名为“一刻专注”的中文番茄钟网页，帮助需要长时间伏案的人把注意力放回当前任务。页面要让第一次使用的人一眼看懂当前处于什么模式、还剩多少时间，以及今天准备完成哪些事情。

页面顶部显示品牌名“一刻专注”和主标题“把这一刻，留给最重要的事”，说明文字为“用一段专注、一次休息，把大任务慢慢变小。”，并展示“今日专注 0 分钟”和“完成任务 0 项”两项今日概览。开始专注后，今日专注按已经过去的完整分钟累计；短休息和长休息不增加这项统计，刷新页面后累计值需要保留。

主要区域左侧是番茄钟。提供“专注”“短休息”“长休息”三种模式，默认选中“专注”，对应时间分别为 25:00、05:00 和 15:00。切换模式时显示对应时间并停止正在进行的计时。计时器提供“开始”和“重置”操作；开始后时间按秒递减，“开始”变为“暂停”，暂停后时间停止并显示“继续”，继续后恢复倒计时。点击重置后回到当前模式的初始时间并停止计时。任一模式倒计时到 00:00 后停止计时，播放一个不依赖网络的提示铃声，并显示清楚的结束提示；专注结束时提示用户“本轮专注结束，起来休息一下”。

主要区域右侧是“今日任务”。初始状态提示“还没有任务，先写下今天最重要的一件事。”，提供任务名称输入框和“添加任务”按钮。未填写任务名称时添加，显示“请输入任务名称”；填写后将任务加入列表并清空输入框。每项任务都可以标记为完成，完成后使用删除线等清楚的完成样式，同时更新顶部的完成任务数量。任务列表和完成状态需要在刷新页面后保留。

页面下方展示“专注建议”，包含“一次只做一件事”“铃响后离开座位休息”“连续完成四轮后进行长休息”三条提示。

视觉上使用奶油色 `#F7F3EA` 作为页面背景，深绿色 `#24352F` 作为主要文字颜色，番茄红 `#E85D4A` 作为主要按钮、当前模式和进度强调色。主标题使用衬线字体，计时数字要足够醒目。番茄钟使用圆形进度环呈现，并以剩余时间作为进度：默认显示 25:00 时，完整的进度环使用番茄红；倒计时开始后，番茄红弧线随着剩余时间逐步缩短。任务区使用带细边框和圆角的独立卡片。在 1440×900 的桌面页面中，番茄钟和今日任务形成清楚的左右双栏并同时进入首屏；页面不要出现横向滚动，也不要使用需要联网才能显示的图片、字体或数据。

## Expected Behavior

Agent 应该从空目录生成完整前端项目，安装、构建、启动流程可用，首页能在浏览器中访问。页面应完整呈现“一刻专注”的番茄钟内容，包含当前模式、倒计时、今日概览、今日任务、专注建议，以及刷新后仍保留的任务和专注统计。

正确实现应避免外部网络依赖，所有视觉和交互都在本地页面内完成；计时器、任务添加和完成状态都应有清楚反馈。

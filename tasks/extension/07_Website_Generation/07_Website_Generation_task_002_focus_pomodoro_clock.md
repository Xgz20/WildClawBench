# 一刻专注番茄钟

## Prompt

请在 /tmp_workspace 下从空目录创建一个可运行的中文效率工具/番茄钟网页项目。项目根目录需要提供 package.json，并支持 npm install、npm run build，以及 npm run start -- --host 127.0.0.1 --port 4173 启动网站。页面运行时不要依赖外部图片、字体、接口或其他网络资源；不要接入真实支付或发送真实请求。

我想做一个叫“一刻专注”的中文番茄钟网页，给需要长时间伏案的人用，帮他们把注意力放回眼前的事情。页面要简单清楚，让第一次打开的人马上知道现在是什么模式、还剩多少时间，以及今天打算完成哪些任务。

顶部放上品牌名“一刻专注”，主标题用“把这一刻，留给最重要的事”，说明文字是“用一段专注、一次休息，把大任务慢慢变小。”。旁边展示今天累计的专注分钟数和已经完成的任务数。只把专注时间计入今日累计，短休息和长休息不算。

番茄钟提供“专注”“短休息”“长休息”三种模式，时间分别是 25:00、05:00 和 15:00，切换后显示对应的完整时长。计时可以开始、暂停、继续和重置，重置后回到当前模式的初始时间。倒计时结束时发出提示音，并在页面上给出清楚的提醒；如果结束的是一轮专注，要提醒用户起来休息一下。

再做一个“今日任务”区域，可以写下任务并添加到列表里，也可以把任务标记为完成。没有任务时，提示用户先写下今天最重要的一件事；没有填写内容时不要添加空任务，给出清楚的提示。完成的任务要有明显区别，顶部的完成数量也要跟着更新。

页面下方放一个“专注建议”区域，包含“一次只做一件事”“铃响后离开座位休息”“连续完成四轮后进行长休息”三条提示。

视觉上用偏暖的浅色背景和深绿色文字，主要按钮、当前模式和进度用醒目的红色。主标题用衬线字体，倒计时数字要足够醒目。计时器做成圆形进度环，完整时长显示完整进度，开始后随着剩余时间逐渐缩短。任务区用带细边框和圆角的独立卡片。桌面上把番茄钟和今日任务并排放，让人打开页面就能同时看到。手机上也要能正常计时和记任务。

## Expected Behavior

Agent 应从空目录生成可运行的前端网站，按 Prompt 完成页面内容、交互和视觉要求；项目应能在本地 npm install、npm run build 并通过 npm run start 启动，且不依赖外部网络资源。

评分由 Playwright 运行时检查（内容与交互类评分点）和基于截图的视觉判分（视觉与布局类评分点）共同完成；每个评分点按“预设状态 → 操作 → 期望结果”独立判定。

## Grading Criteria

本题仅使用 LLM Judge 评分。评分点全部放在 `## LLM Judge Rubric` 中，每个 Criterion 只有 1.0 和 0.0 两档：非视觉类评分点由 Playwright 检查器按 key 给出运行时结果，视觉类评分点由 LLM 依据截图判定。
